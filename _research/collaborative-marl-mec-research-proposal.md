# Multi-Agent Deep Reinforcement Learning for Collaborative Computation Offloading in Mobile Edge-Computing

## 자료 정보

| 항목 | 내용 |
| --- | --- |
| 제목 | Multi-Agent Deep Reinforcement Learning for Collaborative Computation Offloading in Mobile Edge-Computing |
| 저자 | Iman Rahmati |
| 연도 | 원문에 연도 미기재 |

## 핵심 질문

Mobile device에서 edge node로 보내는 D2E offloading과 edge node 사이의 E2E forwarding을 함께 고려하려는 3쪽 연구 제안이다. Dec-POMDP와 multi-agent DDPG를 설계 후보로 제시한다.

## 강의 구성

- D2E와 E2E offloading의 역할
- 부분 관측 환경에서 협력이 필요한 이유
- 분산 actor와 중앙 critic의 제안 방향
- 제안서에 명시된 범위와 후속 정의가 필요한 항목

## 읽을 때 구분할 점

완성된 알고리즘이나 실험 결과를 보고한 논문이 아니다. 원문에는 state·action·reward의 구체적 정의, queue 갱신식, 학습 pseudocode, 실험 설정과 성능 결과가 없으므로 제안 방향과 검증된 결과를 구분한다.
