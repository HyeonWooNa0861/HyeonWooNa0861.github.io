## 1. 점근적 성장 함수

점근적 성장 함수 `f(n)`은 수행 시간 함수 `T(n)`에서 입력 크기 `n`이 커질 때 지배적인 항만 남긴 것이다.

```text
T(n) = 3n^2 + 2n + 5  ->  f(n) = n^2
```

상수 계수와 낮은 차수 항은 큰 입력에서 영향이 상대적으로 작아지므로 생략한다.

## 2. Big-O

Big-O는 점근적 상한을 표현한다.

```text
T(n) ∈ O(f(n))
```

이는 충분히 큰 `n`에 대해 `T(n)`이 `c * f(n)`보다 커지지 않는다는 뜻이다.

```text
T(n) ≤ c * f(n)  for all n > n0
```

직관적으로는 "이 알고리즘은 `f(n)`보다 더 빠르게 나빠지지는 않는다"라고 해석하면 된다.

## 3. Big-O 예제

| 수행 시간 함수 | Big-O | 이유 |
|---|---|---|
| `7n + 3` | `O(n)` | 선형항이 지배한다. |
| `3n^3 + 7n + 5` | `O(n^3)` | 세제곱항이 지배한다. |
| `5n^2 + 100n` | `O(n^2)` | 큰 입력에서는 `n^2`이 더 빠르게 증가한다. |

Big-O 증명에서는 적절한 양의 상수 `c`와 기준점 `n0`를 찾으면 된다. 예를 들어 `7n + 3 ≤ 8n`은 `n ≥ 3`에서 성립하므로 `7n + 3 ∈ O(n)`이라고 할 수 있다.

## 4. Prefix Average 예제

Prefix Average 문제는 길이 `n` 배열에서 각 위치 `i`마다 `A[0]`부터 `A[i]`까지의 평균을 계산하는 문제다.

### 구현 1: 매번 다시 합산

```text
for i = 0 to n-1:
    sum = 0
    for j = 0 to i:
        sum += A[j]
    B[i] = sum / (i + 1)
```

각 `i`마다 앞부분을 다시 더하므로 총 연산 수는 `1 + 2 + ... + n`에 비례한다. 따라서 시간 복잡도는 `O(n^2)`이다.

### 구현 2: 누적합 사용

```text
sum = 0
for i = 0 to n-1:
    sum += A[i]
    B[i] = sum / (i + 1)
```

각 원소를 한 번씩만 더하므로 시간 복잡도는 `O(n)`이다.

이 예제의 핵심은 같은 문제라도 **이전 계산 결과를 재사용하면 차수가 달라질 수 있다**는 점이다.

## 5. Big-Ω

Big-Ω는 점근적 하한을 표현한다.

```text
T(n) ∈ Ω(f(n))
```

이는 충분히 큰 `n`에 대해 `T(n)`이 `c * f(n)` 이상이라는 뜻이다.

```text
T(n) ≥ c * f(n)  for all n > n0
```

직관적으로는 "아무리 잘 되어도 이 정도 시간은 든다"에 가깝다.

## 6. Big-Θ

Big-Θ는 상한과 하한이 같은 차수임을 뜻한다.

```text
T(n) ∈ Θ(f(n))
```

즉 충분히 큰 `n`에서 다음이 성립한다.

```text
c1 * f(n) ≤ T(n) ≤ c2 * f(n)
```

Big-Θ는 실행 시간의 정확한 차수를 말할 때 쓴다.

## 표기법 비교

| 표기 | 의미 | 한 줄 해석 |
|---|---|---|
| `O(f(n))` | 상한 | 이보다 더 나빠지지는 않는다. |
| `Ω(f(n))` | 하한 | 이보다 더 좋아지지는 않는다. |
| `Θ(f(n))` | tight bound | 이 차수로 증가한다. |

## 시험 포인트

| 질문 | 답의 방향 |
|---|---|
| `T(n) = 10n^2 + 3n + 7`의 점근적 성장 함수는? | `n^2` |
| Big-O와 Big-Θ의 차이는? | Big-O는 상한, Big-Θ는 상한과 하한이 모두 같은 경우 |
| Prefix Average 구현 1과 2의 차이는? | 중복 합산 때문에 `O(n^2)`, 누적합 사용 시 `O(n)` |
| 상수 계수는 왜 무시하는가? | 큰 입력에서 성장 차수를 바꾸지 않기 때문 |
