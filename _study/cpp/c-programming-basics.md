## 1. 교과목과 학습 목표

이 강의의 큰 목표는 C/C++을 통해 프로그램이 컴퓨터 시스템에서 어떻게 실행되는지 이해하는 것이다. Python이나 Java처럼 추상화가 많은 언어와 달리, C/C++은 메모리, 컴파일, 포인터, 타입, 함수 호출 구조를 더 직접적으로 다룬다.

핵심 학습 목표는 다음과 같다.

| 목표 | 설명 |
|---|---|
| C 언어 학습 | 프로그램이 컴퓨터 시스템에서 수행되는 방식을 이해한다. |
| C++ 객체지향 적용 | 클래스, 상속, 다형성 같은 객체지향 개념을 C++에서 활용한다. |
| STL 활용 | C++ 표준 라이브러리와 컨테이너를 실습에 적용한다. |
| 저수준 작동 이해 | 컴파일, 메모리, 포인터, 디버깅 흐름을 이해한다. |

## 2. C 언어의 탄생

C 언어는 UNIX 운영체제와 함께 발전했다. 초기 운영체제는 어셈블리어로 작성되어 이식성과 유지보수가 어려웠다. 1972년 Dennis Ritchie는 B 언어를 발전시켜 C 언어를 만들었고, UNIX를 C로 다시 작성하면서 C는 시스템 프로그래밍 언어로 자리 잡았다.

C의 설계 철학은 다음 문장으로 정리할 수 있다.

> 하드웨어에 가깝지만 사람이 읽을 수 있는 언어

C는 메모리 주소, 포인터, 배열, 함수 호출을 직접 다룰 수 있으면서도 어셈블리어보다 훨씬 읽기 쉽고 이식성이 좋다. 그래서 운영체제, 임베디드, 드라이버, 시스템 라이브러리처럼 하드웨어와 가까운 영역에서 여전히 중요하다.

## 3. C에서 C++로

C++은 Bjarne Stroustrup이 C에 클래스 개념을 더하면서 발전했다. 초기 이름은 `C with Classes`였고, 1983년에 `C++`이라는 이름이 붙었다. `++`는 C의 증가 연산자이므로 “C를 한 단계 발전시킨 언어”라는 의미를 담고 있다.

| 항목 | C | C++ |
|---|---|---|
| 패러다임 | 절차적 프로그래밍 | 절차적 + 객체지향 + 제네릭 |
| 주요 도구 | 함수, 구조체, 포인터 | 클래스, 템플릿, STL, RAII |
| 추상화 | 상대적으로 낮음 | 높은 수준의 추상화 가능 |
| 성능 철학 | 하드웨어에 가까움 | zero-overhead abstraction 지향 |

C++의 중요한 철학은 **zero-overhead abstraction**이다. 사용하지 않는 기능에 비용을 지불하지 않고, 추상화를 사용하더라도 직접 구현한 코드와 비슷한 성능을 목표로 한다.

## 4. Python과 C의 핵심 차이

| 항목 | Python | C |
|---|---|---|
| 타입 선언 | 불필요, 동적 타입 | 필수, 정적 타입 |
| 실행 방식 | 인터프리터 중심 | 컴파일 필요 |
| 메모리 관리 | 자동, GC | 직접 관리 필요 |
| 문자열 | 객체로 다룸 | 문자 배열과 포인터로 다룸 |
| 원본 수정 | 객체 모델에 따라 다름 | 값 전달이 기본, 포인터 필요 |

C는 Python보다 번거롭지만, 메모리와 실행 구조를 직접 이해할 수 있다. 이 지식은 C++의 포인터, 참조, 객체 수명, 성능 최적화를 이해하는 기반이 된다.

## 5. 개발 환경과 컴파일

C/C++ 개발에는 소스 코드 작성, 컴파일, 링크, 실행 과정이 필요하다.

```text
source file (.c/.cpp)
→ preprocessing
→ compilation
→ assembly
→ linking
→ executable
```

대표적인 `g++` 명령은 다음과 같다.

```bash
g++ -std=c++17 -Wall -Wextra -g main.cpp -o main
./main
```

주요 옵션:

| 옵션 | 의미 |
|---|---|
| `-std=c++17` | C++17 표준 사용 |
| `-Wall` | 주요 경고 활성화 |
| `-Wextra` | 추가 경고 활성화 |
| `-g` | 디버깅 정보 포함 |
| `-o main` | 출력 실행 파일 이름 지정 |

| 코드 | 의미 |

## 8. 변수, 자료형, 연산자

C는 변수를 사용하기 전에 타입을 명시해야 한다.

```c
int age = 20;
double height = 175.5;
char grade = 'A';
```

기본 자료형:

| 분류 | 예 |
|---|---|
| 정수형 | `char`, `short`, `int`, `long`, `long long` |
| 실수형 | `float`, `double` |
| 문자형 | `char` |

주요 연산자:

| 분류 | 예 |
|---|---|
| 산술 | `+`, `-`, `*`, `/`, `%` |
| 비교 | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| 논리 | `&&`, `\|\|`, `!` |
| 증감 | `++`, `--` |
| 대입 | `=`, `+=`, `-=`, `*=`, `/=` |

## 9. 조건문과 반복문

조건문:

```c
if (score >= 90) {
    printf("A\n");
} else {
    printf("B or lower\n");
}
```

반복문:

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
```

```c
while (n <= 5) {
    printf("%d\n", n);
    n++;
}
```

`break`는 반복문을 빠져나가고, `continue`는 현재 반복의 나머지를 건너뛰고 다음 반복으로 이동한다.

## 10. 함수와 값 전달

C 함수는 반환 타입, 함수 이름, 매개변수 타입을 명시한다.

```c
int add(int a, int b);

int add(int a, int b) {
    return a + b;
}
```

C는 기본적으로 **값 전달(call-by-value)** 이다. 함수에 전달된 인자는 복사본이므로 함수 안에서 값을 바꿔도 원본은 바뀌지 않는다.

```c
void swap_wrong(int a, int b) {
    int tmp = a;
    a = b;
    b = tmp;
}
```

원본을 바꾸려면 포인터로 주소를 전달해야 한다.

```c
void swap(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
```

## 11. 포인터 기초

포인터는 어떤 변수의 주소를 저장하는 변수다.

```c
int x = 42;
int* p = &x;

printf("%d\n", *p);
```

| 기호 | 의미 |
|---|---|
| `&x` | `x`의 주소 |
| `int* p` | `int`를 가리키는 포인터 |
| `*p` | 포인터가 가리키는 값에 접근 |

포인터 사용의 기본 원칙은 다음이다.

- 이미 존재하는 유효한 객체를 가리키게 한다.
- 초기화하지 않은 포인터를 사용하지 않는다.
- `NULL` 또는 `nullptr` 가능성을 고려한다.
- 꼭 필요한 경우에만 사용한다.

## 12. 변수 스코프

스코프는 변수가 접근 가능한 범위다.

| 종류 | 설명 |
|---|---|
| 전역 변수 | 파일 전체에서 접근 가능 |
| 지역 변수 | 선언된 블록 안에서만 접근 가능 |
| 매개변수 | 함수 호출 중 함수 내부에서만 사용 |

스코프를 이해하면 왜 포인터가 필요한지 명확해진다. 함수 밖의 원본 값을 함수 안에서 바꾸려면, 값 자체가 아니라 주소를 전달해야 한다.

| 개념 | 꼭 기억할 점 |
|---|---|
| C | 하드웨어에 가깝고 메모리 제어가 가능한 시스템 언어 |
| C++ | C에 객체지향, 제네릭, STL을 더한 언어 |
| 컴파일 | 소스 코드를 실행 파일로 바꾸는 과정 |
| 자료형 | C에서는 변수 선언 시 타입을 명시해야 한다. |
| 함수 | 반환 타입과 매개변수 타입을 명시한다. |
| 값 전달 | 함수 인자는 기본적으로 복사된다. |
| 포인터 | 원본 수정과 메모리 접근을 위해 주소를 다룬다. |
| 스코프 | 변수의 접근 가능 범위를 결정한다. |

이 문서는 C 언어의 역사와 개발 환경, C 기본 문법, 포인터 입문을 하나의 흐름으로 정리한 것이다. 이후 구조체, 동적 할당, C++ 클래스와 참조를 이해하기 위한 기초가 된다.

## Study Guide

이 문서는 C/C++ 학습의 출발점이다. 처음에는 문법을 모두 외우려 하기보다 "컴파일 언어가 어떻게 실행 파일이 되는가", "자료형이 왜 필요한가", "함수 호출에서 값이 어떻게 전달되는가"를 중심으로 읽는 것이 좋다.

C의 핵심은 명시성이다. 변수에는 타입이 있고, 함수에는 반환 타입과 매개변수 타입이 있으며, 포인터를 통해 주소를 직접 다룰 수 있다. Python처럼 많은 부분이 자동으로 처리되는 언어와 비교하면 처음에는 번거롭지만, 컴퓨터가 메모리와 값을 어떻게 다루는지 더 선명하게 볼 수 있다.

포인터는 이후 구조체, 동적 할당, 참조, 클래스 학습으로 이어지는 핵심 개념이다. `&`는 주소를 얻고, `*`는 포인터가 가리키는 값에 접근한다. 함수에서 원본 값을 바꾸려면 값이 아니라 주소를 전달해야 한다는 점을 반복해서 확인해야 한다.

<summary>1. C에서 함수 인자는 기본적으로 어떤 방식으로 전달되는가?</summary>

답변: 기본적으로 값 전달(call-by-value)이다. 함수에 전달된 값은 복사본이므로 함수 내부에서 매개변수를 바꿔도 호출한 쪽의 원본 변수는 바뀌지 않는다.

</details>

<details>
<summary>2. 함수 안에서 호출한 쪽의 원본 변수를 바꾸려면 왜 포인터가 필요한가?</summary>

답변: 값 자체를 복사해서 전달하면 원본에 접근할 수 없기 때문이다. 원본 변수의 주소를 포인터로 전달하면 함수 내부에서 `*p`를 통해 그 주소의 값을 직접 수정할 수 있다.

</details>

<details>
<summary>3. 컴파일은 어떤 과정이며, C/C++에서 왜 중요한가?</summary>

답변: 컴파일은 사람이 작성한 소스 코드를 컴퓨터가 실행할 수 있는 기계어 또는 실행 파일로 바꾸는 과정이다. C/C++은 컴파일 언어이므로 실행 전에 타입 검사, 문법 검사, 목적 코드 생성, 링크 과정을 거친다.

</details>
