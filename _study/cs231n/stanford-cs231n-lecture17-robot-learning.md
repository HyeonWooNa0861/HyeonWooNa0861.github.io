# Stanford CS231N Lecture 17: Robot Learning

Source: [Stanford CS231N Spring 2025 Lecture 17](https://www.youtube.com/watch?v=XSfmOH_xVSU){:target="_blank" rel="noopener"}

## 핵심 내용

시각 인식이 실제 행동과 연결되는 embodied AI와 robot learning을 다룬다. 로봇은 관찰, 상태 추정, 계획, 제어, 보상, 상호작용을 함께 다뤄야 하며, 시뮬레이션과 실제 환경의 차이도 중요하다. Imitation learning과 reinforcement learning은 로봇이 작업을 배우는 대표적 접근이다.

## 학습 포인트

- 로봇 학습은 perception과 action을 연결하는 문제다.
- 시뮬레이션에서 배운 정책을 실제 환경으로 옮길 때 sim-to-real gap이 생긴다.
- 모방학습과 강화학습은 로봇 행동 학습의 주요 축이다.

## 핵심 개념

| 개념 | 설명 |
|---|---|
| Embodied AI | 물리적 또는 가상 환경에서 관찰하고 행동하는 지능 시스템 |
| Imitation Learning | 전문가 시연을 따라 행동 정책을 학습하는 방법 |
| Reinforcement Learning | 보상을 최대화하도록 시행착오로 정책을 학습하는 방법 |
| Sim-to-Real | 시뮬레이션 학습 결과를 실제 환경에 이전하는 문제 |

## Study Guide

1. 로봇 학습이 정적 이미지 분류보다 어려운 이유는 무엇인가?
2. imitation learning과 reinforcement learning은 어떤 데이터와 신호를 사용하는가?
3. sim-to-real gap을 줄이려면 어떤 전략이 필요한가?
