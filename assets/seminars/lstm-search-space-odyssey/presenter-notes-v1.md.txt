## 1. LSTM: A Search Space Odyssey

1. LSTM: A Search Space Odyssey

발표 대본
이 논문은 새로운 LSTM cell을 제안하지 않습니다. 당시 널리 쓰인 vanilla LSTM을 기준으로 여덟 가지 구성요소를 한 번에 하나씩 바꾸고, 음성·필기·음악 세 과제에서 각각 hyperparameter를 다시 탐색한 통제 실험입니다. 발표에서는 먼저 1997년 원형과 논문이 평가한 vanilla cell을 구분하고, 한 번의 state update를 직접 계산한 다음, 변형 비교와 fANOVA가 실제로 말해 주는 범위를 살펴보겠습니다.

## 2. 연구 질문을 실험 규모로 바꾸기

2. 연구 질문을 실험 규모로 바꾸기

발표 대본
논문의 실험 격자는 아홉 architecture와 세 dataset의 조합 27개입니다. 각 조합마다 200개의 hyperparameter trial을 독립적으로 뽑아 총 5,400회를 실행했습니다. 각 실험은 평균 24.3시간이 걸렸고, 단일 CPU 시간으로 합치면 15년에 조금 못 미칩니다. 이 규모는 한 설정에서 우연히 잘 나온 모델을 찾기보다 architecture 변화가 여러 tuning 조건에서 어떻게 작동하는지 비교하기 위한 것입니다.

## 3. 이 논문이 답하는 것과 답하지 않는 것

3. 이 논문이 답하는 것과 답하지 않는 것

발표 대본
논문의 제목 때문에 무한한 LSTM 구조 공간을 탐색한 연구처럼 들릴 수 있지만 실제 범위는 명확합니다. Vanilla에서 한 항목만 바꾼 여덟 variant를 세 dataset에서 비교합니다. 각 조합을 따로 tuning해 architecture가 요구하는 설정 차이를 허용합니다. 따라서 결과는 강한 비교 증거지만, 이후의 optimizer나 다른 데이터 규모, 여러 부품을 동시에 바꾼 cell까지 포괄하는 보편적 우열 정리는 아닙니다.

## 4. 1997 원형에서 Odyssey 기준 cell까지

4. 1997 원형에서 Odyssey 기준 cell까지

발표 대본
1997년 원형은 input gate와 output gate, 고정 self-loop를 가진 Constant Error Carousel을 사용했지만 forget gate와 peephole은 없었습니다. 또한 gate들 사이의 full gate recurrence가 있었고, cell gradient만 시간축으로 전달하며 다른 recurrent gradient는 잘랐습니다. 이후 forget gate, peephole, full BPTT가 더해져 논문이 vanilla라고 부르는 형태가 됐습니다. Odyssey는 이 later vanilla의 구성요소를 하나씩 바꾸어 평가합니다.

## 5. 1997 original과 평가 대상 vanilla

5. 1997 original과 평가 대상 vanilla

발표 대본
역사적 차이를 표로 고정하겠습니다. 1997 original에는 forget gate와 peephole이 없고, gate 사이 recurrent connection은 있었습니다. 학습도 today-style full BPTT가 아니었습니다. Odyssey의 vanilla는 forget gate와 peephole, full gradient training을 사용하지만 full gate recurrence는 기본적으로 없습니다. 그러므로 NFG 하나만 보고 original LSTM이라고 부르면 gate recurrence와 gradient 학습 차이를 놓칩니다.

## 6. Vanilla cell의 여섯 계산 요소

6. Vanilla cell의 여섯 계산 요소

발표 대본
Vanilla cell의 forward pass를 역할 중심으로 읽겠습니다. z는 현재 입력과 이전 block output으로 만든 새 후보입니다. Input gate i는 후보를 얼마나 cell에 쓸지, forget gate f는 이전 cell state를 얼마나 유지할지 정합니다. Cell state를 h로 squash한 뒤 output gate o가 외부 block output을 조절합니다. Gate activation은 sigmoid이고, 논문의 기본 block input과 output activation은 tanh입니다.

## 7. Peephole은 cell state를 gate에 보여 준다

7. Peephole은 cell state를 gate에 보여 준다

발표 대본
Peephole은 cell state에서 gate로 가는 weighted connection입니다. Input gate와 forget gate는 이전 state cₜ₋₁을 보고, output gate는 이번에 갱신된 cₜ을 봅니다. 논문은 precise timing을 학습할 때 cell이 gate를 제어하도록 이 연결이 도입됐다고 설명합니다. Peephole은 block output의 recurrent connection과 다른 경로이며, NP variant는 이 세 cell-to-gate 항만 제거합니다.

## 8. Cell state는 새 content와 남긴 memory의 합

8. Cell state는 새 content와 남긴 memory의 합

발표 대본
Vanilla의 핵심 state 식은 cₜ = zₜ×iₜ + cₜ₋₁×fₜ입니다. 첫 경로는 새 후보를 input gate로 걸러 쓰고, 둘째 경로는 이전 cell state를 forget gate로 조절해 남깁니다. 두 결과를 더한 뒤 output activation h를 적용하고 output gate o를 곱해 yₜ를 만듭니다. 이 도식은 논문 Figure 1을 복사한 것이 아니라 forward equation의 계산 의존성을 편집 가능한 객체로 풀어쓴 것입니다.

## 9. 한 번의 scalar state update 계산

9. 한 번의 scalar state update 계산

발표 대본
이 숫자는 논문의 실험 parameter가 아니라 cell 식을 이해하기 위한 독립 계산입니다. 이전 state는 0.50, 후보 z는 0.80, input gate는 0.25, forget gate는 0.90입니다. 새 content는 0.20이고 유지된 memory는 0.45여서 cₜ는 0.65가 됩니다. Output gate 0.60을 tanh(0.65)에 곱하면 약 0.343입니다. 어느 branch가 forgetting을 담당하는지 수치로 확인할 수 있습니다.

## 10. Forget gate 값이 state 경로에 미치는 영향

10. Forget gate 값이 state 경로에 미치는 영향

발표 대본
Cell 식에서 cₜ₋₁에 직접 곱해지는 계수는 fₜ입니다. 다른 경로를 고정해 보면 fₜ가 1에 가까울수록 이전 state가 남고, 0에 가까울수록 reset됩니다. 이것이 gradient가 오래 유지될 수 있는 직접 경로이기도 합니다. 다만 전체 gradient는 gate의 recurrent dependency와 다른 경로도 가지므로 f 하나만으로 모든 장기 의존성을 설명하면 안 됩니다. NFG는 이 계수를 항상 1로 고정합니다.

## 11. 여덟 variant는 한 번에 한 항목만 바꾼다

11. 여덟 variant는 한 번에 한 항목만 바꾼다

발표 대본
모든 variant는 vanilla에서 정확히 한 측면만 추가·제거·수정합니다. 이렇게 해야 성능 차이를 그 변화와 연결할 수 있습니다. 그러나 architecture가 바뀌면 좋은 learning rate나 hidden size도 달라질 수 있으므로 논문은 모든 variant에 동일한 hyperparameter를 강제하지 않습니다. 대신 variant와 dataset의 각 조합을 별도로 random search하고 validation set으로 선택한 뒤 test set에서 비교합니다.

## 12. Gate를 바꾸는 네 variant

12. Gate를 바꾸는 네 variant

발표 대본
NIG, NFG, NOG는 각각 gate 출력을 1로 고정해 해당 gate의 조절을 제거합니다. CIFG는 input gate와 forget gate를 결합해 fₜ를 1−iₜ로 정합니다. 그래서 새 content를 더 많이 쓸수록 이전 memory를 덜 남기는 관계가 생깁니다. CIFG는 forget 작동을 유지하며 parameter를 줄이는 later variant이고, forget gate가 없던 1997 original과 같지 않습니다.

## 13. Activation과 연결을 바꾸는 네 variant

13. Activation과 연결을 바꾸는 네 variant

발표 대본
NIAF는 새 후보를 만드는 g를 identity로 바꾸고, NOAF는 cell output activation h를 identity로 바꿉니다. NP는 input, forget, output gate의 peephole 항을 제거합니다. FGR은 이전 time step의 세 gate에서 현재 세 gate로 가는 모든 연결을 더하므로 3×3, 즉 recurrent weight matrix 아홉 개가 추가됩니다. FGR은 original LSTM에 있던 특징 하나를 vanilla에 되돌리지만 original 전체를 재현하지는 않습니다.

## 14. Variant 해석에서 피해야 할 세 혼동

14. Variant 해석에서 피해야 할 세 혼동

발표 대본
Ablation 이름은 변경된 항목만 알려 줍니다. NFG가 f를 1로 만들더라도 peephole과 full BPTT 등은 vanilla 그대로입니다. CIFG는 forget gate 값을 input gate와 묶어 계산하므로 forgetting 기능이 남습니다. FGR도 original의 gate recurrence를 추가할 뿐 original의 truncated gradient 학습으로 돌아가지 않습니다. NP는 peephole 연결을 없애지만 gate 자체를 지우지 않습니다.

## 15. 세 dataset은 서로 다른 sequence 문제다

15. 세 dataset은 서로 다른 sequence 문제다

발표 대본
세 과제는 sequence라는 공통점만 있고 출력과 metric이 다릅니다. TIMIT은 audio frame마다 phone을 분류하고 classification error percentage를 씁니다. IAM Online은 pen movement sequence를 문자열로 바꾸고 CTC 기반 character error rate를 씁니다. JSB Chorales는 piano-roll의 다음 step을 예측하고 negative log-likelihood를 보고합니다. 모두 낮을수록 좋지만 단위와 과제가 달라 절대 숫자를 서로 비교할 수 없습니다.

## 16. 과제마다 network 방향과 loss도 다르다

16. 과제마다 network 방향과 loss도 다르다

발표 대본
TIMIT과 IAM은 입력을 앞뒤 방향으로 처리하는 bidirectional LSTM을 사용합니다. 두 방향 hidden layer는 하나의 softmax output에 연결됩니다. TIMIT은 cross-entropy, IAM은 alignment를 포함하는 CTC loss를 사용합니다. JSB는 단일 LSTM hidden layer와 sigmoid output으로 next-step prediction을 학습하며 결과를 negative log-likelihood로 보고합니다. 따라서 세 결과를 하나의 동일한 training setup으로 단순화하면 안 됩니다.

## 17. 공정 비교를 만드는 실험 pipeline

17. 공정 비교를 만드는 실험 pipeline

발표 대본
각 dataset은 train, validation, test로 나눕니다. Random trial의 network를 train split에서 학습하고 validation으로 early stopping과 좋은 설정을 선택합니다. Test set은 마지막 architecture 비교에 사용합니다. 중요한 점은 vanilla의 좋은 hyperparameter를 다른 variant에 그대로 쓰지 않았다는 것입니다. 각 variant가 자신의 좋은 설정을 찾을 기회를 받은 뒤 비교했기 때문에 구성요소 효과를 더 공정하게 볼 수 있습니다.

## 18. 27개 random search는 서로 설정을 공유하지 않는다

18. 27개 random search는 서로 설정을 공유하지 않는다

## 19. Random search가 표본화한 범위

19. Random search가 표본화한 범위

발표 대본
Hidden block 수와 learning rate는 log-uniform으로 뽑아 여러 규모를 고르게 탐색합니다. Momentum은 1에서 log-uniform sample을 뺀 형태이고 input noise 표준편차는 0부터 1까지 uniform입니다. TIMIT은 momentum 방식과 gradient clipping 여부도 실험했습니다. 논문은 search range를 합리적으로 선택했다고 설명하지만, 범위를 훨씬 넓히거나 다른 optimizer를 쓰면 좋은 설정을 찾는 난이도와 비교 결과가 달라질 수 있습니다.

## 20. Training protocol의 고정 조건

20. Training protocol의 고정 조건

발표 대본
모든 LSTM은 full BPTT로 gradient를 계산하고 sequence마다 SGD update를 수행했습니다. 기본 optimizer는 Nesterov-style momentum이며 initial weight 표준편차는 0.1입니다. Training은 150 epoch 또는 validation이 15 epoch 넘게 개선되지 않으면 끝납니다. 논문은 variant마다 parameter 수를 같게 강제하지 않았습니다. 구조별로 parameter 활용이 달라 같은 수를 맞추면 오히려 비교가 편향될 수 있다고 판단했습니다.

## 22. 주요 결론: 유일한 승자 variant는 없었다

22. 주요 결론: 유일한 승자 variant는 없었다

발표 대본
논문의 broad conclusion은 평가한 여덟 variant 중 어느 것도 vanilla를 유의하게 개선하지 못했다는 것입니다. 반대로 forget gate를 제거한 NFG와 output activation을 제거한 NOAF는 세 dataset 모두에서 성능이 유의하게 나빠졌습니다. CIFG와 NP는 유의한 성능 저하 없이 계산과 parameter를 줄일 가능성을 보였습니다. 이는 CIFG나 NP가 보편적으로 더 좋다는 뜻이 아니라 이 평가에서 simpler alternatives로 남았다는 뜻입니다.

## 23. Variant 효과는 공통 결과와 task 차이로 나뉜다

23. Variant 효과는 공통 결과와 task 차이로 나뉜다

발표 대본
NFG와 NOAF의 악화는 세 과제에 공통으로 나타났습니다. NIG, NOG, NIAF는 speech와 handwriting에서 유의한 성능 저하가 있었지만 music modeling에서는 유의한 영향이 없었습니다. CIFG와 NP는 어느 dataset에서도 평균 성능을 유의하게 바꾸지 않았습니다. FGR은 TIMIT과 IAM에서 유의한 변화가 없고 JSB에서 더 나빴습니다. 이 표의 동일은 성능 수치가 같다는 뜻이 아니라 유의한 평균 차이가 없다는 뜻입니다.

## 24. CIFG와 NP가 실용적 후보로 남은 이유

24. CIFG와 NP가 실용적 후보로 남은 이유

발표 대본
CIFG와 NP는 architecture를 단순화하고 parameter 및 계산 비용을 줄입니다. 이 두 variant의 mean performance는 평가한 dataset에서 vanilla와 유의한 차이가 없었습니다. 따라서 자원 제약이 있으면 검토할 실용적 후보이지만, vanilla보다 성능이 유의하게 좋아졌다는 결과는 아닙니다. 논문도 이 구분을 유지하며 두 변형을 architecture 단순화 관점에서 매력적이라고 설명합니다.

## 26. fANOVA는 search 결과를 중요도 지도로 바꾼다

26. fANOVA는 search 결과를 중요도 지도로 바꾼다

발표 대본
fANOVA는 실험을 더 실행하는 알고리즘이 아니라 이미 수행한 random search를 분석합니다. 먼저 hyperparameter에서 test performance를 예측하는 regression forest 100개를 학습하고 예측을 평균합니다. 다른 차원을 평균내면 특정 parameter의 marginal effect를 얻을 수 있습니다. 이어서 예측 성능의 variance를 개별 parameter와 interaction 성분으로 나눕니다. 그러므로 중요도는 이 search space 안에서 모델이 설명한 성능 변동 비율이지 보편적 인과 계수가 아닙니다.

## 28. Parameter가 approximately independent라는 뜻

28. Parameter가 approximately independent라는 뜻

발표 대본
Figure 6 오른쪽은 개별 parameter 효과를 제거한 interaction residual입니다. 두 parameter가 완전히 독립이면 residual은 0이지만 실제 결과는 작으면서 뚜렷한 구조가 없었습니다. 가장 큰 측정 pair는 learning rate와 network size였지만 main learning-rate effect보다 작았습니다. 저자들은 실용적으로 learning rate를 작은 network에서 먼저 tuning할 수 있다고 제안합니다. 다만 IAM과 JSB의 좋은 learning-rate basin 상단이 탐색 범위 밖일 수 있다고 논문이 직접 경고합니다.

## 29. 논문에서 도출되는 조건부 tuning 순서

29. 논문에서 도출되는 조건부 tuning 순서

발표 대본
저자들은 learning rate의 좋은 basin이 넓기 때문에 높은 값에서 시작해 10으로 나누며 성능이 더 좋아지지 않을 때까지 coarse search할 수 있다고 설명합니다. Learning rate와 size interaction이 작아 작은 network에서 rate를 먼저 맞추고 큰 network로 옮길 수 있다고 제안합니다. 이후 size의 수익 감소와 training time을 보고, input noise는 dataset마다 효과가 달랐으므로 별도로 확인해야 합니다. 이 절차는 현대 optimizer 전체에 대한 규칙이 아닙니다.

## 30. 증거의 적용 범위

30. 증거의 적용 범위

발표 대본
5,400회는 당시 큰 실험이지만 비교 범위는 여전히 제한됩니다. 한 번에 한 변화만 검사했으므로 여러 개선을 동시에 결합한 cell은 다루지 않습니다. 세 dataset은 sequence domain을 넓히지만 언어나 비전, 매우 큰 규모를 포함하지 않습니다. Training은 full BPTT와 online SGD 중심이며 modern optimizer와 regularization을 비교하지 않습니다. Search prior와 200-trial budget도 결과의 일부입니다. 따라서 실용적 근거로 사용하되 timeless ranking으로 읽지 않습니다.

## 31. Odyssey에서 가져갈 네 가지

31. Odyssey에서 가져갈 네 가지

발표 대본
마지막으로 네 축을 연결하겠습니다. Vanilla state는 새 content와 유지 memory의 합이고 forget gate가 이전 state 경로를 조절합니다. 이 vanilla는 1997 original과 다릅니다. 실험은 architecture마다 별도 tuning을 수행해 비교 공정성을 높였습니다. 결과는 forget gate와 output activation의 중요성을 강하게 지지하지만 어떤 variant도 전반적 개선을 보이지 않았습니다. Hyperparameter 분석은 learning rate를 우선하라는 실용 지침을 주되 범위 밖 보편 법칙은 아닙니다.
