## 1. Dueling Network Architecture

1. Dueling Network Architecture

발표 대본
이 발표는 Dueling Network Architectures for Deep Reinforcement Learning 논문을 소개합니다. 논문이 묻는 질문은 한 상태에서 여러 행동의 결과가 비슷할 때에도 각 행동의 Q 값을 처음부터 따로 표현해야 하는가입니다. Dueling 구조는 공통 feature 뒤를 두 stream으로 나누지만, 최종 출력은 기존 Q network와 같은 행동별 Q 벡터입니다. 핵심은 두 stream을 만든 사실보다 두 출력을 어떤 제약으로 다시 합치는가에 있습니다.

## 2. Q network가 예측하는 값

2. Q network가 예측하는 값

발표 대본
먼저 예측 대상을 정의하겠습니다. 상태 s는 현재 관측을 나타내고 행동 a는 지금 선택할 수 있는 동작입니다. Q^pi(s,a)는 행동 a를 한 뒤 정책 pi를 따른다고 할 때 얻을 할인 return의 기댓값입니다. 즉시 보상 하나나 확정된 미래 결과가 아닙니다. 이산 행동 환경의 Q network는 한 상태를 입력받아 가능한 행동 수만큼 값을 출력합니다. Dueling도 이 입력과 출력 형식을 바꾸지 않습니다.

## 3. 정책의 가치와 advantage

3. 정책의 가치와 advantage

발표 대본
여기서는 참된 정책량을 정의합니다. V^pi(s)는 정책 pi가 행동을 고르는 분포로 Q^pi를 평균한 값입니다. A^pi(s,a)는 개별 행동의 Q 값에서 그 정책 가치를 뺀 차이입니다. 따라서 정책 pi로 행동을 평균하면 참된 advantage의 기댓값은 0입니다. 뒤에서 network가 출력하는 V와 A라는 이름은 이 정의를 반영하지만, 그 출력이 별도 supervision 없이 참된 V^pi와 A^pi로 자동 식별되는 것은 아닙니다.

## 4. 일반적인 Q network

4. 일반적인 Q network

발표 대본
일반적인 DQN 계열의 Q network를 보겠습니다. 입력 상태에서 convolution layer가 공통 feature를 추출하고, 상위 fully connected layer가 가능한 행동마다 하나의 Q 값을 냅니다. 모든 행동 값이 같은 feature를 사용하더라도 마지막 표현은 하나의 경로에서 직접 만들어집니다. Dueling 논문은 학습 목표나 Q 벡터의 용도를 먼저 바꾸지 않고 이 상위 표현 구조를 바꿉니다.

## 5. 비슷한 행동이 많은 상태

5. 비슷한 행동이 많은 상태

발표 대본
논문은 Enduro의 장면을 동기로 듭니다. 자동차가 즉시 피해야 할 장애물이 없는 상태에서는 여러 행동의 가치가 비슷할 수 있습니다. 장애물이 가까우면 행동 선택이 중요해집니다. saliency map은 value stream과 advantage stream이 서로 다른 영역에 반응하는 모습을 보여 주지만, 입력 gradient를 시각화한 해석 자료입니다. 이 그림만으로 모든 환경에서 stream이 참된 의미를 학습했다고 결론 내릴 수는 없습니다.

## 6. Dueling network의 분기와 결합

6. Dueling network의 분기와 결합

발표 대본
Dueling 구조의 실제 데이터 흐름입니다. 상태 s에서 얻은 공통 feature가 두 stream으로 갈라집니다. V stream은 scalar 하나를 내고 A stream은 행동 수만큼 raw score를 냅니다. 두 출력은 aggregation module 안에서 다시 합쳐져 최종 Q 벡터가 됩니다. 두 stream은 하위 feature와 최종 Q loss를 공유하므로 독립적으로 학습하는 두 개의 DQN이 아닙니다. 논문은 공통 파라미터를 theta, advantage stream을 alpha, value stream을 beta로 표기합니다.

## 7. Architecture와 학습 알고리즘의 구분

7. Architecture와 학습 알고리즘의 구분

발표 대본
세 방법을 같은 종류로 부르면 논문의 기여가 흐려집니다. Dueling은 Q 값을 표현하는 network architecture입니다. Double DQN은 bootstrap target에서 행동을 고르는 network와 그 행동을 평가하는 network snapshot의 역할을 나눕니다. Prioritized replay는 어떤 transition을 더 자주 학습할지 바꿉니다. 논문의 Atari dueling model은 DDQN으로 학습되며, 뒤에서는 prioritized replay와도 결합합니다. 호환된다는 사실이 세 방법의 작동 원리가 같다는 뜻은 아닙니다.

8. 단순 합산 Eq. (7)

9. Eq. (7)의 non-identifiability

## 10. Max-centered 대안 Eq. (8)

10. Max-centered 대안 Eq. (8)

발표 대본

## 11. Mean-centered aggregation Eq. (9)

11. Mean-centered aggregation Eq. (9)

발표 대본
Eq. (9)은 A stream의 raw 출력에서 그 상태의 행동 평균을 뺍니다. 이 centered advantage들의 합은 0입니다. 여기에 V scalar를 모든 행동에 더하면 최종 Q 벡터가 됩니다. 모든 A에서 같은 평균을 빼므로 행동 순서와 argmax는 그대로 유지됩니다. 이 연산은 network의 forward pass 안에 있는 aggregation이며, 학습이 끝난 뒤 별도로 수행하는 후처리 알고리즘이 아닙니다.

## 13. Eq. (9)이 보존하는 것

13. Eq. (9)이 보존하는 것

발표 대본
Mean centering으로 정확히 무엇이 성립하는지 정리하겠습니다. 모든 행동에 같은 평균을 빼므로 행동 간 차이와 순위는 보존됩니다. Centered A의 합은 0이고 Q 벡터의 단순 평균은 V scalar와 같습니다. 그러나 이 평균은 행동을 균등하게 평균한 network 출력입니다. 정책 pi의 행동 분포로 정의한 V^pi와 항상 같다고 말할 수 없습니다. 논문도 Eq. (9)이 V와 A의 원래 의미를 state-dependent constant만큼 이동시킨다고 설명합니다.

## 14. 기존 Q-learning 방식으로 학습

14. 기존 Q-learning 방식으로 학습

발표 대본
학습 과정에서 replay transition을 뽑고 DQN 또는 DDQN 방식으로 target을 만듭니다. 현재 network의 두 stream은 Eq. (9)에서 Q로 합쳐집니다. 선택한 행동의 Q와 target 사이 TD error를 계산하고 그 gradient가 aggregation을 거쳐 V stream, A stream, shared feature로 함께 흐릅니다. V나 A 각각에 정답 label을 주는 별도 supervision은 없습니다. 논문의 Atari dueling model은 이 구조를 DDQN 학습과 결합합니다.

## 21. Dueling architecture의 핵심

21. Dueling architecture의 핵심

발표 대본
전체 흐름을 정리하겠습니다. 문제는 여러 행동의 가치가 비슷한 상태에서도 Q network가 행동별 값을 모두 표현해야 한다는 점입니다. Dueling은 shared feature 위에서 상태 공통 scalar와 행동별 raw score를 나눕니다. 단순히 더하면 offset이 식별되지 않으므로 Eq. (9)에서 raw A의 평균을 빼고 V를 더합니다. 최종 Q 벡터는 기존 DQN이나 DDQN 방식으로 학습할 수 있습니다. Corridor와 Atari 결과는 이 구조의 동기와 실용성을 지지하지만 모든 환경에 대한 보편적 우세를 보장하지 않습니다.

## 22. 부록: Network parameter 표기

22. 부록: Network parameter 표기

발표 대본
기호를 다시 확인하겠습니다. theta는 두 stream이 공유하는 convolutional feature의 parameter입니다. beta는 value stream, alpha는 advantage stream의 parameter입니다. 최종 Q는 세 parameter 집합을 모두 거쳐 계산됩니다. TD loss의 gradient도 aggregation을 통해 세 집합으로 흐릅니다. 이런 구조 때문에 value network와 advantage network가 서로 독립된 두 Q learner라고 표현하면 정확하지 않습니다.

## 23. 부록: Dueling Double DQN의 한 update

23. 부록: Dueling Double DQN의 한 update

발표 대본
Dueling Double DQN이라는 이름을 한 update 안에서 풀어 보겠습니다. Online network와 target network 각각은 dueling architecture로 Q 벡터를 만듭니다. Double DQN target에서는 online Q가 다음 행동을 고르고 target Q가 그 행동의 값을 평가합니다. 현재 transition의 loss는 aggregated Q와 이 target의 차이로 계산됩니다. 따라서 dueling은 각 snapshot 내부의 representation이고 Double DQN은 두 snapshot을 target 계산에 배치하는 방식입니다.
