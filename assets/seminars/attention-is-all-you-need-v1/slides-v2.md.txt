근거: [arxiv-record](https://arxiv.org/abs/1706.03762) Submission history: v1 dated 12 Jun 2017, [arxiv-v1](https://arxiv.org/pdf/1706.03762v1) p. 1, version stamp and abstract

## 2. 같은 제목, 서로 다른 artifact

Revision date와 publication type을 먼저 적으면 수치 출처가 섞이지 않는다


| Artifact | Date | Source type | Lecture role |
| --- | --- | --- | --- |
| arXiv v1 | 2017-06-12 | Initial submission | 이 supplement |
| NeurIPS | 2017 | Proceedings record | 별도 artifact |
| arXiv v7 | 2023-08-02 | Final arXiv revision | Main mechanism |

핵심: Paper identifier가 같아도 revision과 proceedings는 동일한 text record가 아니다

근거: [arxiv-record](https://arxiv.org/abs/1706.03762) Submission history, [neurips](https://proceedings.neurips.cc/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html) Official proceedings abstract page

## 3. Backbone은 공유되지만 기록은 동일하지 않다

이 conceptual pipeline은 v1과 v7 모두에 있고 상세 공식은 main lecture의 v7을 따른다

- **Source encoder**: Source tokens + position → encoder ×6 → K,V
- **Shifted target**: Shifted target + position → masked self → Q
- **Cross-attention**: Decoder Q + encoder K,V
- **Decoder output**: FFN → next decoder layer; final softmax

근거: [arxiv-v1](https://arxiv.org/pdf/1706.03762v1) pp. 3-6, architecture and attention, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 3-6, canonical mechanism

## 4. 핵심 delta: multi-head 식의 W^O

v1 text와 v7 text에 실제로 적힌 식을 source-location별로 구분한다


| Source | Written formula | Observed difference |
| --- | --- | --- |
| v1 p. 4 | MultiHead = Concat(heads) | Final W^O가 식에 없음 |
| v7 p. 5 | MultiHead = Concat(heads) W^O | W^O와 shape가 명시됨 |
| Main lecture | v7 formula 사용 | 완전한 canonical mechanism |

핵심: v7 식을 v1 인용으로 가장하지 않고 formula source를 명시한다

근거: [arxiv-v1](https://arxiv.org/pdf/1706.03762v1) p. 4, multi-head equation and parameter list, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, multi-head equation and W^O shape

## 5. W^O는 concatenated head features를 혼합한다

두 head만 대표로 표시하며 실제 base configuration은 h=8이다

- **Projected Q,K,V**: Head별 learned subspace inputs
- **Head 1 output**: d_v-dimensional vector
- **Head 2 output**: d_v-dimensional vector
- **Concat**: 모든 head vector를 길게 연결
- **Multiply by W^O**: hd_v → d_model 선형 변환

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, W^O in Sec. 3.2.2, [arxiv-v1](https://arxiv.org/pdf/1706.03762v1) p. 4, earlier displayed equation

| Source location | d_model | d_ff | Reading |

| v7 p. 5 prose | 512 | 2048 | 본문 dimension |

핵심: v1 source contains conflicting values; author intent는 추가 근거 없이 진단하지 않는다

근거: [arxiv-v1](https://arxiv.org/pdf/1706.03762v1) p. 5, Sec. 3.3; p. 8, Table 3 base row, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, Sec. 3.3; p. 8, Table 3 base row

## 8. v1을 보존하며 정확하게 읽는 법

공통 architecture는 main lecture로 돌아가고 version-specific claim만 이 자료에서 확정한다


| Question | Safe answer |
| --- | --- |
| v1 전체가 틀렸나? | 아니다. 공통 Transformer backbone이 있다 |
| W^O는 어디서 가르치나? | v7 p. 5의 explicit equation |
| Base d_ff는 얼마인가? | v1 내부 conflict; v7 기준 2048 |
| EN-FR score는 하나인가? | Artifact와 location별로 다르다 |
| Attention cost는 linear인가? | 두 판본 모두 full attention O(n^2 d) |

핵심: 판본 차이는 원문을 버릴 이유가 아니라 citation precision을 높일 근거다
