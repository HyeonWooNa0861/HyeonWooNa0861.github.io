## 5. W^O는 concatenated head features를 혼합한다

5. W^O는 concatenated head features를 혼합한다

발표 대본
W^O는 각 head의 output을 concatenate한 vector에 적용되는 learned linear projection입니다. Head features를 최종 model-width representation으로 섞습니다. 새로운 attention score를 계산하거나 softmax를 한 번 더 수행하는 block이 아닙니다. 이 mechanism의 명시적 공식 source는 v7입니다. 작은 attention arithmetic은 W^O correction의 성능 효과를 증명하지 않습니다.

## 6. v1 내부에도 d_ff 값 충돌이 있다

6. v1 내부에도 d_ff 값 충돌이 있다

## 8. v1을 보존하며 정확하게 읽는 법

8. v1을 보존하며 정확하게 읽는 법

발표 대본
v1을 obsolete라며 삭제하거나 전체가 틀렸다고 말하지 않습니다. Shared architecture는 main v7 lecture에서 학습하고, 이 supplement는 W^O equation, d_ff table conflict, BLEU source differences를 정확히 표시합니다. 두 판본 모두 attention-only가 FFN과 residual까지 없다는 뜻이 아니며 full attention은 O(n squared d)입니다. Code release wording도 v1과 v7에서 다르므로 현재 maintenance status로 일반화하지 않습니다.
