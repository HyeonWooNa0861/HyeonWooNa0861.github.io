# Safe Reinforcement Learning의 지도

논문: A Comprehensive Survey on Safe Reinforcement Learning

저자: Javier García, Fernando Fernández (2015)

## 1. Safe Reinforcement Learning의 지도

기대 보상, 위험 기준, 탐색 제어를 구분해 읽는 2015년 JMLR survey


근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) title page, abstract

## 2. 이 survey가 말하는 Safe RL

학습 또는 배포 중 성능과 안전 제약이 중요한 문제에서 정책을 배우는 방법의 분류

- 목표는 기대 return을 크게 하는 정책 학습이다.
- 안전은 물리적 손상 회피만 뜻하지 않는다.
- 희귀한 큰 손실, 불확실성, error state도 risk가 될 수 있다.
- 저자들의 핵심 기여는 방법들의 taxonomy와 비교 기준이다.

핵심: 이 논문은 단일한 안전 보장을 제안하기보다 서로 다른 risk 개념을 정리한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1437-1439, abstract and §1

## 3. 기대 return만으로는 보이지 않는 것

risk-neutral RL은 평균을 최적화하지만 return 분포의 다른 성질을 무시한다


| 기준 | 주로 보는 값 | 위험을 읽는 관점 |
| --- | --- | --- |
| risk-neutral | Eπ[R] | 분산과 희귀한 큰 손실을 놓칠 수 있음 |
| worst-case | 가장 나쁜 return | 드물어도 치명적인 결과까지 고려 |
| risk-sensitive | return과 risk의 조합 | 선호하는 risk 수준 |
| constrained | return과 제약 | 허용 한도를 넘는 비용 |

핵심: 같은 평균 보상이라도 손실의 크기와 발생 방식은 다를 수 있다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1439-1444, §2 and §3

## 4. 교육용 예시: 평균과 최악 결과

같은 상태에서 기준을 바꾸면 선호 행동도 달라질 수 있다


| 행동 | return 분포 | 기대 return | 최악 return |
| --- | --- | --- | --- |
| Safe | 항상 5 | 5 | 5 |
| Risky | 90%: 9, 10%: -20 | 0.9×9 + 0.1×(-20) = 6.1 | -20 |

핵심: 기대 return 기준은 Risky를, worst-case 기준은 Safe를 고른다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1443-1445, §3.1

## 5. 학습 중 위험과 배포 후 위험

같은 방법도 어느 시점의 위험을 줄이는지에 따라 해석이 달라진다


| 질문 | 학습 과정 | 배포된 정책 |
| --- | --- | --- |
| 주된 걱정 | 탐색 행동이 손상이나 error를 일으킴 | 최종 정책이 불리한 결과를 선택함 |
| 대표 개입 | demonstration, teacher advice, risk-directed exploration | worst-case, risk-sensitive, constrained criterion |
| 주의점 | 안전한 탐색이 최종 최적성을 자동 보장하지 않음 | 좋은 최종 정책이 안전한 학습 과정을 보장하지 않음 |

핵심: 안전한 학습 경로와 위험을 고려한 최종 정책은 구별해야 한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1437-1442, §§1-2

## 6. 두 개입 지점

survey는 안전을 반영하는 위치에 따라 literature를 정리한다

- **risk가 중요한 RL task**: 기대 return만으로 충분한가
- **목적함수 수정**: 무엇을 최적이라고 부를지 변경
- **탐색 과정 수정**: 무엇을 시도할지 변경
- **정책 행동**: risk를 반영한 선택
- **Safe RL 분류**: 방법의 가정과 효과를 비교

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1439-1442, §2 and Table 1

## 7. 목적함수 수정의 네 갈래

평균 return 이외의 기준을 최적화 문제에 넣는다


| 갈래 | 목적에 추가하는 것 | source의 예 |
| --- | --- | --- |
| worst-case | 최악 return | inherent 또는 parameter uncertainty |
| risk-sensitive | utility 또는 risk 항 | 지수 utility, variance, error 확률 |
| constrained | 기대 측도의 경계 | cost 또는 error 제약 |
| other criteria | 특수한 분포 기준 | VaR, R-squared, return density |

핵심: 각 갈래는 risk를 측정하는 방식과 필요한 가정이 다르다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1440-1442, §2 and Table 1

## 8. worst-case와 두 종류의 불확실성

나쁜 결과의 원인을 구분해야 worst-case 기준의 의미가 선명해진다

- **worst-case criterion**: 최소 return을 크게 하는 정책
- **inherent uncertainty**: 확률적 환경에서 결과가 달라짐
- **parameter uncertainty**: MDP parameter를 정확히 모름
- **보수적 평가**: 불리한 경우를 기준에 반영
- **정책 선택**: 가정한 uncertainty 모델에 의존

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1443-1445, §§3.1.1-3.1.2

## 9. 지수 utility 기반 risk sensitivity

return을 utility로 변환해 큰 손실과 변동성에 대한 민감도를 조절한다

- 정책 평가는 raw return 대신 exponential utility를 사용한다.
- risk sensitivity parameter가 위험 회피 또는 선호의 정도를 정한다.
- parameter 선택은 application의 의사결정 선호를 반영해야 한다.
- 이 기준은 위험의 정의를 자동으로 발견하지 않는다.

핵심: utility 함수의 모양은 평균 return 이외에 무엇을 벌점으로 볼지 정한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1445-1447, §3.2.1

## 10. return과 risk의 가중 결합

기대 return에 risk measure의 벌점을 결합하는 방식


| risk measure | 무엇을 줄이려는가 | 해석 시 조건 |
| --- | --- | --- |
| return variance | return의 변동 폭 | 위험을 variance로 보는 가정 |
| error-state probability | error state에 들어갈 가능성 | error state 정의와 확률 추정 |
| 가중 계수 | return과 risk의 trade-off | 계수 선택이 정책을 바꿈 |

핵심: 가중 결합은 risk 정의와 weight를 함께 정해야 의미가 있다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1447-1449, §3.2.2

## 11. constrained criterion

return을 키우되 별도의 기대 측도를 허용 범위 안에 둔다

1. **정책 후보**: return과 cost를 함께 예측
2. **제약 확인**: 기대 측도가 bound를 만족하는가
3. **feasible 정책**: 제약을 만족한 후보만 남김
4. **return 최대화**: 남은 후보 중 목적을 최적화

핵심: 제약의 의미는 어떤 측정값에 어떤 bound를 두는지로 결정된다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1449-1450, §3.3

## 12. 기타 목적함수 기준

survey는 금융·분포 관점의 기준도 별도 갈래로 남긴다

- r-squared와 VaR 등 금융 risk metric도 다룬다.
- 각 metric의 상세 정의와 가정은 원 논문에서 확인해야 한다.
- return density 추정은 return 분포 자체를 모델링한다.
- 서로 다른 기준은 같은 안전 뜻이나 같은 보장을 공유하지 않는다.

핵심: risk의 수학적 표현을 바꾸면 정책 비교의 의미도 바뀐다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1450-1451, §3.4

## 13. 탐색 과정 수정의 두 갈래

고전적 return 목적을 유지하면서 위험한 trial을 덜 하도록 행동 선택을 바꾼다


| 갈래 | 개입 수단 | 학습 초기에 바꾸는 것 |
| --- | --- | --- |
| external knowledge | 초기 지식, demonstration, teacher advice | 탐색의 출발점이나 행동 후보 |
| risk-directed exploration | risk metric | 행동을 선택할 확률 |

핵심: 탐색 수정은 ‘무엇이 최적인가’보다 ‘무엇을 먼저 해 볼 것인가’에 초점을 둔다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1440-1442 and 1452, §§2 and 4

## 14. 초기 지식으로 탐색을 시작하는 방식

teacher example 또는 과거 정보로 초기 policy와 value를 bootstrap한다

1. **사전 정보**: example 또는 task 지식
2. **초기화**: value, policy, case에 반영
3. **초기 탐색**: relevant region을 먼저 시도
4. **후속 학습**: 관측으로 policy를 계속 갱신

핵심: 초기 지식은 blind random exploration을 줄일 수 있지만 그 품질에 의존한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1452-1454, §4.1.1

## 15. 유한 demonstration에서 정책을 얻는 방식

온라인 무작위 시도 대신 teacher가 준 example으로 offline policy를 학습한다

1. **teacher demonstrations**: 유한한 state-action example
2. **offline 학습**: example으로 model 또는 policy를 유도
3. **정책 도출**: offline model에서 policy를 얻음
4. **배포 또는 추가 학습**: 새 상황의 일반화는 별도 문제

핵심: demonstration은 탐색 데이터를 대체하지만 coverage와 teacher 품질이 중요하다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1454-1455, §4.1.2

## 16. teacher advice의 시작 주체

advice는 누가 언제 상호작용을 시작하는지에 따라 세 갈래로 정리된다


| 형태 | 상호작용 시작 | 의미 |
| --- | --- | --- |
| learner asks | learner가 필요할 때 요청 | 불확실하거나 위험하다고 판단한 순간의 도움 |
| teacher gives | teacher가 먼저 개입 | teacher가 필요하다고 판단할 때 행동 또는 정보 제공 |
| other interaction | 주체가 혼합되거나 불명확 | 여러 teacher-learner 구조 |

핵심: advice의 안전 효과는 teacher의 정보와 개입 규칙에 달려 있다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1455-1460, §§4.1.3.1-4.1.3.3

## 17. risk-directed exploration

최종 목적은 유지하고 exploration action의 선택 확률에 risk를 반영한다

1. **현재 state**: 가능한 action과 관측 정보
2. **risk measure**: action별 위험 신호를 추정
3. **탐색 확률**: 위험을 고려해 action probability 조정
4. **경험 수집**: 고전적 return 목적 아래 policy 갱신

핵심: risk-directed exploration은 risk를 action selection에 쓰되 고전적 목적을 유지한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1460-1461, §4.2

## 18. 목적함수 수정과 탐색 수정의 비교

두 흐름은 바꾸는 대상과 주장할 수 있는 범위가 다르다


| 질문 | 목적함수 수정 | 탐색 과정 수정 |
| --- | --- | --- |
| 주로 바꾸는 것 | 정책을 평가하는 criterion | 학습 중 action 선택 방식 |
| 필요한 선택 | risk definition과 trade-off | prior knowledge 또는 risk signal |
| 주요 위험 | 잘못된 risk metric과 weight | 부정확한 advice와 부족한 coverage |
| 학습 중 안전 | 별도 탐색 설계 없이는 불명확 | 위험 trial 감소를 겨냥 |

핵심: 어느 흐름을 택할지는 위험의 정의와 사용할 수 있는 정보에 달려 있다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1439-1442, 1452-1461, §§2-4

## 19. 방법을 비교하는 네 차원

Section 5는 방법을 하나의 점수로 줄이지 않고 특성을 나란히 본다


| 차원 | 확인할 질문 | 예시 |
| --- | --- | --- |
| allowed learner | 어떤 RL learner와 결합 가능한가 | model-free 또는 특정 구조 |
| spaces | 어떤 state/action-space 규모·형태의 domain에서 적용됐는가 | S/a: large/continuous state, small/discrete action |
| risk | 무엇을 위험으로 측정하는가 | variance, error probability, constraint |
| exploration | 위험을 언제 어떻게 줄이는가 | prior knowledge, advice, action probability |

핵심: 같은 ‘safe’라는 이름보다 risk 표현과 적용된 state/action domain을 먼저 비교해야 한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1462-1466, §5.1 and Tables 2-3

## 20. 열린 설계 질문

survey는 안전을 위한 단일 default를 제시하지 않고 선택해야 할 문제를 남긴다


| 질문 | 왜 필요한가 | 발표에서 확인할 말 |
| --- | --- | --- |
| risk metric | 위험 정의가 행동 선택을 바꿈 | 무엇을 unacceptable로 보는가 |
| optimum criterion | 평균과 risk의 trade-off가 필요 | 최적의 의미는 무엇인가 |
| risk detection | 위험 신호가 부정확할 수 있음 | 어떻게 위험을 알아내는가 |
| learning schema | prior knowledge와 learner 구조가 다름 | 어떤 정보가 주어지는가 |
| exploration strategy | 초기 trial 자체가 비용일 수 있음 | 언제 intervention하는가 |

핵심: Safe RL의 선택은 알고리즘 이름보다 위험 정의와 정보 가정에서 시작한다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1466-1470, §§5.2.1-5.2.5

## 21. 2015년 survey의 역사적 범위

논문은 당시 literature의 taxonomy이며 이후 방법의 포괄적 성능 판정이 아니다

- source는 2015년에 출판된 JMLR survey다.
- 대표 citation들은 공통 benchmark의 직접 비교 결과가 아니다.
- 각 branch의 guarantee는 원 논문별 가정과 risk 정의에 달려 있다.
- 현대 deep RL이나 최신 safe RL 결과는 별도 source가 필요하다.

핵심: taxonomy는 출발점이며 최신 성능이나 보장의 대체 근거가 아니다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1437-1439 and 1470-1471, §§1 and 6

## 22. Safe RL 논문을 읽는 순서

안전이라는 말보다 먼저 위험의 정의와 개입 위치를 확인한다

1. **위험 정의**: 손실, uncertainty, error, constraint 중 무엇인가
2. **개입 위치**: 목적함수 또는 탐색 과정
3. **가정 확인**: model, prior knowledge, risk estimate
4. **증거 해석**: 학습 중 위험, 배포 성능, 보장 범위를 분리

핵심: Safe RL은 하나의 기법 이름이 아니라 위험을 정책 학습에 넣는 설계 공간이다

근거: [jmlr](https://www.jmlr.org/papers/v16/garcia15a.html) pp. 1439-1442 and 1470-1471, §§2 and 6
