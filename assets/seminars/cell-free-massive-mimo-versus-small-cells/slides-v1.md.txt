# 셀프리 Massive MIMO는 왜 small cell과 다른가

논문: Cell-Free Massive MIMO versus Small Cells

저자: Hien Quoc Ngo, Alexei Ashikhmin, Hong Yang, Erik G. Larsson, Thomas L. Marzetta (2017)

## 1. 셀프리 Massive MIMO는 왜 small cell과 다른가

분산 AP의 공동 서비스, pilot, 공정성 제어를 원문 조건과 함께 읽기


근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 1, title and abstract, [ieee-doi](https://doi.org/10.1109/TWC.2017.2655515) publication record

## 2. 이 덱에서 지키는 읽기 경계

원문은 분석 모델과 수치 실험을 제시한다. 현장 배포 성능 보증을 직접 제시하지는 않는다.


| 구분 | 원문이 하는 일 | 읽을 때의 경계 |
| --- | --- | --- |
| 협력 구조 | 모든 AP가 모든 user를 서비스 | ideal backhaul 가정의 모델 |
| 수학 | large-M 분석과 finite-M lower bound | 현장 측정값 자체가 아님 |
| 비교 | 동일 총 방사전력의 simulator | 표의 조건을 유지해 해석 |
| 실용성 | small cell backhaul이 더 작음 | 구현비용을 성능표에서 숨기지 않음 |

핵심: ‘셀프리의 우세’는 이 논문의 모델과 비교 조건 안에서만 정확한 문장이다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 3, 5-6, 10, 14-15

## 3. 출발점: 약한 user의 rate를 어떻게 끌어올릴까

한 AP에만 의존하면 shadowing이 나쁜 user가 남는다. 논문은 AP 협력과 max-min 제어를 함께 묻는다.

1. **분산 AP**: 가까운 AP가 user마다 다르다
2. **한 AP 서비스**: 약한 link가 bottleneck이 된다
3. **공동 서비스**: 여러 AP가 같은 data를 보낸다
4. **max-min 제어**: 가장 낮은 modeled rate를 높인다

핵심: 문제는 AP를 많이 두는 것보다, 협력과 제한된 전력을 누구에게 어떻게 배분하느냐이다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 1-2, abstract and contributions

## 4. 두 구조의 핵심 차이: 누가 한 user를 서비스하는가

둘 다 AP와 user가 분산되어 있어도, 서비스 관계와 필요한 협력이 다르다.


| 항목 | cell-free 모델 | small-cell baseline |
| --- | --- | --- |
| 서비스 | 모든 M AP가 모든 K user를 함께 서비스 | 각 user는 한 available AP에 연결 |
| DL | AP들의 coherent conjugate beamforming | 선택된 한 AP의 전송 |
| UL | AP local filter 뒤 CPU가 결과를 합산 | 선택 AP가 user 신호를 처리 |
| 연결 선택 | joint service가 기본 | 큰 beta를 가진 available AP를 선택 |
| 실용 경계 | 큰 backhaul·동기화 가정 | 더 적은 backhaul |

핵심: 셀프리는 AP를 공동 사용하고, 이 baseline은 AP를 user별로 나눈다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 3, 8-9

## 5. 원문의 실제 정보 흐름: local CSI, CPU aggregation

AP가 instant CSI를 local로 쓰고, CPU는 UL 처리 결과와 slow control을 다룬다는 분업이다.

- **레인 UL**
- **레인 DL**
  - **user**: pilot·payload
  - **AP local**: estimate·MF
  - **CPU**: processed sum
  - **UL data**: decoded output
  - **CPU**: payload·power
  - **AP local**: conjugate
  - **user**: effective gain
  - **decode**: channel stats
- user → AP local (실선, 단방향)
- AP local → CPU (실선, 단방향)
- CPU → UL data (실선, 단방향)
- CPU → AP local (실선, 단방향)
- AP local → user (실선, 단방향)
- user → decode (실선, 단방향)

핵심: CPU는 all CSI 저장소가 아니라 UL 합산과 power 조정 역할을 맡는다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 3-4, System Model and Eqs. (10), (18)

## 6. 한 coherence interval의 TDD 순서

CSI는 DL에 앞서 UL pilot에서 얻는다. 세 구간의 길이 배분이 payload와 pilot 품질을 함께 제한한다.

1. **UL training**: 동시 pilot으로 local CSI 추정
2. **DL payload**: local conjugate transmission
3. **UL payload**: local filter 뒤 CPU sum

핵심: 더 긴 pilot은 estimation을 돕지만, 같은 coherence block 안의 payload 자리를 줄인다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 3, TDD protocol and assumptions

## 7. 채널의 두 층: 빠르게 변하는 h와 느린 beta

원문은 g_mk를 sqrt(beta_mk)와 h_mk의 곱으로 나눈다. 두 층을 섞으면 pilot·power 설명이 흐려진다.


| 기호 | 뜻 | 변화 속도 | 논문에서의 역할 |
| --- | --- | --- | --- |
| g_mk | AP m과 user k의 전체 채널 | 두 성분을 함께 포함 | signal processing 대상 |
| h_mk | small-scale fading | 빠름 | Rayleigh 분석 가정 |
| beta_mk | path loss와 shadow fading | 느림 | pilot·power control의 입력 |
| gamma_mk | estimate quality 계수 | pilot과 beta에 의존 | AP power constraint에 등장 |

핵심: greedy pilot assignment는 빠른 h가 아니라 slow beta를 이용해 동작한다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 3-4, Eqs. (1), (8)-(9)

## 8. pilot contamination은 왜 생기는가

training symbol이 user 수보다 부족하면 모든 user에게 직교 pilot을 줄 수 없다.

1. **K users**: 각자 unit-norm pilot을 보낸다
2. **짧은 training**: tau_cf가 K보다 작다
3. **pilot overlap**: inner product가 0이 아닐 수 있다
4. **estimate 혼합**: 다른 user 항이 남는다

핵심: pilot overlap이 있으면 다른 user training 항이 estimate에 섞인다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 3-4, Eqs. (2)-(9)

## 9. 강의용 pilot 계산: 직교와 overlap의 차이

가상의 길이 2 pilot 예시다. 원문 실험의 user 수나 rate를 재현한 값이 아니다.


| case | user 1 pilot | user 2 pilot | inner product | estimate 해석 |
| --- | --- | --- | --- | --- |
| 직교 | [1, 0] | [0, 1] | 0 | 서로의 projected term이 사라짐 |
| 같은 pilot | [1, 0] | [1, 0] | 1 | 다른 user term이 최대 겹침 |
| 부분 overlap | [1, 0] | [0.6, 0.8] | 0.6 | cross term이 남음 |

핵심: inner product가 작을수록 이 source model에서 training 혼합 항도 작아진다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 4, Eqs. (6)-(9); constructed example

## 10. DL: local conjugate beamforming과 AP별 전력 제한

각 AP는 모든 user의 data를 local estimate에 맞춰 더하지만, AP마다 쓸 수 있는 weighted power가 제한된다.

1. **local estimate**: AP m이 user별 estimate를 가진다
2. **weighted sum**: 각 user data에 eta를 곱한다
3. **conjugate**: local estimate의 conjugate를 쓴다
4. **AP budget**: sum eta gamma는 1 이하

핵심: AP budget 때문에 모든 user coefficient를 함께 키울 수는 없다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 4, Eq. (5) and constraints (6)-(8)

## 11. UL: local matched filtering 뒤 CPU sum

AP들은 user 신호를 local estimate로 filter하고, CPU는 그 processed contribution을 더한다.

1. **UL receive**: AP가 모든 user signal을 받는다
2. **local MF**: estimate로 원하는 user를 filter
3. **processed term**: AP가 scalar result를 CPU로 보낸다
4. **CPU sum**: AP contribution을 합쳐 detect

핵심: 원문의 분산성은 CSI를 중앙에 모두 보내지 않고 local processing을 먼저 한다는 데 있다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 4, Eqs. (10)-(11)

## 12. channel hardening과 favorable propagation은 다르다

둘 다 AP 수가 커질 때 유용하지만, 하나는 gain의 안정성이고 다른 하나는 user 간 분리다.


| 개념 | 무엇이 좋아지는가 | 사용자 관점 | 원문에서의 경계 |
| --- | --- | --- | --- |
| channel hardening | effective gain이 덜 흔들림 | instantaneous gain 대신 통계를 쓸 여지 | Fig. 2의 특정 조건에서 비교 |
| favorable propagation | 서로 다른 channel vector가 분리 | 다른 user 간 간섭 해석에 도움 | large-M 분석의 조건부 성질 |
| pilot contamination | training 혼합 항이 남음 | pilot을 공유한 user 구분이 어려움 | large-M에서도 남는 항 |

핵심: hardening과 propagation을 같은 말로 부르면, 무엇이 남고 무엇이 사라지는지 설명할 수 없다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 5-6, Eqs. (14)-(18), Fig. 2, Remarks 3-5

## 13. large-M 분석과 finite-M rate를 과장하지 않기

두 식은 설계를 이해시키지만, 서로 다른 주장 강도를 가진다.


| 구분 | 원문이 보이는 것 | 남는 것 또는 조건 | 말하면 안 되는 것 |
| --- | --- | --- | --- |
| large-M | noise·small-scale·noncoherent 항 소거 | pilot contamination은 남음 | 유한 망의 무조건 보장 |
| finite-M DL | achievable lower bound | user의 decoding knowledge 조건 | 정확한 측정 throughput |
| finite-M UL | achievable lower bound | estimate와 interference 조건 | 모든 환경의 capacity |

핵심: 논문의 수식은 ‘모델 아래 가능한 rate’를 설명하며, 배포 현장의 자동 성능보증은 아니다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 5-6, Eqs. (14)-(18), Theorems 1-2, Eqs. (24),(27)

## 14. greedy pilot assignment: 누구의 pilot을 바꾸는가

instantaneous CSI를 다시 찾지 않는다. slow beta와 pilot overlap으로 가장 약한 DL user를 반복적으로 돕는다.

1. **초기화**: random pilot assignment를 둔다
2. **bottleneck**: 가장 낮은 DL rate user를 찾는다
3. **candidate score**: AP·user별 beta와 overlap을 합친다
4. **replace**: 최소 score pilot으로 바꾼다
5. **repeat N**: 정한 update 횟수까지 반복

핵심: greedy pilot 제어는 bottleneck user를 순차로 개선한다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 7, Algorithm 1 and Eqs. (29)-(31)

## 15. max-min power control: 평균이 아니라 bottleneck rate

목표는 가장 낮은 modeled user rate를 가능한 한 높이는 것이다. 이것은 sum-rate 최대화와 다른 질문이다.


| 대상 | 결정변수 | 목표 | 핵심 제약 |
| --- | --- | --- | --- |
| DL | AP-user coefficient eta_mk | min DL rate 최대화 | 각 AP의 weighted power |
| UL | user power coefficient eta_k | min UL rate 최대화 | 0부터 1까지의 user power |
| 공통 | target rate를 시험 | bottleneck을 균등화 | feasible 여부를 먼저 검사 |

핵심: weak user를 올리는 설계이므로, median이나 평균 rate의 변화는 별도로 확인해야 한다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 7-8, Eqs. (32)-(37), Propositions 1-2

## 16. DL·UL max-min의 다른 feasibility 형태

두 경우 모두 bisection으로 common rate를 시험하지만, 제약의 형태가 다르다.

- **target rate**: bisection으로 시험
- **DL**: SOCP feasibility
- **UL**: LP feasibility
- **feasible?**: yes면 rate를 올림
- **max-min rate**: 모델 제약 안의 해

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 7-8, Algorithm 2, Eqs. (34)-(35); Proposition 2, Eq. (37)

## 17. 강의용 2 AP·2 user toy: service와 feasibility

가상 beta·gamma 값이다. 원문의 complete rate bound나 실험 수치를 재현하지 않는다.


| 단계 | cell-free | small-cell baseline | 계산 결과 |
| --- | --- | --- | --- |
| beta | AP1: 0.9, 0.4 / AP2: 0.6, 0.7 | user 1부터 선택 | user 1은 AP1 선택 |
| available AP | 두 AP가 두 user에 모두 참여 | AP1은 user 2에 unavailable | user 2는 AP2 선택 |
| gamma | AP1: 0.6, 0.2 / AP2: 0.4, 0.5 | 해당 없음 | eta=1일 때 AP1=0.8, AP2=0.9 |
| 해석 | 두 AP budget 모두 1 이하 | AP는 user 사이에 나뉨 | rate ratio는 이 표에서 계산하지 않음 |

핵심: toy는 joint service와 AP budget만 보이며 rate 배율은 주장하지 않는다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 4, 8-9; constructed example

## 18. small cell도 같은 방식으로 DL CSI를 쓰지 않는다

셀프리에서는 hardening을 이용해 statistics decoding을 검토하지만, 단일 AP link에는 그 이득이 약하다.


| 항목 | cell-free 원문 모델 | small-cell baseline |
| --- | --- | --- |
| effective channel | 여러 AP contribution의 합 | 한 AP의 Rayleigh channel |
| DL knowledge | 통계에 의존한 lower bound를 분석 | user가 effective channel을 추정 |
| training | UL training 길이 tau_cf | UL·DL training을 모두 고려 |
| 서비스 | AP들이 coherent하게 공동 전송 | 한 serving AP가 전송 |

핵심: training overhead와 channel knowledge도 throughput 비교에 반영된다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 5-6, 8-10

## 20. 조건부 DL 결과: 95%-likely net throughput

M=100, K=40, training length 20; 단위는 Mbit/s. 높을수록 95% user가 넘는 rate가 높다.


| 방법 | CF uncor. | SC uncor. | CF corr. | SC corr. |
| --- | --- | --- | --- | --- |
| greedy + PC | 14.00 | 2.08 | 8.12 | 0.83 |
| random + PC | 12.70 | 1.37 | 6.95 | 0.54 |
| greedy, no PC | 5.46 | 0.86 | 1.58 | 0.24 |

핵심: 이 setting에서 joint service와 max-min은 weak-user DL percentile을 높인다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 15, Table II; pp. 10-13 conditions

## 21. 조건부 UL 결과: 95%-likely net throughput

| 방법 | CF uncor. | SC uncor. | CF corr. | SC corr. |

| random + PC | 5.54 | 1.27 | 2.26 | 0.26 |

## 22. pilot과 power control은 어떤 차이를 만들었나

원문 Fig. 3–9와 Tables II–III는 두 제어가 모두 weak-user percentile에 영향을 줌을 보인다.

## 23. 공동 service가 동일 전력을 뜻하지는 않는다

원문의 max-min solution에서는 user의 allocated power 중 대부분이 일부 AP에서 올 수 있다.

- Fig. 9는 user power의 95% 이상을 보내는 effective AP 수를 센다.
- M=100에서도 user당 약 10–20 effective AP가 관찰되는 조건이 있다.
- 나머지 AP의 contribution이 0이라는 일반 명제는 아니다.
- 이 수는 M, K, pilot length와 source power-control solution에 의존한다.

핵심: 공동 서비스에서도 AP contribution은 제어되어 비대칭일 수 있다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) p. 12, Fig. 9 and discussion

## 24. 왜 correlated shadowing이 비교를 더 어렵게 만드는가

동일한 장애물이 가까운 link들을 함께 약화시키면, 독립 shadowing보다 위치 다양성 이득이 달라진다.


| 조건 | 모델상 의미 | Table II DL | Table III UL |
| --- | --- | --- | --- |
| uncorrelated | link shadowing을 독립으로 둠 | CF 14.00 / SC 2.08 | CF 6.29 / SC 2.04 |
| correlated | AP와 user 위치의 shadow correlation | CF 8.12 / SC 0.83 | CF 3.55 / SC 0.31 |
| 읽기 | greedy + PC row | 95%-likely net rate | 95%-likely net rate |

핵심: 상관 shadowing에서도 percentile 차이는 남지만 절대 rate는 모델에 민감하다

근거: [arxiv-v2](https://arxiv.org/pdf/1602.08232v2) pp. 10, 12-15, shadow model and Tables II-III

## 25. 성능표 밖에서 반드시 함께 말할 가정

공동 transmission을 가능하게 하는 요소는 rate 식 밖의 시스템 요구사항이기도 하다.


| 가정 또는 제약 | 왜 필요한가 | 실용적 경계 |
| --- | --- | --- |
| perfect backhaul | CPU와 AP 사이 payload·control | transport 비용 미반영 |

## 26. 한 문장씩 정리하면

셀프리 Massive MIMO의 핵심은 ‘더 많은 AP’가 아니라, distributed local processing과 coherent joint service의 결합이다.

- AP는 UL pilot으로 local CSI를 얻고 local processing을 수행한다.
- pilot overlap은 estimate에 섞이며 greedy는 bottleneck을 보완한다.
- max-min power control은 weakest modeled rate를 높인다.
- Table II–III 차이는 정해진 simulation 조건의 evidence다.
- 배포 판단에는 backhaul·sync·calibration 검증이 더 필요하다.

핵심: architecture·algorithm·가정을 함께 볼 때 비교 결과를 정확히 설명할 수 있다
