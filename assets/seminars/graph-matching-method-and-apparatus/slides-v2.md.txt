# 그래프 매칭의 대칭과 중복 제거

논문: 그래프 매칭 방법 및 장치 (KR101747854B1)

저자: 서동민, 유석종, 이민호, 강유, 박하명 · 한국과학기술정보연구원 (2017)

## 1. 그래프 매칭의 대칭과 중복 제거

정점 번호와 질의 대칭으로 같은 패턴의 표현을 하나만 남기는 방법


근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 1–23; KR101747854B1

## 2. 같은 구조를 다른 순서로 찾는 일이 반복된다

네 정점의 사이클은 시작점과 방향만 바꿔도 여러 매핑으로 표현된다


| 구분 | 예 | 줄이려는 대상 |
| --- | --- | --- |
| 데이터 그래프 | 검색할 전체 연결 구조 | 패턴이 존재하는 위치 |
| 질의 그래프 | 찾을 C4 패턴 | 매칭의 모양과 조건 |
| 서로 다른 매핑 | 같은 구조에 다른 정점 대응 | 대칭에 따른 중복 표현 |
| 특허의 접근 | 번호·대칭 제약 | 탐색 중 불필요한 분기 |

핵심: 데이터를 지우는 것이 아니라 같은 패턴의 여러 표현 중 대표를 선택한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 4–6, [0002]–[0022], Fig. 3

## 3. 무엇을 같은 결과라고 부르는가

매핑, 간선 패턴, 정점 집합은 일반적으로 서로 다른 출력이다


| 출력 단위 | 같다고 판단하는 기준 | 주의할 점 |
| --- | --- | --- |
| 매핑 f | p·q·r·s의 대응이 모두 같음 | 대칭 대응도 별도 출력 |
| 패턴의 간선상 | 질의의 간선들이 같은 곳에 대응 | 이 설명의 중복 제거 단위 |
| 정점 집합 | 선택된 데이터 정점들만 같음 | 다른 연결 패턴까지 합칠 수 있음 |

핵심: 이 자료는 대칭으로만 다른 매핑을 하나로 줄이는 경우를 설명한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 4–5, Fig. 3; interpretation

## 4. 질의 그래프를 먼저 고정한다

C4의 연결: p—q—s—r—p; 표에서 1은 간선이 있음을 뜻한다


| 정점 | p | q | r | s |
| --- | --- | --- | --- | --- |
| p | 0 | 1 | 1 | 0 |
| q | 1 | 0 | 0 | 1 |
| r | 1 | 0 | 0 | 1 |
| s | 0 | 1 | 1 | 0 |

핵심: 필수 간선은 pq·pr·qs·rs이며 ps·qr는 질의에 없다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) p. 21, Fig. 11

## 5. 예제의 데이터 그래프: 이웃 목록을 명시한다

이후 계산은 도9의 그래프 하나만 사용한다


| 정점 | 이웃 | 차수 |
| --- | --- | --- |
| a | b, e | 2 |
| b | a, c, d, e | 4 |
| c | b, d | 2 |
| d | b, c, e | 3 |
| e | a, b, d | 3 |

핵심: 차수는 한 정점에 연결된 간선 수이며 정점 번호와는 다르다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) p. 20, Fig. 9; recomputed

## 6. 간선이 더 있어도 매칭인가

이 예제는 질의의 간선을 보존하는 비유도 매칭으로 읽는다


| 조건 | 검사 | 예제에서의 의미 |
| --- | --- | --- |
| 서로 다른 정점 | p·q·r·s가 다른 곳에 대응 | 일대일 대응 |
| 질의의 간선 | pq·pr·qs·rs가 모두 존재 | 필수 조건 |
| 추가 데이터 간선 | 질의에 없어도 허용 | 비유도 매칭 |
| 유도 매칭이라면 | 없는 간선까지 보존 | 이 데이터의 C4는 0개 |

핵심: 매칭 종류를 바꾸면 같은 입력에서도 정답이 바뀐다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 4–5, 20–22, Figs. 3, 9, 11; recomputed

## 7. 하나의 C4에 왜 여덟 대응이 생기는가

시작 정점 4개 × 진행 방향 2개 = 대칭 8개


| 선택 | 가능한 수 | 그 뒤에 정해지는 것 |
| --- | --- | --- |
| p가 갈 정점 | 4개 | 사이클의 시작점 |
| q가 갈 이웃 | 2개 | 진행 방향 |
| r이 갈 이웃 | 남은 1개 | p의 다른 이웃 |
| s가 갈 정점 | 남은 1개 | p의 반대쪽 정점 |

핵심: 이 여덟 가지는 간선을 보존하며 질의 자체를 바꾸는 대칭이다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 12–14, [0071]–[0087], Figs. 11–12; recomputed

## 8. 두 종류의 사전 정보가 탐색에서 만난다

데이터의 순서와 질의의 대칭 제약을 따로 만든 뒤 함께 검사한다

- **데이터 그래프**: 차수 정렬 → 고정 번호 N
- **질의 그래프**: 대칭 분석 → 부등식 조건
- **매칭 탐색**: 간선·일대일·부등식 검사
- **대표 매핑**: 같은 대칭 부류에서 하나

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 8–14, Figs. 5, 8, 10

## 9. 번호 부여: 낮은 차수부터 고정 순서를 만든다

같은 차수끼리는 하나의 순서를 정해 이후 바꾸지 않는다


| 정점 | 원래 차수 | 번호 N |
| --- | --- | --- |
| a | 2 | 1 |
| c | 2 | 2 |
| d | 3 | 3 |
| e | 3 | 4 |
| b | 4 | 5 |

핵심: 번호는 비교용 순위이지 메모리 절감이나 실행 순서 그 자체가 아니다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 10–12, [0056]–[0070], Figs. 8–9

## 10. p < q는 알파벳을 비교하는 식이 아니다

정확한 뜻: N(f(p)) < N(f(q))


| 기호 | 의미 | 예 |
| --- | --- | --- |
| p, q | 질의 정점 | 찾으려는 역할 |
| f(p) | p에 대응한 데이터 정점 | f(p)=c |
| N(c) | c의 고정 번호 | N(c)=2 |
| p < q | 대응 정점의 번호 비교 | c와 d이면 2 < 3 |

핵심: 데이터 정점의 이름, 번호, 질의의 역할을 구분하면 부등식을 읽을 수 있다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 14–15, [0088]–[0092]; notation clarification

## 11. 첫 제약: 가장 작은 번호를 p에 대응시킨다

같은 C4의 여덟 표현 가운데 p의 위치를 하나로 고정한다


| 항목 | 조건 / 수 | 이유 |
| --- | --- | --- |
| 조건 1 | p < q | p가 q보다 작음 |
| 조건 2 | p < r | p가 r보다 작음 |
| 조건 3 | p < s | p가 s보다 작음 |
| 남는 표현 | 8 → 2 | q와 r의 방향만 남음 |

핵심: p가 최소라는 조건은 한 사이클의 시작점 중복을 제거한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 13–14, [0078]–[0084], Fig. 12; recomputed

## 12. 두 번째 제약: p의 두 이웃을 구분한다

q < r를 더하면 남아 있던 두 방향 중 하나만 통과한다


| p를 최소로 둔 표현 | q와 r의 번호 | 판정 |
| --- | --- | --- |
| (p,q,r,s)=(a,e,b,d) | 4 < 5 | 통과 |
| (p,q,r,s)=(a,b,e,d) | 5 < 4 | 탈락 |
| 같은 간선 패턴 | ab·ae·bd·de | 대표 1개 |

핵심: 시작점 4개와 방향 2개를 각각 제거해 8 → 2 → 1이 된다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 13–14, [0085]–[0087]; Fig. 9 recomputation

## 13. 조건은 일부 순서만 요구한다

최종 조건: p < q, p < r, p < s, q < r


| 관계 | 요구 여부 | 설명 |
| --- | --- | --- |
| p와 나머지 | p가 모두보다 작음 | 시작점 고정 |
| q와 r | q가 r보다 작음 | 방향 고정 |
| s와 q / r | 비교하지 않음 | 추가 제한 불필요 |
| p < r | 다른 조건에서 유도 | p < q < r의 추이성 |

핵심: 동치인 최소 조건은 p < q, q < r, p < s다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 14–15, [0088]–[0089]; corrected derivation

## 14. 대표 매핑 A: 네 간선과 번호를 모두 확인한다

(p,q,r,s) = (a,e,b,d), 번호는 (1,4,5,3)


| 질의 간선 | 대응 데이터 간선 | 존재 여부 |
| --- | --- | --- |
| p—q | a—e | 있음 |
| p—r | a—b | 있음 |
| q—s | e—d | 있음 |
| r—s | b—d | 있음 |

핵심: 1 < 4, 1 < 5, 1 < 3, 4 < 5를 모두 만족한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 20–21, Figs. 9, 11; recomputed

## 15. 대표 매핑 B: 다른 위치의 사이클은 보존한다

(p,q,r,s) = (c,d,b,e), 번호는 (2,3,5,4)


| 질의 간선 | 대응 데이터 간선 | 존재 여부 |
| --- | --- | --- |
| p—q | c—d | 있음 |
| p—r | c—b | 있음 |
| q—s | d—e | 있음 |
| r—s | b—e | 있음 |

핵심: 2 < 3, 2 < 5, 2 < 4, 3 < 5를 모두 만족한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 20–21, Figs. 9, 11; recomputed

## 16. 작은 예는 전수 검사로 정답을 확인할 수 있다

다섯 데이터 정점에서 서로 다른 네 정점을 대응시키는 120개를 검사한다


| 검사 단계 | 남은 수 | 뜻 |
| --- | --- | --- |
| 모든 일대일 대응 | 5×4×3×2 = 120 | 아직 간선 검사 전 |
| 필수 네 간선 보존 | 16 | 사이클 2개 × 대칭 8개 |
| p를 최소로 제한 | 4 | 각 사이클의 두 방향 |
| q < r까지 적용 | 2 | 서로 다른 대표 2개 |

핵심: 이 수치는 작은 예제의 정확성 검사이며 실행시간 측정값이 아니다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) Figs. 9, 11–12; exhaustive constructed check

## 17. 실패한 부분 분기는 완성하기 전에 중단한다

완성된 결과를 모두 저장한 뒤 걸러내는 과정과 구분한다

1. **p = a**: 번호 1을 고정하고 이웃 후보 탐색
2. **q = b**: a—b 존재, 1 < 5 통과
3. **r = e**: a—e 존재, 그러나 5 < 4 실패
4. **되돌아감**: 이 분기만 중단; 다른 q·r 후보 계속

핵심: 이미 결정된 정점끼리 검사할 수 있는 조건을 가능한 이른 시점에 적용한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 14–15, [0088]–[0092]

## 18. 전처리와 탐색을 구분한 실행 흐름

부등식은 매칭 조건에 추가되는 검사다

1. **전처리**: 고정 번호 N과 질의 제약 생성
2. **후보 선택**: 미사용 데이터 정점으로 부분 매핑 확장
3. **조건 검사**: 간선·일대일·현재 판정 가능한 부등식
4. **분기 처리**: 실패하면 복귀; 미완성이면 계속 확장
5. **출력**: 완성된 대표를 기록하고 다른 분기 탐색

핵심: 이웃 연결을 검사하지 않고 번호 조건만 검사하면 잘못된 결과도 통과한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 8–15, Figs. 5, 8, 10, 13

## 19. p < q < r < s로 바꾸면 정답이 사라진다

원래 제약에 없는 r < s를 추가하면 대표를 과도하게 제한한다


| 매핑 | 번호 튜플 | 전체 순서 검사 |
| --- | --- | --- |
| 대표 A | (1,4,5,3) | 5 < 3에서 실패 |
| 대표 B | (2,3,5,4) | 5 < 4에서 실패 |
| 올바른 조건 | p가 최소 + q < r | 정답 2개 유지 |
| 전체 순서 | p < q < r < s | 이 예의 정답 0개 |

핵심: 중복 제거 규칙은 정답을 하나 남긴다는 근거와 함께 만들어야 한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 13–15, [0078]–[0089]; constructed counterexample

## 20. 기존 탐색과의 차별점은 대칭 제약의 활용이다

VF2에 대한 특허의 문제 제기와 실제 성능 증명을 구분한다


| 접근 | 결과 처리의 초점 | 해석 범위 |
| --- | --- | --- |
| 여러 매핑 열거 | 대응 관계 각각을 출력 | 출력 정의에 따라 정상 |
| 사후 중복 제거 | 완성 결과들을 비교 | 이미 수행한 탐색은 남음 |
| 이 특허의 제안 | 번호·대칭 제약으로 조기 제한 | 중복 분기를 줄이려는 설계 |
| 우월성 판단 | 같은 출력·입력·구현으로 측정 | 특허에는 정량 비교 없음 |

핵심: VF2가 항상 무작정 탐색하거나 언제나 더 느리다고 단정하지 않는다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 4–6, [0004]–[0022]

## 21. 중복을 줄이는 규칙을 만드는 비용도 든다

질의가 작을 때의 예와 대규모 질의의 전처리 문제는 구분해야 한다


| 단계 | 필요한 작업 | 비용을 바꾸는 요인 |
| --- | --- | --- |
| 데이터 번호 | 차수 계산·정렬 | 데이터 정점·간선 수 |
| 대칭 분석 | 구조가 같은 치환 탐색 | 질의 크기와 대칭성 |
| 매칭 검사 | 후보 확장·간선·부등식 검사 | 후보 수와 pruning 효과 |
| 출력 | 남은 대표 저장 | 실제 패턴 발생 수 |

핵심: 번호 부여만으로 그래프 크기나 출력량의 한계가 없어지지는 않는다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 10–14, Figs. 8, 10; complexity interpretation

## 22. 원문의 경우의 수는 그대로 계산에 쓰기 어렵다

설명 가능한 C4 대칭과 원문 표기의 모순을 분리한다


| 항목 | 원문 / 계산 | 설명에 사용할 범위 |
| --- | --- | --- |
| 네 정점의 순열 | [0071]은 32; 4!은 24 | 단순 순열 수는 24 |
| 그룹 그림 | 8개씩 2그룹 = 16 | 전체 24의 완전 분할 아님 |
| 선택한 C4 그룹 | 간선 보존 대칭 8개 | 8 → 2 → 1을 직접 검증 |
| 조건 단순화 | [0089]에서 p < s 누락 | p < q, q < r, p < s |

핵심: 확인된 예의 동작과 모든 질의에 대한 일반적 보장을 혼동하지 않는다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 12–15, [0071], [0074], [0089], Fig. 12

## 23. 번호 조건을 통과해도 간선이 없을 수 있다

원문 성공 예 (p,q,r,s)=(c,d,e,b)는 c—e를 요구한다


| 검사 | 결과 | 이유 |
| --- | --- | --- |

## 24. 장치 구성은 프로그램을 실행하는 일반 구조다

프로세서·RAM·저장장치의 역할은 서로 다르다


| 구성 | 담당 | 뜻하지 않는 것 |
| --- | --- | --- |
| 프로세서 | 매칭 프로그램 실행 | 전용 가속기 성능 실증 |
| RAM | 실행 중 데이터와 상태 | 디스크 용량과 동일함 |
| 스토리지 | 프로그램·대규모 데이터 보관 | 자동 out-of-core 처리 |
| 인터페이스·버스 | 통신과 내부 데이터 이동 | 분산 확장성 측정 |

핵심: 알고리즘의 중복 제거와 하드웨어 용량 문제는 별도로 확인해야 한다

## 25. 이 문헌으로 확인되는 것과 남는 질문

## 26. 핵심 정리: 대표를 남기되 정답은 잃지 않는다

고정 번호와 질의 대칭을 결합해 중복 표현을 제한한다

1. **정의**: 무엇을 하나의 출력으로 볼지 먼저 정한다
2. **전처리**: 데이터 번호와 질의의 대칭 조건을 만든다
3. **탐색**: 간선·일대일·부등식을 함께 검사한다
4. **해석**: 예제의 정확성과 실측 성능을 구분한다

핵심: 중복 제거는 추가 제약의 수가 아니라 정답 보존 근거로 판단한다

근거: [patent](https://patents.google.com/patent/KR101747854B1/ko) pp. 8–16, Figs. 5, 8, 10–14
