## 2. 왜 한 slot 안에 끝난다고 가정할 수 없을까

2. 왜 한 slot 안에 끝난다고 가정할 수 없을까

발표 대본
기존 비교 연구 일부는 task 처리와 전송이 한 slot 안, 또는 다음 task 도착 전 끝난다고 두었습니다. 이 논문은 non-divisible task가 device queue와 edge queue에서 여러 slot을 지날 수 있게 모델링합니다. 따라서 새 task가 도착했을 때 현재 delay는 과거 action의 결과를 물려받고, task의 cost도 바로 다음 slot에 관측되지 않을 수 있습니다.

## 3. 먼저 고정해야 하는 모델 경계

3. 먼저 고정해야 하는 모델 경계

발표 대본
논문은 task를 나누지 않고 local 또는 하나의 edge에 보냅니다. Device는 local computation FIFO와 transmission FIFO를 갖고, edge는 각 device마다 하나의 FIFO queue를 가집니다. Edge CPU는 active queue들에게 동일하게 capacity를 나눕니다. Wireless는 orthogonal channel과 constant transmission rate를 두므로, 실제 radio interference와 packet error를 포함한 production scheduler로 일반화하면 안 됩니다.

4. 새 task가 만나는 세 대기 지점

## 5. slot 순서: enqueue 뒤 service, 다음 job은 다음 slot

5. slot 순서: enqueue 뒤 service, 다음 job은 다음 slot

발표 대본
논문은 processing 또는 transmission이 어느 slot에서 완료되면, queue의 다음 task는 다음 slot의 beginning에 시작한다고 둡니다. 이 순서는 local wait와 transmission wait을 계산할 때 이전 task의 completion/drop slot으로부터 정해집니다. 그림의 흐름은 within-slot procedure를 보여 주며, 각 칸을 별도 transmission frame이라고 뜻하지 않습니다.

6. local FIFO wait은 completion·drop slot으로 계산한다

## 7. edge 처리 지연은 왜 action 순간에 확정되지 않는가

7. edge 처리 지연은 왜 action 순간에 확정되지 않는가

발표 대본
Edge n은 device별 queue를 유지하고, active queue 집합의 각 queue가 equal processing capacity share를 받습니다. B_n(t)는 새 arrivals와 기존 queue length에 의해 시간에 따라 바뀌므로, 현재 action을 결정할 때 future edge queuing delay는 unknown입니다. 논문은 그래서 그것을 state에 직접 넣지 않고, edge가 broadcast하는 past active-queue counts를 history matrix H(t)로 넣습니다.

## 10. reward가 아니라 discounted cost를 최소화한다

10. reward가 아니라 discounted cost를 최소화한다

발표 대본
Processed task의 cost는 arrival slot부터 completed slot까지의 delay입니다. Dropped task는 delay 대신 positive constant C penalty를 받습니다. 각 device는 discount factor gamma를 사용한 expected long-term cost를 최소화하는 policy를 찾습니다. 즉 이 논문의 epsilon-greedy exploitation은 maximum reward가 아니라 minimum Q-value action을 고릅니다. Energy와 subscription fee는 extension으로 언급될 뿐 source experiment의 cost에는 들어가지 않습니다.

## 13. runtime action과 edge-assisted learning은 분리된다

13. runtime action과 edge-assisted learning은 분리된다

발표 대본
각 mobile device m에는 training을 돕는 assigned edge n_m가 있습니다. 새 task에서 device는 parameter request를 보내 current Net_m vector u_m를 받고 epsilon-greedy action을 선택합니다. Task가 processed 또는 dropped되어 cost가 관측되면 device는 delayed experience를 edge로 보냅니다. 아래 feedback lane은 그 완료된 과거 task의 experience가 D_m, Net_m(k+1), Target Net_m으로 진행하는 bounded unroll입니다. 따라서 current action의 나중 feedback을 역방향 화살표로 그리지 않습니다. Edge node는 device별 replay memory, evaluation Net, Target Net을 유지합니다.

## 22. 핵심 정리

22. 핵심 정리

발표 대본
마지막으로 다섯 연결을 기억하면 됩니다. Queue and deadline change the meaning of an action; unknown future edge load means the state must use history rather than unavailable future delay; DQN additions have distinct roles; device-side action and edge-side learning are not the same procedure; and source metrics require joint reading. Reported gains are conditioned simulation findings, while convergence and deployment questions remain open.

공개 출처
paper | abstract; §§2–6
Tang and Wong — Deep Reinforcement Learning for Task Offloading in Mobile Edge Computing Systems
