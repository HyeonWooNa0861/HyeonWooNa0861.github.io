# Dataset Pruning: 영향으로 학습 데이터를 줄이는 법

논문: Dataset Pruning: Reducing Training Data by Examining Generalization Influence

저자: Shuo Yang, Zeke Xie, Hanyu Peng, Min Xu, Mingming Sun, Ping Li (2023)

## 1. Dataset Pruning: 영향으로 학습 데이터를 줄이는 법

개별 점수 대신 제거 집합의 공동 영향을 제한하는 데이터 선택 방법


근거: [paper](https://arxiv.org/abs/2205.09329) pp. 1–2, abstract and introduction

## 2. 학습 데이터의 중복이 반복 계산 비용을 키운다

큰 데이터셋의 모든 예제가 같은 정도로 일반화에 기여하지는 않는다

- 데이터가 커지면 학습·튜닝·구조 탐색을 반복하는 비용도 함께 커진다
- 예제를 하나씩 빼고 재학습하면 영향은 알 수 있지만, 실제 규모에서는 불가능하다
- 개별 점수만 정렬하면 여러 예제가 함께 만드는 상쇄와 증폭을 놓친다
- 목표는 성능 손실을 제한하면서 남길 학습 집합을 가능한 작게 만드는 것이다

핵심: Dataset pruning은 데이터 개수를 먼저 정하지 않고 허용 가능한 변화에서 출발한다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 1–2, §1

## 3. 데이터를 줄이는 세 가지 질문

선택 예산, 합성 데이터, 허용 변화는 서로 다른 문제를 만든다


| 접근 | 먼저 고정하는 것 | 찾는 것 |
| --- | --- | --- |
| 점수 기반 선택 | 남길 데이터 수 | 점수가 높은 예제 |
| dataset condensation | 합성 예제 수 | 새로 만든 proxy data |
| dataset pruning | 허용 parameter 변화 | 제거할 최대 중복 집합 |
| 고정 제거량 variant | 제거할 예제 수 m | 영향이 가장 작은 집합 |

핵심: 논문의 새 설정은 cardinality 제약을 generalization 관련 제약으로 바꾼다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 2–4, §2–§4.2

## 4. 개별 영향이 커도 함께 제거하면 상쇄될 수 있다

영향은 scalar 순위가 아니라 방향을 가진 vector로 더해야 한다


| 강의용 vector | 개별 norm | 함께 더한 결과 |
| --- | --- | --- |
| g₁ = (3, 0) | 3 | 첫 vector |
| g₂ = (−3, 0) | 3 | 둘째 vector |
| g₁ + g₂ | 개별 값은 큼 | (0, 0), norm 0 |

핵심: gradient norm이나 influence norm만 정렬하면 이 joint effect를 볼 수 없다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 1, 4 and 8, group effect

## 5. 문제에 등장하는 집합과 모델

제거 집합과 남은 집합을 먼저 분리하면 최적화 식을 읽기 쉽다


| 기호 | 뜻 | 역할 |
| --- | --- | --- |
| D, n | 원본 dataset과 예제 수 | pruning 출발점 |
| D̂, m | 제거할 subset과 크기 | 최대화 대상 |
| D̃ = D − D̂ | 남은 training set | 최종 재학습 data |
| θ̂ | D에서 얻은 ERM 해 | parameter 기준점 |
| θ̂₋D̂ | D̂ 제거 후 ERM 해 | 변화량 비교 대상 |

핵심: 논문은 남길 집합이 아니라 제거할 중복 집합 D̂를 직접 선택한다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 3, §3 and Definition 1

## 6. ε-redundant subset의 정의

제거 전후 parameter 거리가 ε 이하이면 그 subset을 중복으로 본다


| 조건 | 읽는 법 | 주의 |
| --- | --- | --- |
| \|\|θ̂₋D̂ − θ̂\|\|₂ ≤ ε | model parameter 변화 제한 | test accuracy 식이 아님 |
| D̂ε | 조건을 만족한 제거 subset | 여러 개가 가능 |
| D̂εmax | 가장 큰 ε-redundant subset | 남은 D̃는 가장 작아짐 |

핵심: parameter 근접성이 generalization 근접성을 대신하는 핵심 proxy다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 3, Definition 1

## 7. 정확한 subset 검사는 2ⁿ번 재학습을 요구한다

가능한 제거 집합마다 모델을 다시 학습하는 방식은 확장되지 않는다

1. **n개 예제**: 각 예제를 제거하거나 유지
2. **2ⁿ개 subset**: 가능한 조합을 모두 생성
3. **매번 재학습**: θ̂₋D̂를 새로 계산
4. **영향 근사**: 한 기준 model에서 변화 추정

핵심: Influence Function은 subset마다 재학습하는 비용을 한 번의 local 근사로 바꾼다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 1 and 4, §1 and §4

## 8. 한 예제의 제거 영향을 재학습 없이 근사한다

sample gradient를 Hessian inverse로 보정해 parameter 이동 방향을 얻는다

- **레인 influence**
  - **sample gradient**: ∇L(z, θ̂)
  - **curvature 보정**: −H⁻¹∇L(z, θ̂)
  - **I_param(z)**: weight 증가 방향
  - **제거 변화 근사**: −I_param(z) / n
- sample gradient → curvature 보정 (실선, 단방향)
- curvature 보정 → I_param(z) (실선, 단방향)
- I_param(z) → 제거 변화 근사 (실선, 단방향)

핵심: Eq. (2)는 trained solution 주변의 1차 local approximation이다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 4, §4.1 and Eq. (2)

## 9. Influence Function이 계산하는 것과 계산하지 않는 것

parameter 이동의 1차 추정치를 실제 재학습 결과와 같은 값으로 보면 안 된다


| 구분 | 논문의 값 | 경계 |
| --- | --- | --- |
| 입력 | θ̂에서의 gradient와 Hessian | 한 local 지점 |
| 출력 | parameter change vector | test metric 직접 예측 아님 |
| subset | 개별 influence의 합 | 선형 근사 |
| 실험 구현 | 마지막 linear layer만 계산 | 전체 network와 다름 |

핵심: 계산이 빨라지는 대신 local linearization과 layer 근사를 받아들인다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 4 and 7, §4.1 and §6.1

## 10. Subset 영향은 선택한 vector의 합이다

S는 각 예제 제거의 parameter 변화 근사를 모아 둔 행렬이다


| 기호 | 정의 | 해석 |
| --- | --- | --- |
| sᵢ | −I_param(zᵢ) / n | 예제 i 제거 vector |
| S | 모든 sᵢ를 모은 matrix | candidate influence 집합 |
| Wᵢ = 1 | 예제 i를 D̂에 선택 | 유지가 아니라 제거 |
| WᵀS | 선택 vector의 합 | joint parameter 변화 |

핵심: 최적화 변수 W는 예제별 순위를 만들지 않고 조합을 직접 고른다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 4, §4.2

## 11. Eq. (3): 허용 영향 안에서 제거 수를 최대화한다

목적 함수와 constraint를 분리해 읽으면 선택 방향이 선명해진다


| 구성 | 표현 | 뜻 |
| --- | --- | --- |
| 변수 | W ∈ {0,1}ⁿ | 각 예제 제거 여부 |
| 목적 | maximize ΣWᵢ | 제거 example 최대화 |
| constraint | \|\|WᵀS\|\|₂ ≤ ε | joint influence 제한 |
| 결과 | D̂εmax = {zᵢ : Wᵢ=1} | 가장 큰 feasible 제거 집합 |

핵심: ε가 작을수록 parameter 변화는 더 제한되지만 제거 가능한 수는 줄 수 있다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 4, Eq. (3)

## 12. Eq. (4): 제거 수를 고정하면 영향 norm을 최소화한다

실험 비교에서는 baseline과 같은 pruning ratio를 맞추기 위해 이 variant를 쓴다


| 질문 | Eq. (3) | Eq. (4) |
| --- | --- | --- |
| 먼저 정하는 값 | 영향 tolerance ε | 제거 수 m |
| 최적화 목표 | ΣWᵢ 최대화 | \|\|WᵀS\|\|₂ 최소화 |
| 공통 변수 | binary selector W | binary selector W |
| 논문 실험 | theory 검증에 연결 | baseline pruning 비교 |

핵심: 같은 pruning ratio의 성능 비교가 Eq. (3)의 tolerance-driven 문제와 같지는 않다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 4 and 8, Eq. (4) and §6.3

## 13. Algorithm 1과 이후 평가의 흐름

전체 model을 한 번 학습한 뒤 influence와 discrete solver로 제거 집합을 만든다

- **레인 pruning**
  - **full-data 학습**: D에서 θ̂ 계산
  - **influence 추정**: 모든 sᵢ 저장
  - **W 최적화**: Eq. (3) 또는 Eq. (4)
  - **D̂ 제거**: D̃ = D − D̂
  - **실험 재학습**: D̃로 새 model 학습
- full-data 학습 → influence 추정 (실선, 단방향)
- influence 추정 → W 최적화 (실선, 단방향)
- W 최적화 → D̂ 제거 (실선, 단방향)
- D̂ 제거 → 실험 재학습 (실선, 단방향)

핵심: pruning 전 full-data 학습과 influence 계산이 필요하므로 선택 단계도 공짜가 아니다

근거: [paper](https://arxiv.org/abs/2205.09329) p. 5, Algorithm 1; p. 8, §6.3

## 15. Theorem 1: expected loss gap의 상계

논문은 influence constraint를 loss gap과 연결하는 asymptotic bound를 제시한다


| 항목 | 표기·관계 | 의미 |
| --- | --- | --- |
| gap | \|L(θ_after) − L(θ_before)\| | 제거 후·전 expected test loss 차이 |
| premise | \|\|Σ I_param(zᵢ)\|\|₂ ≤ ε | unscaled influence 합 제한 |
| bound | O(ε/n + m/n²) | 1차 항과 2차 remainder |
| derivation | Taylor + Cauchy–Schwarz | local approximation 사용 |

핵심: 상계는 observed accuracy가 ε만큼만 감소한다는 직접 보장이 아니다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 5–6, Theorem 1 and Eq. (7)

## 16. Guarantee를 읽을 때 남겨야 할 조건

논문의 이론, 근사, 구현은 같은 수준의 주장이 아니다

- Hessian은 positive definite라고 가정한다
- Influence Function과 subset 합은 θ̂ 주변의 1차 근사다
- Eq. (3)의 S는 이미 1/n을 포함하지만 theorem premise는 unscaled 합을 쓴다
- 실험은 full network가 아니라 마지막 linear layer의 influence를 계산한다
- simulated annealing은 discrete problem의 global optimum을 보장하지 않는다

핵심: 일반화 bound는 이 조건을 포함한 분석 결과이며 모든 pruning 실행의 절대 보증이 아니다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 4–7, Eq. (2)–(14) and §6.1

## 24. Dataset pruning의 비용과 적용 경계

작은 dataset의 이득을 얻기 전에 full model과 influence 계산이 필요하다


| 항목 | 필요한 비용 | 해석 제한 |
| --- | --- | --- |
| 기준 model | full D에서 먼저 학습 | one-shot 절감 아님 |
| influence | 모든 예제 vector 저장 | last-layer approximation |
| Hessian | inverse estimate 계산 | positive-definite 가정 |
| subset solver | simulated annealing | global optimum 미보장 |
| 외부 적용 | 새 task에서 재검증 | image/NAS 결과에 한정 |

핵심: 많은 model을 같은 data에서 반복 학습할 때 비용 상쇄 가능성이 가장 크다

근거: [paper](https://arxiv.org/abs/2205.09329) pp. 5, 7 and 9, Algorithm 1 and §6

## 25. 정리: 제거 집합의 공동 영향으로 data를 줄인다

Dataset pruning은 tolerance-driven subset selection을 influence optimization으로 푼다

- 한 sample의 제거 효과를 Hessian-adjusted influence vector로 근사한다
- 여러 sample의 vector 합을 제한해 group effect를 선택 과정에 포함한다
- CIFAR와 NAS 실험은 계산 절감과 accuracy trade-off를 조건부로 보여 준다
- Theorem의 scale, Taylor assumption, last-layer 구현과 heuristic solver를 함께 읽어야 한다
