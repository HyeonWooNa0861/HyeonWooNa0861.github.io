## 2. 학습 데이터의 중복이 반복 계산 비용을 키운다

2. 학습 데이터의 중복이 반복 계산 비용을 키운다

발표 대본
논문은 모델 파라미터 pruning과 구분되는 데이터 중복 문제를 다룹니다. 모든 부분집합을 직접 시험하면 데이터가 n개일 때 2의 n제곱 번 재학습해야 합니다. 저자들은 이 비용을 피하면서 제거 집합의 공동 영향을 고려하는 방법을 제안합니다. 여기서 작은 데이터셋 자체가 목적이 아니라, 허용한 변화 안에서 학습 비용을 줄이는 것이 목적입니다.

## 8. 한 예제의 제거 영향을 재학습 없이 근사한다

## 15. Theorem 1: expected loss gap의 상계

15. Theorem 1: expected loss gap의 상계

발표 대본
이 슬라이드에서 L은 논문의 expected test loss, θ_before는 전체 데이터의 추정 모델, θ_after는 선택한 데이터를 제거한 뒤의 추정 모델을 뜻합니다. 원문의 θ hat과 제거 집합 첨자가 붙은 θ hat을 각각 before와 after로 풀어 쓴 표기입니다. Theorem 1은 expected test loss의 차이를 big O epsilon over n plus m over n squared로 씁니다. 증명은 test loss를 theta hat 주변에서 first-order Taylor expansion하고 Cauchy–Schwarz를 적용합니다. 논문은 higher-order term을 작다고 취급합니다. 따라서 특정 run의 accuracy drop이 정확히 이 값 이하라는 finite constant bound로 읽으면 안 됩니다.

논문의 중요한 전환은 개별 example score를 정렬하는 대신 제거 subset 전체의 parameter influence를 최적화하는 것입니다. 이론은 parameter influence constraint와 expected loss gap을 연결하고, 실험은 CIFAR와 NAS에서 효율을 보여 줍니다. 하지만 theorem의 scaling convention과 approximation assumption, source의 small-network label inconsistency, last-layer influence와 simulated annealing 구현은 적용 전에 확인해야 합니다.
