# 전송률을 넘어 사용자 경험으로: SIM 자원 할당

논문: QoE-Driven Resource Allocation for Stacked Intelligent Metasurface Systems

저자: Hosein Zarini, S. Mohsen Kazemi, Jiancheng An, Ali Movaghar, Mehdi Sookhak, Nuri Yilmazer (2025)

## 1. 전송률을 넘어 사용자 경험으로: SIM 자원 할당

다층 전자기파 제어와 전력 배분을 QoE 목표로 연결하는 Meta-CQL 프레임워크


근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 1, title and abstract

## 2. 같은 전송률 증가가 같은 만족도 증가를 뜻하지는 않는다

QoS는 통신 성능, QoE는 서비스 이용자의 경험을 평가하려는 관점이다


| 개념 | 이 논문에서의 역할 | 혼동하지 않을 점 |
| --- | --- | --- |
| QoS | SINR와 전송률 같은 통신 지표 | 사용자 만족도를 직접 측정한 값 아님 |
| QoE | 서비스별 MOS 모델로 경험을 수치화 | 모델 기반 점수이지 사용자 실험 자체 아님 |
| MOS | Mean Opinion Score: 만족도 척도 | 서비스별 변환식과 범위가 다름 |
| 최적화 | 전력·SIM 설정으로 MOS 합을 높임 | sum-rate 최대화와 목표가 같지 않음 |

핵심: 통신 지표를 서비스 경험으로 바꾸는 변환식이 자원 배분의 목표를 바꾼다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 1, 3, Introduction; QoE Preliminaries

## 3. 기지국의 전파가 여러 SIM 층을 지나 사용자에게 도달한다

BS는 Base Station, SIM은 Stacked Intelligent Metasurface의 약자다

1. **BS와 U개 stream**: 사용자별 전력 pᵤ를 배분
2. **L개 SIM 층**: 각 층에 F개 meta-atom
3. **위상 제어**: 각 원소의 전파 위상을 조절
4. **U명 사용자**: 단일 안테나에서 원하는 신호 수신
5. **서비스 경험**: 간섭·전송률을 MOS와 연결

핵심: 결정 변수는 사용자별 전력과 SIM 위상이며, 계산 task를 offload할지의 문제가 아니다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 2, Fig. 1; Sec. II.A–C

## 4. 두 층으로 줄여 보면 위상과 전파 연산의 순서가 보인다

설명용 L=2 구조: Ω = Γ²B²Γ¹, 첫 층 유입 b¹ᵤ는 Ω 밖에 있다

- **레인 wave propagation**
  - **b¹ᵤ**: BS에서 첫 층으로
  - **Γ¹**: 첫 층 위상 조절
  - **B²**: 층 사이 전파
  - **Γ²**: 둘째 층 위상 조절
  - **Ωb¹ᵤ**: 사용자 채널 hᵤ로
- b¹ᵤ → Γ¹ (실선, 단방향)
- Γ¹ → B² (실선, 단방향)
- B² → Γ² (실선, 단방향)
- Γ² → Ωb¹ᵤ (실선, 단방향)

핵심: 위상 설정을 바꾸면 원하는 신호와 다른 사용자 간섭이 함께 달라진다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 2, Eqs. (1)–(2)

## 5. SINR는 원하는 신호와 간섭을 함께 반영한다

Ω는 사용자마다 독립적인 신호 증폭기가 아니라 다중 사용자 전파 경로를 함께 바꾼다


| 항목 | 수식 또는 정의 | 뜻 |
| --- | --- | --- |
| 유효 gain | gᵤᵥ = \|hᵤΩb¹ᵥ\|² | stream v가 사용자 u에 미치는 세기 |
| 원하는 신호 | gᵤᵤpᵤ | 자기 stream의 수신 전력 |
| 간섭과 잡음 | Σᵥ≠ᵤ gᵤᵥpᵥ + σᵤ² | 다른 stream의 영향 포함 |
| SINR → R | Rᵤ = log₂(1 + SINRᵤ) | 원문 Eq. (4)의 정규화 rate proxy |

핵심: 전력을 한 사용자에게 더 주면 다른 사용자에게는 간섭이 커질 수 있다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 3, Eqs. (3)–(4)

## 6. MOS로 바꾸는 경로는 서비스마다 다르다

웹은 페이지 지연, 비디오는 PSNR, 음성은 음질 지표를 통해 만족도를 모델링한다


| 서비스 | 원문의 변환 구조 | 범위·주의 |
| --- | --- | --- |
| Web | R → 페이지 지연 ν(R) → −K₁lnν + K₂ | MOS 척도 1–5 |
| Video | R → PSNR Ξ → 구간별 로그 변환 | MOS 1–4.5 |
| Audio | R-factor 또는 log(R) 근사 → MOS | MOS 1–4.5 |
| 원문 경계 | 음성 RF 분기 조건이 겹침 | 해당 분기를 실행식으로 확정하지 않음 |

핵심: QoE 목표를 이해하려면 통신식뿐 아니라 서비스 변환식의 조건도 알아야 한다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 3, Sec. II.D; Eq. (5)

## 7. 논문은 서비스 종류별로 세 개의 최적화 문제를 정의한다

ℓ∈{Web, Video, Audio}에 대해 사용자 MOS 합을 최대화한다


| 요소 | 원문 설정 | 해석 |
| --- | --- | --- |
| 결정 Ψ | 사용자별 전력 P와 SIM 응답 Ω | 두 요소를 함께 조절 |
| 목표 | Σᵤ MOSℓ,ᵤ 최대화 | 각 서비스 ℓ별 문제 |
| 최소 경험 | 모든 u: MOSℓ,ᵤ ≥ MOSℓᵐⁱⁿ | 합이 높아도 개별 사용자가 중요 |
| 전력 예산 | Σᵤpᵤ ≤ Pᵐᵃˣ | BS 전체 전력 제한 |

핵심: 서비스별 목적식과 모든 사용자 최소 조건을 함께 읽어야 한다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 3, Eq. (6) and following paragraph

## 8. 전력만 맞추면 가능한 action이 되는 것은 아니다

C1–C5는 최소 경험·전력·실현 가능한 위상 구조를 함께 제한한다


| 제약 | 원문이 요구하는 것 | 정책에 대한 별도 확인 |
| --- | --- | --- |
| C1 | 각 사용자 최소 MOS | 학습 결과가 항상 충족하는지 |
| C2 | BS 전력 합이 예산 이하 | 출력 전력의 제약 처리 |
| C3·C4 | Ω는 실제 층·위상 행렬의 곱 | 임의 복소 행렬을 고르는 것 아님 |
| C5 | 위상 κ ∈ [0, 2π) | 원소별 허용 범위 |

핵심: 문제의 제약을 정의한 것과 학습 정책의 제약 충족을 증명한 것은 다르다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 3–4, Eq. (6); MDP transformation

## 9. MDP에서는 이전 SINR로 현재 전력과 SIM 응답을 정한다

edge node가 제어 agent이며 state와 action을 통신 자원 변수에 연결한다

1. **state s[n]**: 이전 slot의 사용자별 SINR
2. **action a[n]**: 전력 P[n]와 SIM 응답 Ω[n]
3. **전파 환경**: 채널·간섭이 새 SINR를 결정
4. **경험 점수**: 서비스 모델로 MOS 계산
5. **학습 신호**: MOS와 제약을 보상에 반영하려는 설계

핵심: state는 과거 SINR, action은 통신 전력과 SIM 설정이다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 4, Sec. III.A

## 10. CQL을 채택한 동기: 데이터 밖 행동을 과신하지 않기

아래는 학습 항의 역할 구분이며, 원문의 식을 복원한 실행 알고리즘은 아니다

- **과거 관측 데이터**: state·action·reward
- **Bellman 적합**: 목표 Q와 현재 Q 비교
- **보수적 가치 평가**: 과도한 행동 가치 억제
- **Q 학습의 두 역할**: 적합도와 보수성
- **자원 제어 정책**: P·Ω 선택에 활용

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 4, Sec. III.B

## 11. 메타학습: 새 task에 적응할 시작점 찾기

inner loop는 task별 적응, outer loop는 여러 적응 결과를 통해 초기 파라미터를 조정한다

1. **task 집합**: 환경 task Tᵢ를 선택
2. **공유 초기값 θ**: 각 task가 같은 시작점 사용
3. **inner update**: task별 θ′ᵢ로 적응
4. **outer objective**: 적응한 task 목적들을 합산
5. **새 초기값**: 다음 task의 적응 출발점 갱신

핵심: 실제 적응 비용과 task 분포까지 알아야 ‘새 환경에 빠르다’는 주장을 재현할 수 있다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 4–5, Sec. III.C; Eq. (7)

## 12. 강의용 예제: 같은 총 rate라도 분배 결과는 다를 수 있다

다음 gain·전력·효용은 모두 설명용 가정이며 논문의 실험이나 MOS 식이 아니다


| 항목 | 가정 | 계산 목적 |
| --- | --- | --- |
| 사용자 두 명 | 원하는 gain²=4, 교차 gain²=1 | 신호와 간섭을 함께 계산 |
| 잡음·전력 | 잡음=1, 전체 전력 예산=2 | 정규화된 무차원 예제 |
| 배분 A / B | A=(1,1), B=(1.5,0.5) | 둘 다 전력 합은 2 |
| 가상 만족도 | m(R)=1+min(R,2), 최소 m=2 | 포화와 개별 최소 조건 설명 |

핵심: 전체 전력과 전체 rate만 보면 숨겨지는 개별 사용자 차이를 계산해 보자

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 3, Eqs. (3)–(6); constructed teaching example

## 13. 전력 합과 rate 합이 같아도 최소 만족도는 달라진다

위에서 정의한 가상 효용을 적용한 산술 예제 — 실제 논문 결과가 아니다


| 계산 | 배분 A: (1,1) | 배분 B: (1.5,0.5) |
| --- | --- | --- |
| SINR₁ / SINR₂ | 4/2=2 / 4/2=2 | 6/1.5=4 / 2/2.5=0.8 |
| R₁ / R₂ | 1.5850 / 1.5850 | 2.3219 / 0.8480 |
| rate 합 | 3.1699 | 3.1699 |
| m₁ / m₂ | 2.5850 / 2.5850 | 3.0000 / 1.8480 |
| 효용 합·최소 조건 | 5.1699; 둘 다 m≥2 | 4.8480; 사용자 2는 미달 |

핵심: QoE 최적화는 사용자별 변환과 최소 조건을 버린 sum-rate 비교로 대체할 수 없다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) p. 3, Eqs. (3)–(6); constructed teaching example

## 14. 원문의 reward indicator는 두 곳에서 반대 의미로 쓰인다

이 불일치를 해결하지 않고 정확한 학습 보상을 재현했다고 말할 수는 없다


| 위치 | 인쇄된 내용 | 문제가 되는 이유 |
| --- | --- | --- |
| p. 4 | χᵢ=1: 제약 만족, χᵢ=0: 미만족 | 만족한 제약이 감점 항에 들어감 |
| p. 4 보상 | Rew=(1−Σᵢχᵢ)S, S=ΣᵤMOS | 다섯 제약 만족 시 문자 그대로 −4S |
| p. 6 | 제약 위반 때문에 penalty 차감 | p. 4의 indicator 설명과 반대 |
| 강의의 경계 | MOS에 제약을 반영하려는 목적만 확인 | 구현에서 쓴 조건·부호는 미확정 |

핵심: 문제의 목적은 설명할 수 있지만, 모순된 reward 식을 확정된 코드로 제시하면 안 된다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 4, 6, Reward Function; Fig. 2 discussion

## 15. CQL의 목적함수 이름과 update 연결도 확인이 필요하다

논문이 말하는 보수적 학습 의도와 실제 최소화 식은 서로 다른 검증 대상이다


| 원문 항목 | 표현 | 남는 구현 경계 |
| --- | --- | --- |
| J(θ) | E_D Q − α E_π Q | 뒤 penalty와 방향이 다름 |
| L(θ) | Bellman 오차² + α(E_π Q−Q_data) | J와의 관계가 설명되지 않음 |
| update | θ ← θ − ζ∇J, 본문은 J_CQL 언급 | 어느 손실을 최적화했는지 미확정 |
| meta update | inner·outer에서 gradient 사용 | 부호·trust-region 구현 미완결 |

핵심: 메타학습과 CQL의 역할은 배울 수 있어도, 이 식들만으로 완전한 재현 절차가 되지는 않는다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 4–5, Sec. III.B–C

| 항목 | 확인된 사실 | 따라오는 경계 |
| --- | --- | --- |
| C1 | 모든 사용자 MOS ≥ 최소값 | 같은 사용자 평균도 최소값 이상이어야 함 |
| Fig. 4, x=3.5 | 평균 MOS가 약 1.7 / 1.25 | 원본 곡선의 근사 판독값 |
| 본문의 공백 | soft penalty·평균 대상 차이 설명 없음 | 왜 평균이 최소값보다 낮은지 미해결 |
| 주장 가능한 것 | 원문이 보고한 평균 MOS 곡선 | C1 충족·최소 MOS 보장은 아님 |

핵심: constraint를 적은 수학 문제와 그 constraint를 만족한 실험 결과를 구분하자

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 3, 5–6, Eq. (6) C1; Fig. 4

## 20. 고정 신경망의 비용과 시스템 확장성은 다르다

사용자 수 U와 위상 원소 수 L×F가 바뀌면 입력·출력 표현도 확인해야 한다


| 영역 | 확인할 조건 | 확정할 수 없는 주장 |
| --- | --- | --- |
| state 차원 | 사용자별 SINR이 입력 | U가 늘어도 비용이 불변이라는 주장 |
| action 차원 | 사용자 전력과 SIM 위상 | L·F 변화에 무관한 제어 비용 |
| 학습 비용 | layer·batch·episode·task 수 | 추론 시간과 같은 숫자라는 해석 |
| 실제 장치 | 시뮬레이션 중심의 증거 | 온디바이스·실시간·배터리 성능 보장 |

핵심: 주어진 simulator에서의 MOS 결과가 특정 edge 장치의 실행 가능성을 결정해 주지는 않는다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 2, 4–6, Sec. III.D; Performance Evaluation

## 21. 이 논문에서 가져갈 핵심과 확인할 경계

전력·위상 → SINR → 서비스 경험이라는 구조와, 구현·검증 근거를 함께 읽는다

1. **공동 제어**: P와 Ω가 신호·간섭을 함께 바꿈
2. **서비스 목표**: 같은 rate라도 MOS 효과는 다를 수 있음
3. **학습 구조**: CQL 동기 + task별 meta 적응
4. **실험 해석**: 조건·축·평균·제약을 함께 읽음
5. **재현 경계**: 모순된 식은 정정 근거가 필요

핵심: 좋은 문제 정의, 유망한 simulation, 재현 가능한 구현은 각각 따로 검증해야 한다

근거: [pimrc2025](https://doi.org/10.1109/PIMRC62392.2025.11275274) pp. 1–6, framework and evidence boundaries
