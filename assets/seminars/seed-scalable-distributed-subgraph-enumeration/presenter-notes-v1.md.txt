## 1. SEED: 확장 가능한 분산 서브그래프 열거

1. SEED: 확장 가능한 분산 서브그래프 열거

발표 대본
SEED는 큰 비라벨 그래프에서 주어진 패턴과 동형인 모든 서브그래프를 분산 환경에서 열거하는 방법입니다. 핵심은 단순히 기계를 늘리는 데 있지 않습니다. 어떤 부분 패턴을 먼저 만들고, 로컬 그래프에 무엇을 저장하며, 어떤 중간 결과를 물질화할지 함께 설계해야 합니다. 발표에서는 후보 폭발에서 출발해 SCP 저장, PR 비용 추정, bushy 조인 계획, clique compression으로 이어지는 설계 논리를 따라갑니다.

## 2. 입력은 두 그래프, 출력은 모든 match

2. 입력은 두 그래프, 출력은 모든 match

발표 대본
문제의 입력은 분산 파일 시스템에 저장된 data graph G와 작은 connected pattern P입니다. Match는 P의 각 vertex를 G의 vertex에 대응시키는 mapping입니다. 이 논문은 하나가 존재하는지 묻는 subgraph isomorphism decision이 아니라 조건을 만족하는 모든 mapping을 열거합니다. 따라서 계산 과정의 후보뿐 아니라 최종 출력 크기도 알고리즘이 피할 수 없는 비용이 될 수 있습니다.

## 3. Decision과 enumeration은 종료 조건이 다르다

3. Decision과 enumeration은 종료 조건이 다르다

발표 대본
Enumeration에서는 최종 match가 매우 많다면 그 모든 결과를 실제로 전달해야 합니다. SEED의 clique compression은 중간 join 동안 결과를 압축해 유지하지만, 사용자가 distinct match 전체를 요구하면 마지막에는 확장해야 합니다. 그러므로 이 논문의 확장성 주장은 불필요한 intermediate relation을 줄이는 데 초점을 두며, 최종 output 크기의 하한을 없애는 것은 아닙니다.

## 4. 기본 match의 두 조건에 대칭 제거 조건을 더한다

4. 기본 match의 두 조건에 대칭 제거 조건을 더한다

발표 대본
Conflict freedom은 mapping이 injective해야 한다는 뜻입니다. Structure preservation은 pattern의 모든 edge가 data graph에도 있어야 한다는 뜻입니다. 대칭이 있는 pattern에서는 하나의 실제 subgraph가 여러 mapping으로 반복될 수 있으므로 pattern vertex 사이에 partial order를 두고 order preservation을 추가합니다. 논문은 분석 편의를 위해 대칭 제거 뒤의 match 열거에 초점을 둡니다.

## 5. Symmetry breaking은 같은 subgraph의 중복 표현을 막는다

5. Symmetry breaking은 같은 subgraph의 중복 표현을 막는다

발표 대본
Pattern에 A개의 automorphism이 있으면 같은 subgraph가 A개의 match로 나타날 수 있습니다. 논문은 degree와 ID를 이용해 data vertex의 total order를 만들고, pattern vertex 사이의 partial order를 보존하는 mapping만 남깁니다. 이는 duplicate enumeration을 막는 별도의 장치입니다. 어떤 join unit과 join tree를 선택할지는 그 다음 단계의 비용 최적화 문제입니다.

6. High-degree vertex 하나가 후보를 폭발시킨다

## 11. Left-deep과 bushy는 중간 결과의 모양이 다르다

11. Left-deep과 bushy는 중간 결과의 모양이 다르다

발표 대본
Left-deep tree에서는 매 join마다 한 입력이 원시 join unit입니다. 그래서 하나의 partial relation이 단계마다 커집니다. Bushy tree는 두 subpattern을 독립적으로 선별한 뒤 합칠 수 있어 power-law graph에서 거대한 intermediate를 피할 수 있습니다. 논문 Figure 2의 예에서는 두 plan 모두 세 round이므로, bushy의 이득을 단순히 round 감소로 설명하면 정확하지 않습니다.

## 12. SEED는 다섯 구성요소를 하나의 실행 계획에 묶는다

12. SEED는 다섯 구성요소를 하나의 실행 계획에 묶는다

발표 대본
SCP storage는 가능한 join unit을 늘립니다. PR model은 각 unit과 partial pattern의 match relation 크기를 추정합니다. Dynamic programming은 그 비용을 이용해 bushy plan을 선택합니다. Overlap은 필요한 edge를 조금 중복해 relation을 더 선별적으로 만들고, clique compression은 data graph 안의 큰 clique가 만드는 조합 폭발을 줄입니다. 논문은 이 요소들을 독립 발명 목록이 아니라 하나의 execution-plan framework 안에서 연결합니다.

14. Φ₀는 중심과 incident edge만 저장한다

논문의 PR graph에서는 expected degree sequence w를 주고, i와 j 사이 edge probability를 w_i w_j ρ로 둡니다. ρ는 전체 기대 degree 합의 역수입니다. δ와 δ prime은 data vertex degree가 아니라 edge를 붙이기 직전 partial pattern에서 두 endpoint의 degree입니다. 긴 합의 비율을 한눈에 비교하려고 μ(δ)라는 교육용 축약을 도입했습니다. 이는 새로운 추정기를 제안하는 것이 아니라 원문 Equation 6과 7을 동일하게 다시 쓰는 표기입니다.

## 24. 새 이웃을 붙일 때와 기존 두 정점을 닫을 때의 계산

24. 새 이웃을 붙일 때와 기존 두 정점을 닫을 때의 계산

발표 대본
새 pattern vertex를 추가하는 tree-edge case에서는 γ=∑w_i^(δ+1)/∑w_i^δ입니다. 이미 mapping된 두 endpoint 사이 non-tree edge를 추가하면 γ=ρ×(∑w_i^(δ+1)/∑w_i^δ)×(∑w_j^(δ′+1)/∑w_j^δ′)입니다. 두 식은 원문 Equations 6과 7입니다. 새로운 endpoint를 고르는 연산과 기존 endpoint 사이 edge를 요구하는 연산을 구분해야 합니다. 이 연쇄 계산은 PR 모델 내부에서 conflict freedom을 완화한 count 추정이며, 실제 graph의 tuple 수나 runtime을 결정적으로 상계한다는 뜻이 아닙니다.

## 30. All-or-nothing은 overlap search를 O(3ᵐ)으로 되돌린다

30. All-or-nothing은 overlap search를 O(3ᵐ)으로 되돌린다

발표 대본

Theorem 1은 baseline optimal cost가 graph edge 수 규모 이상이고, 모든 join에 redundant node가 없을 때 얻은 plan의 cost가 exact overlap optimum과 같은 asymptotic order라고 합니다. 동일 cost나 global exact optimum을 보장하는 정리가 아닙니다.
