## 3. 문제는 token 계산의 의존 순서였다

RNN은 이전 state를 기다리지만 self-attention layer는 모든 위치의 표현을 함께 계산할 수 있다


| Layer | Sequential ops | Max path | Per-layer cost |
| --- | --- | --- | --- |
| Recurrent | O(n) | O(n) | O(n d^2) |
| Self-attention | O(1) | O(1) | O(n^2 d) |
| Restricted attention | O(1) | O(n/r) | O(r n d) |

핵심: 짧은 sequential depth와 작은 total cost는 같은 주장이 아니다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 6, Table 1 and Sec. 4

## 4. Source와 target이 decoder layer에서 만난다

교육용 예시 source는 The cat sleeps, target prefix는 Le chat이다

- **Source encoder**: Source tokens + position → encoder ×6 → K,V
- **Shifted target**: Shifted target + position → masked self → Q
- **Cross-attention**: Decoder Q + encoder K,V
- **Decoder output**: FFN → next decoder layer; final softmax

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 3, Fig. 1 and encoder-decoder stacks, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, applications of attention

## 5. Encoder layer 하나를 펼쳐 보기

동일한 구조를 N=6회 쌓으며 각 sublayer에 residual connection과 layer normalization을 적용한다

1. **Layer input**: 모든 source token representations
2. **Self-attention**: Q, K, V가 같은 encoder input에서 옴
3. **Add & Norm**: LayerNorm(x + Sublayer(x))
4. **Position-wise FFN**: 각 position에 같은 network 적용
5. **Add & Norm**: Residual을 더해 다음 layer로 전달

핵심: Attention-only는 FFN·residual·normalization이 없다는 뜻이 아니다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 3, Sec. 3.1 Encoder

## 6. Scaled dot-product attention의 입력

Q와 K는 compatibility를 계산하고 V는 그 weight로 섞을 정보를 담는다


| Symbol | Shape role | 계산에서 하는 일 |
| --- | --- | --- |
| Q | Query rows | 각 위치가 필요한 정보 질의 |
| K | Key rows | Query와 dot product 비교 |
| V | Value rows | Softmax weight로 합산 |
| d_k | Key dimension | Score scaling의 기준 |

핵심: Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 4, Eq. 1 and Sec. 3.2.1

## 7. 숫자로 재현하는 attention

교육용 예시이며 논문의 reported experiment가 아니다: d_k=2, q=[1,0]


| Step | Input | Result | Meaning |
| --- | --- | --- | --- |
| Dot | k1=[1,0], k2=[0,1] | [1, 0] | Compatibility |
| Scale | divide by sqrt(2) | [0.7071, 0] | Large score 완화 |
| Softmax | exp 후 normalize | [0.6698, 0.3302] | Weight 합은 1 |
| Weighted sum | v1=[10,0], v2=[0,10] | [6.698, 3.302] | 두 value의 혼합 |

핵심: Attention output은 가장 큰 value 하나를 고르는 hard selection이 아니다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 4, Eq. 1; arithmetic is a teaching example

## 8. 왜 sqrt(d_k)로 나누는가

독립적인 query/key 성분의 평균이 0, 분산이 1이라는 설명 조건을 따른다

1. **Dot product**: d_k개 component product를 더한다
2. **Variance grows**: 가정 아래 score variance가 d_k가 된다
3. **Large magnitude**: d_k가 크면 unscaled score가 커질 수 있다
4. **Softmax saturation**: 매우 작은 gradient 영역으로 갈 수 있다
5. **Scale**: sqrt(d_k)로 나눠 magnitude를 완화한다

핵심: 이 scaling은 Q와 K vector 자체를 unit norm으로 만드는 연산이 아니다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 4, Sec. 3.2.1 and footnote 4

## 9. Multi-head는 projection을 따로 학습한다

그림에는 8개 중 두 head만 대표로 표시하며 base model은 h=8이다

- **Q, K, V**: 같은 inputs, 다른 learned projections
- **Head 1**: QW1Q, KW1K, VW1V로 attention
- **Head 2**: QW2Q, KW2K, VW2V로 attention
- **Concat(heads)**: 모든 head output을 이어 붙임
- **Projection W^O**: d_model 차원으로 혼합

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, Sec. 3.2.2 and MultiHead equation

## 10. 세 attention의 Q, K, V 출처

Cross-attention만 Q와 K,V가 서로 다른 stack에서 온다


| Mode | Q source | K,V source | Visible positions |
| --- | --- | --- | --- |
| Encoder self | Encoder input | Encoder input | All source |
| Decoder masked | Decoder input | Decoder input | Current and past |
| Cross-attention | Decoder state | Encoder output | All source |

핵심: Cross-attention을 self-attention이라고 부르면 information origin을 잃는다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, Sec. 3.2.3

## 11. Causal mask는 score matrix의 위쪽을 막는다

행은 query position, 열은 key position이며 position은 왼쪽에서 오른쪽으로 증가한다


| Query / Key | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 1 | score | −∞ | −∞ | −∞ |
| 2 | score | score | −∞ | −∞ |
| 3 | score | score | score | −∞ |
| 4 | score | score | score | score |

핵심: Illegal future score를 softmax 전에 −∞로 바꾸면 그 probability는 0이다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, decoder masking description

## 12. Mask와 target shift를 함께 봐야 한다

Training에서도 각 position의 input은 정답 sequence를 한 칸 오른쪽으로 이동한 prefix다

1. **Known target**: Start token과 이전 target tokens
2. **Shift right**: 예측할 token은 decoder input에서 제외
3. **Masked self**: 현재 위치보다 오른쪽 key를 차단
4. **Cross-attention**: Source representations는 모두 참조
5. **Next-token loss**: 해당 위치의 정답 token과 비교

핵심: Mask가 current cell을 허용해도 shift가 정답 token의 직접 노출을 막는다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 3, decoder inputs shifted right, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, masking before softmax

## 13. 순서를 없앤 것이 아니라 별도로 주입했다

Positional encoding은 token embedding과 같은 d_model 차원이며 element-wise로 더한다


| Component | Example role | Combination |
| --- | --- | --- |
| Token embedding | 단어 identity와 learned features | d_model=512 |
| Position vector | Sin과 cos의 여러 frequency | d_model=512 |
| Model input | Token + position | Addition, not concat |
| Alternative tested | Learned position embeddings | Nearly identical result |

핵심: Position vector는 새 token으로 붙는 것이 아니라 embedding에 더해진다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 5-6, Sec. 3.5

## 14. Attention 뒤에는 position-wise FFN이 있다

같은 두-layer network를 각 token position에 독립적으로 적용한다


| Stage | Dimension | Operation |
| --- | --- | --- |
| Input | d_model=512 | 한 position의 vector |
| Linear 1 | 512 → 2048 | xW1 + b1 |
| Activation | d_ff=2048 | ReLU |
| Linear 2 | 2048 → 512 | W2 + b2 |

핵심: FFN parameter는 position 간 공유되지만 layer 간에는 서로 다르다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 5, Eq. 2 and Sec. 3.3, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 8, Table 3 base row

## 15. Training과 inference의 경계

Training layer는 positions를 병렬 계산하지만 inference token 생성은 autoregressive하다

1. **Training batch**: Source와 shifted target sequence 입력
2. **Parallel positions**: Mask 아래 모든 target positions 계산
3. **Softmax loss**: 각 position의 next-token target 비교
4. **Inference**: 생성한 token을 다음 step input에 추가
5. **Beam search**: Paper는 beam 4와 length penalty 0.6 사용

핵심: Layer 내부 parallelism이 output token 사이의 sequential generation을 없애지는 않는다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 2-3, parallelization motivation, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) p. 8, Sec. 6.1 inference settings

## 21. 이 논문이 보장하지 않는 것

Architecture claim과 오늘날 모든 Transformer에 대한 claim을 구분한다


| 오해 | Source-grounded boundary |
| --- | --- |
| Attention만 존재 | FFN·residual·norm·embedding·softmax도 존재 |
| 모든 계산이 parallel | Autoregressive token generation은 sequential |
| O(1)이 total cost | Full attention cost는 O(n^2 d) |
| Head는 고정 문법 기능 | Appendix 그림은 universal guarantee가 아님 |
| 현대 model도 동일 | 2017 encoder-decoder specification의 주장 |

핵심: Attention-only는 recurrent·convolutional sequence layers를 대체했다는 범위의 표현이다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 2-6, architecture and Table 1, [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 13-15, attention visualizations

## 22. 한 token prediction으로 다시 정리

Source context와 target prefix는 서로 다른 attention 경로를 거쳐 다음 token distribution에서 만난다


| Stage | What it preserves | What it changes |
| --- | --- | --- |
| Encoder self | All source positions | Source context |
| Decoder masked self | Known target prefix | Target context |
| Cross-attention | Decoder Q; encoder K,V | Source-target connection |
| FFN and Add & Norm | Per-position pathway | Feature transform |
| Linear and softmax | Decoder final state | Next-token probabilities |

핵심: 기여는 attention 중심 encoder-decoder이며 quadratic cost는 남는다

근거: [arxiv-v7](https://arxiv.org/pdf/1706.03762v7) pp. 3-6, Sec. 3 and Table 1
