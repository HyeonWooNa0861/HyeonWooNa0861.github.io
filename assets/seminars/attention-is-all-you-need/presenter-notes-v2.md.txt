## 3. 문제는 token 계산의 의존 순서였다

3. 문제는 token 계산의 의존 순서였다

발표 대본
논문의 동기는 recurrence가 token position을 따라 sequential dependency를 만든다는 점입니다. Table 1에서 full self-attention은 한 layer 안의 minimum sequential operations와 maximum path length가 O(1)입니다. 그러나 score matrix는 n by n이므로 per-layer cost는 O(n squared d)입니다. 논문은 n이 d보다 작은 조건에서 recurrent layer보다 유리하다고 설명합니다. 따라서 모든 길이에서 무조건 빠르거나 memory가 constant라는 뜻은 아닙니다.

## 5. Encoder layer 하나를 펼쳐 보기

5. Encoder layer 하나를 펼쳐 보기

발표 대본
Encoder layer는 multi-head self-attention과 position-wise feed-forward network의 두 sublayer로 구성됩니다. 각 sublayer 바깥에 residual connection이 있고 그 합을 layer normalization에 넣습니다. 이 구조를 여섯 번 쌓습니다. Attention-only라는 표현은 recurrent 또는 convolutional sequence layer를 쓰지 않는다는 뜻이지, 모델 전체가 attention 연산 하나뿐이라는 뜻은 아닙니다.

## 6. Scaled dot-product attention의 입력

6. Scaled dot-product attention의 입력

발표 대본
논문의 식은 query와 key의 dot product를 compatibility score로 사용합니다. 각 score를 square root of d_k로 나누고 row-wise softmax를 적용해 weight를 만든 뒤 value vectors의 weighted sum을 계산합니다. Q가 질문, K가 주소, V가 내용이라는 말은 교육적 해석이며 별개의 data type을 뜻하지 않습니다.

## 7. 숫자로 재현하는 attention

7. 숫자로 재현하는 attention

발표 대본
q와 k1의 dot product는 1이고 q와 k2는 0입니다. d_k가 2이므로 sqrt 2로 나누면 0.7071과 0입니다. Softmax weight는 약 0.6698과 0.3302입니다. 이를 v1과 v2에 곱해 더하면 6.698과 3.302가 됩니다. 이 예는 계산을 재현하기 위한 것이며 model quality를 입증하지 않습니다.

## 8. 왜 sqrt(d_k)로 나누는가

8. 왜 sqrt(d_k)로 나누는가

발표 대본
논문의 footnote는 query와 key component가 independent random variables이고 mean zero, variance one인 경우를 설명합니다. Dot product의 variance는 d_k가 됩니다. Dimension이 커져 score magnitude가 커지면 softmax가 매우 작은 gradient 영역에 들어갈 수 있습니다. 그래서 score를 sqrt d_k로 나눕니다. 이를 vector normalization이라고 설명하면 다른 연산이 됩니다.

## 9. Multi-head는 projection을 따로 학습한다

9. Multi-head는 projection을 따로 학습한다

발표 대본
각 head는 동일 계산을 복사하는 것이 아니라 Q, K, V에 서로 다른 learned linear projection을 적용합니다. 각 head의 결과를 concatenate한 뒤 W^O로 다시 projection합니다. v7의 정확한 식은 MultiHead equals Concat of heads times W^O입니다. Base model은 8 heads, d_k와 d_v는 각각 64이며 d_model은 512입니다. Head마다 고정된 문법 역할이 보장된다고 말하지 않습니다.

## 10. 세 attention의 Q, K, V 출처

10. 세 attention의 Q, K, V 출처

발표 대본
Encoder self-attention은 Q, K, V가 모두 이전 encoder layer output에서 옵니다. Decoder masked self-attention은 모두 decoder 쪽에서 오지만 future target positions를 가립니다. Cross-attention은 query가 decoder state이고 key와 value는 encoder output입니다. Source는 모두 볼 수 있어도 target future는 masked self-attention에서 계속 차단되므로 decoder의 autoregressive property는 유지됩니다.

## 11. Causal mask는 score matrix의 위쪽을 막는다

11. Causal mask는 score matrix의 위쪽을 막는다

발표 대본
이 표의 convention은 row가 query, column이 key이며 target position이 증가하는 순서입니다. Query 2는 key 1과 2까지만 볼 수 있고 key 3과 4는 future이므로 score를 negative infinity로 바꿉니다. Softmax of zero, zero, negative infinity는 0.5, 0.5, 0이므로 forbidden value는 output에 기여하지 않습니다. Current position 자체는 허용되지만 target embedding을 한 칸 shift하므로 prediction은 아직 모르는 다음 token을 입력으로 받지 않습니다.

## 12. Mask와 target shift를 함께 봐야 한다

12. Mask와 target shift를 함께 봐야 한다

발표 대본
Mask만 단독으로 설명하면 current position을 볼 수 있다는 사실 때문에 혼동이 생깁니다. Decoder input은 output embeddings를 한 position offset한 sequence입니다. 따라서 current decoder cell이 자기 input position을 참조해도 그 input은 예측해야 할 token이 아니라 이전까지 알려진 target prefix입니다. Cross-attention은 source 전체를 볼 수 있지만 target future는 볼 수 없습니다.

## 13. 순서를 없앤 것이 아니라 별도로 주입했다

13. 순서를 없앤 것이 아니라 별도로 주입했다

발표 대본
Recurrence와 convolution이 없으므로 model은 position information을 별도로 받아야 합니다. 논문은 sine과 cosine의 서로 다른 frequency로 positional encoding을 만들고 token embedding에 더합니다. 두 vector는 같은 d_model dimension이라 합할 수 있습니다. Learned positional embeddings도 실험했고 거의 같은 variation result를 보고했지만, 더 긴 길이로 extrapolate할 가능성을 이유로 sinusoidal form을 선택했습니다.

## 14. Attention 뒤에는 position-wise FFN이 있다

14. Attention 뒤에는 position-wise FFN이 있다

발표 대본
Position-wise feed-forward network는 각 position의 vector에 독립적으로 같은 transformation을 적용합니다. v7 base configuration의 d_model은 512, inner d_ff는 2048입니다. 첫 linear layer와 ReLU가 dimension을 확장하고 두 번째 linear layer가 model width로 되돌립니다. Attention이 position 사이 정보를 섞는다면 FFN은 각 position 안의 feature transformation을 담당합니다.

## 15. Training과 inference의 경계

15. Training과 inference의 경계

발표 대본
Training에서는 정답 target을 shift하고 causal mask를 적용해 여러 positions의 layer computation을 병렬화할 수 있습니다. Inference에서는 다음 token을 생성한 뒤 그것을 다음 step의 prefix에 추가해야 하므로 token generation은 sequential합니다. 논문 translation inference는 beam size 4, length penalty alpha 0.6, maximum output length input length plus 50을 사용했습니다. 이는 논문의 평가 조건이지 모든 Transformer의 필수 설정이 아닙니다.

## 21. 이 논문이 보장하지 않는 것

21. 이 논문이 보장하지 않는 것

발표 대본
Transformer의 contribution을 과장하지 않도록 경계를 정리합니다. Full-sequence layer calculation의 parallelism과 autoregressive decoding의 sequentiality는 동시에 참입니다. Maximum path O(1)과 full attention cost O(n squared d)도 서로 다른 측정입니다. Attention visualization은 learned behavior illustration이지 causal explanation proof가 아닙니다. 또한 이 논문에 없는 RoPE, pre-norm, sparse attention, encoder-only 또는 decoder-only variants를 원 논문의 specification처럼 섞지 않습니다.

## 22. 한 token prediction으로 다시 정리

22. 한 token prediction으로 다시 정리

발표 대본
Source tokens는 positional information이 더해진 embedding에서 시작해 encoder self-attention과 FFN을 여섯 layer 통과합니다. Target prefix는 shift와 causal mask 아래 decoder self-attention을 통과합니다. Cross-attention이 decoder query를 encoder key와 value에 연결합니다. Decoder output은 linear transform과 softmax를 거쳐 next-token distribution이 됩니다. 이 구조는 recurrence를 sequence layer에서 제거했지만 full attention의 quadratic score matrix와 autoregressive generation의 순서를 제거하지는 않습니다.
