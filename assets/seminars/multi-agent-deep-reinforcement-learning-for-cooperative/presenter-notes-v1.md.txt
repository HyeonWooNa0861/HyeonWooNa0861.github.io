## 3. P1과 P2는 서로 다른 오프로딩 결정이다

3. P1과 P2는 서로 다른 오프로딩 결정이다

발표 대본
원문의 devise-edge는 문맥상 device-edge를 뜻합니다. P1은 장치가 인접 edge로 보내는 결정이고, P2는 작업을 받은 edge가 이웃 edge와 부하를 나누는 결정입니다. 제안서는 두 단계 사이의 통신 규칙이나 실행 순서를 더 구체적으로 정의하지 않습니다.

## 4. 부분 관측: 각 agent는 전체 시스템의 일부만 본다

4. 부분 관측: 각 agent는 전체 시스템의 일부만 본다

발표 대본
Dec-POMDP에서 각 agent는 전체 상태 전체가 아니라 자신의 observation을 이용합니다. 표의 queue와 channel은 이해를 위한 예시일 뿐, 제안서가 확정한 observation vector가 아닙니다. 또한 부분 관측이 곧 agent 사이의 관측 공유를 뜻하지도 않습니다.

## 5. 다른 agent의 학습이 내 환경을 움직이게 만든다

5. 다른 agent의 학습이 내 환경을 움직이게 만든다

발표 대본
단일 agent 관점에서는 환경의 규칙이 고정되어 있다고 기대하기 쉽습니다. 하지만 여러 agent가 동시에 정책을 바꾸면 공유 부하가 달라지고, 다른 agent가 경험하는 결과 분포도 바뀝니다. 원문은 이를 non-stationarity의 핵심 동기로 제시합니다.

## 6. Dec-POMDP는 문제 틀을 주지만 해법을 완성하지 않는다

6. Dec-POMDP는 문제 틀을 주지만 해법을 완성하지 않는다

발표 대본
제안서는 P1과 P2를 Dec-POMDP로 모델링하겠다고 말합니다. 이것은 부분 관측을 가진 여러 의사결정자를 표현하는 방향입니다. 그러나 중앙 학습 여부, agent 간 메시지, 보상 구조는 별도 설계입니다. 원문에 없는 중앙집중 학습 구조를 그려 넣지 않습니다.

## 7. 후보 알고리즘: 일반 RL 배경과 제안서의 선택을 구분

7. 후보 알고리즘: 일반 RL 배경과 제안서의 선택을 구분

발표 대본
원문이 말하는 사실은 DDPG 또는 D3QN이 후보라는 점입니다. 가운데 열은 별도 원 논문들에 근거한 일반 RL 배경 설명입니다. DDPG는 연속 제어의 deterministic actor–critic이고, D3QN은 Double DQN의 선택·평가 분리와 dueling의 V·A 분해를 함께 쓰는 이산 행동 가치 계열을 뜻합니다. 이 제안서는 action을 정의하지 않았으므로 어느 방법이 최종 선택인지 말할 수 없습니다.
