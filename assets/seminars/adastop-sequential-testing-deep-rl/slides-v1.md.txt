# AdaStop: Deep RL Agent를 공정하게 순차 비교하기

논문: AdaStop: adaptive statistical testing for sound comparisons of Deep RL agents

저자: Timothée Mathieu, Riccardo Della Vecchia, Alena Shilova, Matheus Medeiros Centa, Hector Kohler, Odalric-Ambrym Maillard, Philippe Preux (2024)

## 1. AdaStop: Deep RL Agent를 공정하게 순차 비교하기

seed를 한꺼번에 정하지 않고도 순차적으로 evidence를 모으며 여러 agent를 비교하는 permutation test


근거: [paper](https://arxiv.org/abs/2306.10882) arXiv v3, title page and abstract

## 2. 같은 agent도 실행할 때마다 score가 달라진다

Deep RL 비교의 관측 단위는 한 번의 deterministic 결과가 아니라 독립적으로 훈련한 run의 score다

1. **agent 고정**: 구현과 hyperparameter를 고정
2. **seed 변경**: 독립적인 training run 실행
3. **policy 평가**: 여러 episode의 성능 측정
4. **score 하나**: 한 run의 대표값 생성
5. **분포 비교**: 여러 run의 score를 검정

핵심: 한 번의 높은 score보다 run 사이 변동까지 포함한 분포가 비교 대상이다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 1–4, §§1–2.2, Fig. 1

## 3. 무엇을 고정하고 무엇을 반복하는가

agent·task·score 정의를 먼저 고정해야 seed 추가가 같은 실험의 반복이 된다


| 요소 | 논문에서의 의미 | 주의점 |
| --- | --- | --- |
| agent | 구현과 hyperparameter가 고정된 대상 | seed는 agent 정의가 아님 |
| task | 한 environment에서의 평가 문제 | 여러 task 집계는 범위 밖 |
| run | 독립 seed로 training한 policy 하나 | 독립성 가정이 중요 |
| score | 한 run을 평가한 대표 성능 | MuJoCo에서는 50회 평균 |

핵심: AdaStop은 한 task에서 같은 정의로 생성한 독립 score들을 순차적으로 사용한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 3–7, §§2.1–2.4; p. 36, App. H.2

## 4. 고정 표본 검정은 sample size를 먼저 정한다

예를 들어 agent마다 N개의 score를 모은 뒤 한 번만 permutation test를 수행한다

1. **N 결정**: 수집 전에 표본 수 고정
2. **score 수집**: agent마다 N개 확보
3. **통계량 계산**: 두 집단 차이를 요약
4. **한 번 검정**: 고정 임계값과 비교
5. **결론**: 기각 또는 기각하지 못함

핵심: 고정 검정의 오류 보장은 미리 정한 시점에서 한 번 판단하는 절차에 맞춰져 있다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 8–10, Table 1; §3.2.1

## 5. 반복 검정은 false positive 기회를 늘린다

각 시점에서 같은 fixed-test 기준을 쓰면 전체 실험의 오류율은 한 번의 α보다 커질 수 있다

1. **batch 1**: 고정 검정 기준으로 확인
2. **계속**: 기각이 아니면 score 추가
3. **batch 2**: 같은 기준으로 다시 확인
4. **반복**: 여러 번 false alarm 기회
5. **왜곡**: 전체 type-I error 증가 가능

핵심: 순차 검정은 ‘언제 볼 것인가’까지 포함해 경계를 설계해야 한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 4–5, Fig. 2; pp. 9–11, §3.2.2

## 6. Group-sequential test는 K개 시점을 함께 보정한다

매 interim마다 N개의 새 score를 더하고 누적 통계량을 해당 단계의 boundary와 비교한다

1. **interim k**: agent마다 N개 score 추가
2. **누적 통계량**: 지금까지의 score로 계산
3. **stage boundary**: 전체 K단계를 고려해 보정
4. **crossing**: 넘으면 차이를 기각 판단
5. **continue**: 아니면 다음 batch로 이동

핵심: AdaStop의 adaptive sample usage는 사전에 둔 K와 stage boundary 안에서 이루어진다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 4–5, Fig. 2; pp. 10–11, Alg. 1

## 7. AdaStop의 설계를 이끈 다섯 요구

Deep RL score의 형태와 training 비용을 동시에 고려해야 한다


| 요구 | 필요한 이유 |
| --- | --- |
| nonparametric | score 분포를 Gaussian으로 단정하기 어렵다 |
| sequential | 차이가 분명하면 최대 budget 전에도 멈추고 싶다 |
| multiple testing | 여러 agent의 모든 pair를 함께 비교한다 |
| reproducible | 명시한 N, K, α로 같은 절차를 재현한다 |
| bounded budget | agent당 최대 N×K runs를 넘지 않는다 |

핵심: AdaStop은 permutation, sequential boundary, step-down을 한 절차로 결합한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 2–8, §§1–2.5, Table 1

## 8. 검정의 두 출력은 ‘다름’과 ‘동일함’이 아니다

귀무가설을 기각하지 못하는 것은 equivalence를 증명한 것이 아니다


| 결과 | 말할 수 있는 것 | 말할 수 없는 것 |
| --- | --- | --- |
| H₀ 기각 | 설정한 오류 통제 아래 차이 evidence | 차이의 practical 크기 |
| 기각하지 못함 | 현재 budget에서 crossing 없음 | 두 agent가 같다는 증명 |
| K 도달 | 추가 수집 없이 남은 비교 종료 | 충분한 power가 있었다는 보장 |
| MLB 표시 | 기각 후 empirical mean이 높은 쪽 | 방향 오류 통제 theorem |

핵심: 운영상 accept라는 표현이 있어도 교육적으로는 ‘budget 내 기각하지 못함’으로 읽어야 한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 6–7, §2.5; p. 14, Alg. 3; p. 23, App. B

## 9. FWER, power, p-value는 서로 다른 질문에 답한다

오류 통제와 차이를 찾아내는 능력을 같은 숫자로 읽으면 안 된다


| 개념 | 질문 | AdaStop에서의 역할 |
| --- | --- | --- |
| type-I error | 참인 H₀를 잘못 기각할 확률은? | 단일 오류의 기본 단위 |
| FWER | 여러 참인 H₀ 중 하나라도 오기각할 확률은? | Theorem 1의 핵심 보장 |
| power | 거짓 H₀를 기각할 확률은? | 실험으로 조건별 측정 |
| p-value | 관측 결과가 H₀에서 얼마나 극단적인가? | 반복 .05 비교가 아님 |

핵심: FWER≤α라도 power가 자동으로 높아지는 것은 아니다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 10–11, §3.2.3; pp. 23–24, App. B

## 10. Permutation test: H₀라면 group label을 바꿔도 된다

두 score 집합을 합친 뒤 label을 섞어 관측 차이가 얼마나 극단적인지 평가한다

1. **pool**: A와 B의 score를 합침
2. **permute**: agent label을 다시 배정
3. **statistic**: 각 배정의 차이 계산
4. **reference**: H₀ 아래 분포 구성
5. **compare**: 관측 statistic의 극단성 판단

핵심: 교환 가능성은 ‘두 score distribution이 같다’는 귀무가설에서 나온다

근거: [paper](https://arxiv.org/abs/2306.10882) p. 9, §3.2.1; pp. 24–27, App. C

## 11. 관측 statistic과 permutation boundary를 비교한다

identity permutation의 누적 차이가 permutation max distribution의 상위 경계를 넘는지 본다


| 기호 | 읽는 법 | 역할 |
| --- | --- | --- |
| Tⱼ(id) | 실제 agent labels의 pair j 차이 | 관측 evidence |
| maxⱼ∈C Tⱼ | 현재 비교 집합에서 가장 큰 차이 | multiple-test statistic |
| Bₖ(C) | interim k와 집합 C의 permutation boundary | 오기각 통제 기준 |
| T>B | 관측 max가 boundary를 crossing | 가장 극단 pair 기각 |

핵심: boundary는 고정 상수가 아니라 interim과 남아 있는 비교 집합에 따라 계산된다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 11–14, Eqs. (5)–(10)

## 12. L개 agent는 J=L(L−1)/2개의 pair를 만든다

agent가 늘면 한 번이라도 잘못 기각할 기회도 늘어나므로 pair를 함께 보정한다

1. **L agents**: 같은 task에서 score 수집
2. **all pairs**: J개의 equality hypothesis
3. **active set C**: 아직 결정되지 않은 pairs
4. **max statistic**: C에서 가장 극단 pair 탐색
5. **FWER control**: 전체 family의 오기각 제한

핵심: AdaStop은 pair별 검정을 따로 반복하지 않고 현재 family의 최대값을 사용한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 10–12, §§3.2.3–3.2.4

## 13. Step-down은 가장 극단적인 pair부터 하나씩 제거한다

한 pair를 기각할 때마다 남은 comparison set에 맞춰 max boundary를 다시 계산한다

1. **C 초기화**: 검정할 모든 pair 포함
2. **max 계산**: C의 가장 큰 T 선택
3. **boundary 비교**: max T와 B(C) 비교
4. **기각·제거**: crossing pair를 C에서 제거
5. **재계산**: 남은 C로 다시 검사

핵심: 현재 max가 boundary 이하면 그 interim에서 남은 pair를 더 기각하지 않는다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 11–12, §3.2.4, Alg. 2

## 14. AdaStop을 실행하기 전에 정하는 입력

N과 K는 adaptive procedure의 batch 크기와 최대 길이를 고정한다


| 입력 | 의미 | 해석 경계 |
| --- | --- | --- |
| agents·task | 같은 task에서 비교할 대상 | multi-task aggregation 아님 |
| comparison set | all pairs 또는 관심 pairs | family를 미리 정의 |
| N | interim마다 agent별 새 score 수 | batch size |
| K | 최대 interim 수 | 무한 peeking 방지 |
| α | 목표 family-wise error level | power 목표와 다름 |

핵심: agent당 N×K는 ceiling이며 전체 절차가 일찍 종료되면 더 적게 사용한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 12–14, §4, Alg. 3

## 15. AdaStop의 한 interim은 수집→보정→step-down이다

새 score를 더한 뒤 permutation boundary를 만들고 crossing된 pair만 active set에서 제거한다

1. **batch 수집**: 각 agent마다 N scores
2. **permute**: 누적 score labels 재배정
3. **boundary**: 현재 C의 Bₖ(C) 계산
4. **step-down**: crossing pair 기각·제거
5. **stop·continue**: C가 비거나 다음 k로 이동

핵심: adaptivity는 임의 규칙 변경이 아니라 미리 정의된 loop 안에서 작동한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 12–14, §4, Alg. 3

## 16. 각 pair의 상태는 세 가지로 읽는다

기각된 pair와 아직 active인 pair를 구분해야 stopping을 정확히 설명할 수 있다


| 상태 | 발생 조건 | 다음 동작 |
| --- | --- | --- |
| reject | T가 현재 boundary를 crossing | C에서 제거, 방향은 MLB로 표시 |
| active | 아직 crossing하지 않았고 k<K | 다음 batch에서 다시 검정 |
| budget 종료 | k=K에도 C에 남음 | 기각하지 못함으로 보고 |
| 전체 종료 | C가 비거나 K에 도달 | 절차 종료 |

핵심: stopping은 equality certificate가 아니라 더 수집할지 말지 정하는 operational rule이다

근거: [paper](https://arxiv.org/abs/2306.10882) p. 14, Alg. 3; p. 23, App. B.1

## 17. 모든 permutation을 열거하지 않아도 된다

독립적으로 고른 permutation subset과 identity를 사용해 boundary를 근사할 수 있다


| 구현 항목 | 논문 지침 | 영향 |
| --- | --- | --- |
| subset 선택 | data와 독립적으로 random 선택 | 오류 통제 조건 유지 |
| identity | subset에 반드시 포함 | 관측 labeling 보존 |
| 개수 B | 실험에서는 주로 10⁴ | 작으면 power 저하 가능 |
| discreteness | 가능한 quantile가 제한됨 | 실제 error가 α보다 작을 수 있음 |

핵심: 작은 N과 K에서는 permutation discreteness 때문에 검정이 매우 보수적일 수 있다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 13–14, §4; p. 17, Table 2 remark

## 18. Theorem 1: distribution equality의 strong FWER

참·거짓 pair가 섞여 있어도 참인 distribution-equality hypotheses의 오기각 family를 통제한다


| 항목 | Theorem 1의 범위 |
| --- | --- |
| 귀무가설 | 각 pair의 score distributions가 동일 |
| 대립가설 | 두 score distributions가 다름 |
| 보장 | 적어도 하나의 참인 H₀를 기각할 확률 ≤ α |
| 강도 | true·false hypotheses의 어떤 구성에서도 strong control |
| 기반 | permutation invariance와 step-down monotonicity |

핵심: finite-sample 핵심 보장은 평균이 아니라 score distribution equality에 대한 것이다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 14–15, Theorem 1; pp. 24–28, App. C

## 19. Theorem 2: mean 비교는 finite-sample exact가 아니다

finite variance 아래 N이 커질 때 두-sample mean test의 type-I error가 α로 수렴한다


| 구분 | distribution equality | mean equality |
| --- | --- | --- |
| 귀무가설 | P=Q | Eₚ[X]=Eᵩ[X] |
| 표본 보장 | non-asymptotic FWER | asymptotic type-I error |
| 추가 조건 | permutation invariance | 양쪽 finite variance |
| 주의 | shape 차이도 reject 가능 | 작은 N의 exact mean 보장 아님 |

핵심: 평균 순위로 해석할 때에는 distribution test와 mean theorem의 범위를 분리해야 한다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 6–7, §2.4; pp. 14–15, Theorem 2

## 20. 강의용 가상 예시: A, B, C 세 agent 비교

아래 흐름은 algorithm을 이해하기 위한 invented trace이며 논문 실험 수치가 아니다


| 설정 | 가상 값 | 역할 |
| --- | --- | --- |
| agents | A, B, C | 세 pair를 동시에 검정 |
| comparison set | C₀={AB, AC, BC} | 아직 결정되지 않은 pairs |
| batch | N=2 | interim마다 agent별 score 두 개 |
| maximum | K=3 | agent당 최대 6 scores |
| boundary | permutation으로 계산 | 숫자는 의도적으로 만들지 않음 |

핵심: 가상 trace의 목적은 statistic 숫자가 아니라 active set이 변하는 순서를 보는 것이다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 12–14, Alg. 3; teaching trace derived from procedure

## 21. 가상 interim 1: 어떤 pair도 boundary를 넘지 못했다

첫 batch만으로 차이를 선언하지 않고 active set 전체를 다음 interim으로 넘긴다

1. **scores 추가**: A, B, C에 각 2개
2. **statistics**: AB, AC, BC 누적 T 계산
3. **max pair**: 가장 큰 T를 선택
4. **below boundary**: max T≤B₁(C₀)
5. **continue**: C₁={AB, AC, BC}

핵심: 기각하지 못했다는 것은 첫 batch에서 evidence가 부족하다는 뜻이지 equality가 아니다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 12–14, Alg. 3; teaching trace derived from procedure

## 22. 가상 interim 2: AC를 기각한 뒤 남은 set을 재검정

가장 큰 pair 하나를 제거하고 같은 interim에서 step-down boundary를 다시 계산한다

1. **scores 추가**: agent별 누적 4개
2. **AC crossing**: T_AC>B₂(C₁)
3. **AC 제거**: C′={AB, BC}
4. **recompute**: B₂(C′)와 새 max 비교
5. **continue**: 나머지는 next interim

핵심: step-down은 하나를 기각한 뒤 이전 boundary를 그대로 재사용하지 않는다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 11–14, Algs. 2–3; teaching trace derived from procedure

## 23. Toy experiment: mean과 distribution 차이를 분리한다

세 constructed cases에서 rejection frequency를 반복 측정해 검정의 성격을 확인한다


| 조건 | 보고된 값 |
| --- | --- |
| batch·interims | N=5, K=5 |
| error level | α=.05 |
| permutations | B=10⁴ |
| 반복 | 각 comparison M=5,000회 |
| 변화량 | mixture separation Δ를 0부터 1까지 변화 |

핵심: 실험은 distribution shape가 결정에 미치는 영향을 보여 준다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 15–16, §5.1, Fig. 4

## 24. Toy 결과: 같은 mean, 다른 distribution shape

AdaStop의 finite-sample distribution test와 asymptotic mean 해석이 다른 이유가 드러난다


| case | 구성 | 관찰 |
| --- | --- | --- |
| 1 | 대칭 mixture, 같은 mean | rejection이 대체로 .05 근처 |
| 2 | mean이 Δ에 따라 분리 | Δ>.6에서 power가 거의 1 |
| 3 | rare high mode, 같은 mean | 극단에서 rejection 약 .2 |
| 해석 | 분포 동일성 검정 | mean equality만 묻는 검정과 다름 |

핵심: 분포 차이 기각을 곧바로 평균 차이 기각으로 바꾸어 말하면 안 된다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 15–16, §5.1, Fig. 4

## 25. SAC–TD3 비교: 최대 20개 중 평균 12.08개 사용

HalfCheetah score data에서 N=4,K=5 설정은 power .82와 adaptive sample 절약을 함께 보였다

명확한 차이는 일찍 결정되었고 구분하기 어려운 pair는 최대 budget까지 남는 경향을 보였다


| 관찰 | 보고된 예 | 해석 경계 |
| --- | --- | --- |

| 최대 사용 | 일부 agent-task는 30 scores | equality 증명 아님 |

## 28. Appendix F의 early accept는 별도 heuristic이다

작은 statistic이 β-boundary 아래이면 비슷한 pair를 일찍 제거해 이후 training을 줄인다

1. **current min**: active pairs 중 작은 T 선택
2. **lower boundary**: β 기반 B 아래인지 확인
3. **early accept**: 해당 pair를 C에서 제거
4. **score 절약**: 다음 interims에서 생략 가능
5. **현재 한계**: 일반 guarantee는 future work

핵심: Walker2d-v3의 10-score 결과는 한 사례이며 일반 theorem이 아니다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 32–33, App. F, Alg. 4

## 29. Theorem 1의 proof는 세 층으로 구성된다

interim 오류 배분, permutation invariance, step-down monotonicity가 strong FWER로 이어진다

1. **simple case**: L=2,K=1 permutation bound
2. **sequential**: interims의 error를 합산
3. **weak FWER**: 모든 H₀가 참인 경우 통제
4. **step-down**: true subset의 boundary 단조성
5. **strong FWER**: 어떤 true·false 구성도 통제

핵심: 핵심 조건은 permutation invariance와 사전 정의한 sequential boundary다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 24–32, Apps. C–E

## 30. AdaStop이 해결하지 않은 문제

오류 통제의 범위와 실험의 범위를 넘는 해석을 피해야 한다


| 한계 | 현재 상태 |
| --- | --- |
| multi-task comparison | 서로 다른 game/task 집계는 open problem |
| early equivalence | 보장된 early accept·equivalence test가 아님 |
| mean finite sample | finite variance 아래 asymptotic result |
| power guarantee | condition별 empirical evaluation 중심 |
| directional error | MLB 방향의 type-III error 미통제 |

핵심: AdaStop은 sequential rejection을 제공하지만 모든 비교 질문을 풀지는 않는다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 5–8, §§2.3–2.5; pp. 18–19, §6

## 31. AdaStop 결과를 읽는 다섯 질문

실험의 통계적 의미와 계산 절약을 동시에 확인한다


| 확인 질문 | 올바른 읽기 |
| --- | --- |
| 무엇을 비교했나? | 한 task의 독립 run score distributions |
| 무엇을 통제했나? | true pairs 중 하나라도 오기각할 FWER |
| 무엇을 찾았나? | boundary를 crossing한 differences |
| 얼마나 썼나? | 실제 count와 maximum N×K를 구분 |
| 남은 pair는? | 동등 판정이 아니라 budget 내 non-rejection |

핵심: 핵심은 adaptive stopping 중에도 오류 해석을 지키는 것이다

근거: [paper](https://arxiv.org/abs/2306.10882) pp. 12–19, §§4–6; Apps. B and F
