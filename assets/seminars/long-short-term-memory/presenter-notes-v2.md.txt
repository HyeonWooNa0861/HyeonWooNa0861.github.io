2. 긴 지연 문제의 구조

## 3. Recurrent gradient는 반복 곱으로 변한다

3. Recurrent gradient는 반복 곱으로 변한다

발표 대본

## 4. CEC는 상태와 error에 factor 1을 제공한다

4. CEC는 상태와 error에 factor 1을 제공한다

발표 대본
Constant error carousel은 identity activation을 쓰는 linear state unit과 weight 1.0의 delayed self-connection으로 구성됩니다. 시간축으로 펼치면 상태가 매 단계 같은 factor one을 통과합니다. Appendix 식 35는 truncated backprop 아래에서 내부 state error의 step derivative가 approximately one임을 보입니다. 전체 network의 모든 gradient가 constant라는 뜻은 아닙니다.

## 5. Bare CEC에는 쓰기와 읽기 충돌이 남는다

5. Bare CEC에는 쓰기와 읽기 충돌이 남는다

발표 대본
원 논문은 먼저 gate가 없는 CEC를 생각한 뒤 두 weight conflict를 지적합니다. Input weight는 특정 신호를 저장하면서 뒤의 무관한 입력에는 반응하지 않아야 합니다. Output weight는 필요할 때 기억을 사용하면서 다른 시점에는 이미 잘 작동하는 출력을 방해하지 않아야 합니다. 이 충돌을 분리하기 위해 input gate와 output gate를 도입합니다.

## 9. 거리와 gradient scaling의 차이

9. 거리와 gradient scaling의 차이

발표 대본
Ordinary path 행은 매 step factor zero point nine를 가정한 교육용 비교입니다. CEC 내부에서는 truncated rule 아래에서 state-to-state derivative가 approximately one이므로 time lag length만큼 작은 factor가 반복되지 않습니다. 그러나 error가 cell output으로 들어올 때 output gate와 h prime에 의해 scaling되고, cell input으로 나갈 때 input gate와 g prime에 의해 다시 scaling됩니다. 이 경계 factor는 존재하지만 lag length만큼 반복되지는 않습니다.

## 10. Truncated gradient가 유지하고 끊는 경로

10. Truncated gradient가 유지하고 끊는 경로

발표 대본
Section 4와 Appendix는 cell net input, input gate net, output gate net에서 더 이전 recurrent activity로 향하는 derivative를 truncate합니다. 그 위치의 incoming weights는 현재 error로 여전히 바뀝니다. 동시에 internal state에 대한 sensitivity는 이전 state로 계속 전달됩니다. 저자들은 이를 altered multiplicative dynamics를 반영한 RTRL variant로 설명하며 ordinary full BPTT와 구분합니다.

## 11. 원 논문의 learning update 흐름

11. 원 논문의 learning update 흐름

발표 대본
LSTM을 cell equation만으로 설명하면 1997년 논문의 핵심 절반을 놓칩니다. Forward pass는 gate와 internal state를 계산합니다. 학습에서는 각 weight에 필요한 recent internal-state derivative만 저장합니다. 현재 output error가 CEC에 들어온 뒤 내부에서 유지되고, incoming weight update에 쓰인 다음 외부 recurrent path로 더 넘어가려는 gradient는 truncate합니다.

## 12. O(1)은 전체 학습 시간이 아니다

12. O(1)은 전체 학습 시간이 아니다

발표 대본
초록의 O one 표현은 weight 하나와 time step 하나당 계산 복잡도입니다. Appendix 식 29는 전체 per-step update가 O of W임을 보입니다. 저장해야 하는 derivative도 O of W이며 input sequence length에는 의존하지 않습니다. 이는 training 전체가 constant time이라는 뜻이 아니고, 실제 실험은 수만에서 수십만 training sequences를 사용합니다.

## 13. Memory cell block과 network topology

13. Memory cell block과 network topology

## 14. 1997년 원형에 포함되지 않은 요소

14. 1997년 원형에 포함되지 않은 요소

발표 대본
이 표는 역사적 경계를 정리합니다. 1997년 설계는 CEC의 state factor와 internal derivative를 one으로 고정하려 했으므로 learned forget factor를 두지 않았습니다. ## 15. Original LSTM과 later standard LSTM

15. Original LSTM과 later standard LSTM

발표 대본
Later common LSTM은 f_t를 곱해 previous state를 유지하거나 줄입니다. Original 1997 cell은 previous state를 그대로 더하며 별도 forget gate가 없습니다. 따라서 CEC를 단순히 forget gate가 one인 modern cell로 설명하면 forward 식만 닮은 특수 경우처럼 보이고, original truncated learning rule과 역사적 설계 이유를 놓칩니다. Odyssey 논문은 이 variant history를 정리합니다.

## 23. 한계 2: state drift와 output saturation

23. 한계 2: state drift와 output saturation

26. 원 논문을 정확히 설명하는 문장
