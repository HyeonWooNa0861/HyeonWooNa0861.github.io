## 1. Consecutive Temporal Pointing의 사용자 수행

1. Consecutive Temporal Pointing의 사용자 수행

발표 대본

## 2. 한 번의 timing 입력과 두 번의 연속 입력

2. 한 번의 timing 입력과 두 번의 연속 입력

## 4. CTP taxonomy는 어느 입력에 시간 조건이 있는가로 나뉜다

4. CTP taxonomy는 어느 입력에 시간 조건이 있는가로 나뉜다

발표 대본

## 15. σ₁은 기존 경향을 따랐지만 σ₂는 맞지 않았다

## 17. Activation point와 짧은 interval의 motor trade-off

17. Activation point와 짧은 interval의 motor trade-off

발표 대본
KeyPressed는 finger가 button floor의 충격을 느끼는 activation point와 정렬되어 높은 precision을 보였습니다. 그러나 Press-Press로 두 번 입력하려면 Down-Up-Down 세 단계가 필요하고, Press-Release는 Down-Up 한 번으로 두 event를 만듭니다. 그래서 TTS가 150밀리초보다 짧은 Press-Press 조건에서는 두 번째 입력이 늦어지는 motor limitation이 나타났습니다.
