# QuaRot: 회전된 LLM의 W4A4KV4 추론

논문: QuaRot: Outlier-Free 4-Bit Inference in Rotated LLMs

저자: Saleh Ashkboos et al. (2024)

## 1. QuaRot: 회전된 LLM의 W4A4KV4 추론

Primary technical text: arXiv:2404.00456v2 · orthogonal basis change 뒤 weight·activation·KV cache를 4-bit로 양자화한다


근거: [arxiv-record](https://arxiv.org/abs/2404.00456) Version history: v2 dated 29 Oct 2024, [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 1, abstract

## 2. 문제에서 해법까지의 한 줄

Coordinate outlier가 shared low-bit range를 지배하는 문제를 representation change로 완화한다


| Stage | Problem or action | Boundary |
| --- | --- | --- |
| Outlier | 몇 coordinate만 매우 큼 | 4-bit scale을 소비 |
| Rotation | Randomized Hadamard로 혼합 | 값별 rescaling 아님 |
| Compensation | 인접 weight도 함께 변환 | FP function 보존 |
| Quantization | W4A4KV4 적용 | Clipping·rounding error 존재 |
| Kernel | INT4 GEMM과 cache 활용 | 모든 연산이 INT4는 아님 |

핵심: QuaRot은 Hadamard가 GPTQ를 대체하는 방법이 아니라 rotation 뒤 PTQ를 적용하는 방법이다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 1-3, motivation and overview, [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 7-8, quantization and results

## 3. 하나의 큰 coordinate가 4-bit range를 지배한다

교육용 row [0.2, 4.0, −0.1, 0.1]에서 max magnitude는 4.0이다

1. **Activation row**: [0.2, 4.0, −0.1, 0.1]
2. **Shared scale**: Symmetric INT4는 row max로 scale 결정
3. **Range usage**: 4.0이 positive endpoint를 차지
4. **Small coordinates**: 0 근처 값은 적은 quantization levels 사용
5. **Error pressure**: Rounding으로 상대 오차가 커질 수 있음

핵심: Outlier-free는 rotated distribution을 뜻하며 quantization error는 남는다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 2, Fig. 1 and outlier discussion

## 4. 2차원 normalized Hadamard를 직접 계산한다

교육용 예시이며 reported experiment가 아니다: H=(1/sqrt(2))[[1,1],[1,−1]]


| Object | Row 1 | Row 2 | Check |
| --- | --- | --- | --- |
| H | [1, 1] / sqrt(2) | [1, −1] / sqrt(2) | Orthogonal rows |
| H^T H | [1, 0] | [0, 1] | Identity I |
| x | [4, 0] | xH=[2sqrt(2),2sqrt(2)] | Max 4 → 2.828 |
| w | [3, 1]^T | H^T w=[2sqrt(2),sqrt(2)]^T | Compensated |

핵심: H^T H=I이므로 activation과 weight를 함께 바꾸면 output이 보존된다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 3, randomized Hadamard definition; arithmetic is illustrative

## 5. 회전 전후 dot product는 12로 같다

x와 w 양쪽을 일관되게 변환해야 equality가 성립한다


| Path | Activation | Weight | Output |
| --- | --- | --- | --- |
| Original | x=[4,0] | w=[3,1]^T | xw=12 |
| Rotated | xH=[2sqrt(2),2sqrt(2)] | H^T w=[2sqrt(2),sqrt(2)]^T | 8+4=12 |
| Identity used | xH | H^T w | xHH^T w=xw |

핵심: 회전 보존성은 quantization 전 full-precision algebra에 대한 statement다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 3-5, orthogonal transformations; arithmetic is illustrative

## 6. Quantization error는 별도의 단계에서 생긴다

교육용 unclipped symmetric INT4 예시: qmax=7, scale=max(abs(z))/7=4/7


| Item | Value | Result |
| --- | --- | --- |
| FP row z | [4, 0.4, −0.2, 0.1] | Max magnitude 4 |
| Integer code | round(z / 0.5714) | [7, 1, 0, 0] |
| Dequantized | code × 0.5714 | [4, 0.5714, 0, 0] |
| Error | dequantized − z | [0, 0.1714, 0.2, −0.1] |

핵심: Orthogonal equality와 low-bit error는 서로 다른 단계다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 7, activation quantization rule; arithmetic is illustrative

## 7. Transformer에서 rotation을 합법화하는 조건

RMSNorm scale을 adjacent weights에 흡수한 norm-only form에서 commutation을 사용한다


| Condition | Operation | Meaning |
| --- | --- | --- |
| Orthogonal Q | QQ^T=I | Inverse cancellation |
| RMSNorm scale | alpha를 weights에 흡수 | Norm-only relation 사용 |
| Commutation | RMSNorm(X)=RMSNorm(XQ^T)Q | Residual basis 이동 |
| Exact scope | Before clipping and quantization | FP function 보존 |
| Implementation | Factors를 weights에 fuse | Runtime matmul 제거 가능 |

핵심: Eq. 3은 arbitrary normalization이나 finite-precision pipeline 전체의 equality가 아니다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 4, Eq. 3 and RMSNorm simplification

## 8. Global residual-stream rotation은 weight에 bake한다

Q=H diag(s)를 고르고 block 경계의 representation을 XQ basis로 바꾼다

1. **Choose Q**: Randomized Hadamard H diag(s)
2. **Residual basis**: X를 XQ representation으로 해석
3. **Input weights**: Q^T diag(alpha) W 형태로 fuse
4. **Output weights**: Output-side matrix에 Q를 fuse
5. **Runtime result**: 별도 global Q matmul 없이 rotated state 유지

핵심: Fusion은 별도 runtime matmul을 없애지만 rotation의 역할은 남는다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 4-5, Eq. 3-4 and global rotation

## 9. FFN 경로 1: gate product까지

첫 장의 출력 상태 FP16 gated activation이 다음 장의 입력 상태와 정확히 같다

- **레인 Up path**
- **레인 Gate path**
  - **XQ**: FP16 rotated input
  - **RMSNorm**: FP32; alpha fused
  - **Quantize**: Per-token INT4
  - **Up GEMM**: INT4; INT32 acc
  - **Gate GEMM**: INT4; INT32 acc
  - **FP16 gated act**: Nonlinear product
- XQ → RMSNorm (실선, 단방향)
- RMSNorm → Quantize (실선, 단방향)
- Quantize → Up GEMM (실선, 단방향)
- Quantize → Gate GEMM (실선, 단방향)
- Up GEMM → FP16 gated act (실선, 단방향)
- Gate GEMM → FP16 gated act (실선, 단방향)

핵심: Gating nonlinearity 때문에 FFN 내부 rotation 전체를 neighboring weights로 넘길 수 없다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 5, Fig. 3 first half

## 10. FFN 경로 2: online H와 down projection

FP16 gated activation에서 시작해 online full-precision Hadamard를 실제 runtime에 수행한다

- **레인 Down path**
  - **FP16 gated act**: Linked intermediate
  - **Hadamard H**: Online FP32
  - **Quantize**: Activation INT4
  - **HWdownQ GEMM**: INT4; INT32 acc
  - **YQ**: Recovered FP16
- FP16 gated act → Hadamard H (실선, 단방향)
- Hadamard H → Quantize (실선, 단방향)
- Quantize → HWdownQ GEMM (실선, 단방향)
- HWdownQ GEMM → YQ (실선, 단방향)

핵심: Stored down matrix는 HWdownQ이고 그 앞의 activation Hadamard는 runtime cost를 가진다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 5, Fig. 3 second half

## 11. Fused rotation과 online rotation을 구분한다

수식에 H나 Q가 보인다고 모두 별도 runtime matrix multiplication인 것은 아니다


| Location | Treatment | Runtime transform |
| --- | --- | --- |
| Residual stream | Factors fused into weights | No separate global matmul |
| FFN internal | H fused into Wdown | Activation H remains online |
| Attention V/out | Head transforms paired | Head mixing may be online |
| Post-RoPE Q,K | Same head-wise H | Both run online |
| KV cache | Rotated K,V quantized | Quant/dequant remains |

핵심: Speed benefit은 fusion과 custom kernel의 조합에서 나온다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 5-7, FFN and attention rotations

## 12. Attention value와 output projection의 paired rotation

각 head의 value basis change를 output projection의 inverse-side factor가 보상한다

1. **Value projection**: Per-head Wv is post-multiplied by H_dh
2. **Rotated values**: Head value coordinates가 mixed basis로 이동
3. **Attention blend**: 같은 attention weights로 values를 합산
4. **Output projection**: Per-head Wout is pre-multiplied by H_dh
5. **Preserved output**: Paired orthogonal factors가 cancel

핵심: V만 회전하고 output projection을 그대로 두면 원래 attention output의 보존 설명이 깨진다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 6, Eqs. 7-9

## 13. Attention의 Q·K·V rotation과 KV cache

Q·K의 H는 RoPE 뒤 online 연산이고, V의 head H는 projection weight에 합쳐진다

- **레인 Query**
- **레인 Key**
- **레인 Value**
  - **Q post-RoPE**: FP16 query
  - **Online H**: QH / FP16
  - **Score equality**: QH(KH)^T = QK^T
  - **K post-RoPE**: New key token
  - **Online H**: Same head basis
  - **KH**: Rotated key
  - **K cache**: Groupwise INT4
  - **Value input**: Input to projection
  - **Fused Wv H_dh**: Rotated value output
  - **V cache**: Groupwise INT4
- Q post-RoPE → Online H (실선, 단방향)
- Online H → Score equality (실선, 단방향)
- K post-RoPE → Online H (실선, 단방향)
- Online H → KH (실선, 단방향)
- KH → Score equality (실선, 단방향)
- KH → K cache (실선, 단방향)
- Value input → Fused Wv H_dh (실선, 단방향)
- Fused Wv H_dh → V cache (실선, 단방향)

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 6, Stage 1c; Eqs. 7-9 and 13-14

## 14. KV cache는 rotated K와 V를 4-bit로 저장한다

Post-RoPE caching을 택해 decode step마다 새 token의 Q와 K만 회전한다

1. **New token**: Post-RoPE Q,K에 head-wise H 적용
2. **Cache write**: Rotated K,V를 groupwise INT4 저장
3. **Decode query**: Q는 FP16으로 유지
4. **Cache read**: K,V segments를 FP16으로 dequantize
5. **Attention**: FP16 dot products와 online softmax 수행

핵심: KV4는 cache format이며 attention score path 전체가 INT4는 아니다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 6-7, cache placement and attention computation

## 15. W4A4KV4의 실제 precision contract

4-bit storage와 operands 사이에도 normalization, accumulation, rescale이 더 높은 precision으로 남는다

1. **RMSNorm**: FP32
2. **Linear operands**: INT4 activations and weights
3. **GEMM accumulate**: INT32
4. **Recovered signal**: Scale 적용 뒤 FP16; online H는 default FP32
5. **KV storage**: INT4; Q와 dequantized cache dot은 FP16

핵심: Outlier channel을 남기지 않아도 FP16·FP32 연산은 남는다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 5 and 7; Appendix p. 16, precision details

## 16. Weight·activation·KV는 서로 다른 quantizer를 쓴다

One global 4-bit scale이라는 설명은 실제 implementation을 지운다


| Target | Method | Scale or clipping | Default role |
| --- | --- | --- | --- |
| Weights | Symmetric per-column GPTQ | Clip searched by squared error | Main W4 result |
| Activations | Symmetric per-token row | max(abs(row))/7; clip 0.9 | Online linear input |
| KV cache | Asymmetric groupwise | group 128; clip 0.95 | K,V storage |
| Weights RTN | Round-to-nearest | No calibration | Ablation baseline |

핵심: Rotation 뒤에도 default weight PTQ인 GPTQ가 필요하다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) p. 7, Quantization section

## 17. Rotation 뒤에도 GPTQ와 RTN은 같은 결과가 아니다

둘은 같은 rotated weights에서 출발하지만 reconstruction 방법과 calibration이 다르다

- **Rotated weights**: QuaRot basis에서 weight PTQ 시작
- **GPTQ**: Calibration과 Hessian-informed reconstruction
- **RTN**: Calibration 없이 nearest level로 rounding
- **LLaMA-2 70B · W4 PPL**: GPTQ 3.79 / RTN 4.14
- **Rotation과 quantizer**: Rotation만으로 같은 성능은 아니다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 7-9, Tables 1 and 3, [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) Appendix p. 15, RTN ablation

## 23. 작은 decode batch에서는 더 느릴 수도 있다

Quantize와 dequantize overhead가 arithmetic saving보다 클 수 있는 구간이 있다


| Regime | Benefit | Overhead | Observed boundary |
| --- | --- | --- | --- |
| Large cache pressure | INT4 memory traffic 감소 | Quant/dequant 추가 | Memory saving 유지 |
| Low batch decode | 작은 GEMM workload | Conversion cost 비중 증가 | FP16보다 느릴 수 있음 |
| Conclusion | Kernel-dependent | Batch-dependent | Universal speedup 아님 |

핵심: Compression ratio와 latency speedup은 같은 metric이 아니다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) Appendix p. 20, low-batch decoding results

## 25. 아무 orthogonal rotation이나 같은 것은 아니다

| Rotation | PPL | Comparison | Boundary |
| --- | --- | --- | --- |
| Randomized Hadamard | 6.10 | Main choice | Structured and fast |
| Random orthogonal | 7.45 | Worse in Table 8 | Still orthogonal |
| No universal claim | — | Dimension and choice matter | Empirical evidence |

핵심: Orthogonality만으로 quantized accuracy와 runtime이 같아지지는 않는다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) Appendix p. 15, Table 8

## 26. QuaRot이 quantization landscape에서 차지하는 위치

핵심 action과 retained precision target을 구분하면 method를 같은 것으로 묶지 않게 된다


| Family | Core action | QuaRot과의 차이 |
| --- | --- | --- |
| GPTQ | Weight reconstruction PTQ | QuaRot 뒤 default weight quantizer |
| OWQ or AWQ style | Selected channels 유지·보호 | QuaRot은 rotated W,A,KV target |
| SmoothQuant | Feature scaling for W8A8 | Orthogonal W4A4KV4가 아님 |
| QuIP family | Weight incoherence 중심 | QuaRot은 activation과 KV도 처리 |
| KV-only | Cache K,V compression | QuaRot은 W,A,KV를 함께 조정 |

핵심: QuaRot은 representation change와 여러 PTQ components를 결합한 end-to-end scheme이다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 2-3, related work, [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 6-7, W4A4KV4 method

## 27. QuaRot의 기여와 한계

Coordinate basis를 바꾸어 4-bit quantizer가 다루기 쉬운 representation을 만든다


| Claim | Supported reading | Not supported |
| --- | --- | --- |
| Invariance | Compensated FP rotation은 function 보존 | Quantized bit-exact equality |
| Outlier-free | Rotated coordinate concentration 완화 | Zero quantization error |
| W4A4KV4 | Weights, linear inputs, cache는 INT4 | Every operation INT4 |
| Performance | Custom-kernel block benchmark 개선 | Universal end-to-end speedup |
| Accuracy | Strong LLaMA-2 evidence | All model families lossless |

핵심: Rotation은 PTQ를 돕지만 quantizer·kernel·model 조건은 남는다

근거: [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) pp. 4-9, method and results, [arxiv-v2](https://arxiv.org/pdf/2404.00456v2) Appendix pp. 15-21, ablations and performance
