# YAQA: 모델 출력을 보존하는 적응형 반올림

논문: Model-Preserving Adaptive Rounding

저자: Albert Tseng, Zhaofeng Sun, Christopher De Sa (2026)

## 1. YAQA: 모델 출력을 보존하는 적응형 반올림

quantizer는 그대로 두고, full-model KL Hessian의 Kronecker 근사로 rounding 결정을 바꾼다


근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) title page, abstract, arXiv v3 footer

## 2. LLM 배포에서 양자화가 맡는 일

고정밀도 weight를 적은 bit로 표현해 memory traffic과 지원 hardware의 계산량을 줄인다

1. **원본 모델**: 수십억 개 고정밀도 weight
2. **low-bit 표현**: weight마다 representable point 선택
3. **압축 모델**: 작은 storage와 memory bandwidth
4. **보존 목표**: 출력 분포가 원본과 가까워야 함

핵심: 압축률만 맞추는 것이 아니라 어떤 rounding이 원본 model behavior를 덜 바꾸는지가 문제다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 1, abstract and §1

## 3. quantizer와 rounding algorithm은 다르다

표현 가능한 값의 집합과 그 집합으로 보내는 결정은 분리된 구성요소다


| 구성요소 | 정하는 것 | 예시 | inference에 미치는 영향 |
| --- | --- | --- | --- |
| quantizer | representable point와 code | E8P, QTIP, INT4 | datatype·decode·kernel 형식 |
| rounding | 각 weight가 받을 point | LDLQ, YAQA | 같은 format 안의 code 선택 |
| YAQA의 위치 | rounding만 교체 | quantizer-independent | 추가 format overhead 없음 |
| 남는 비용 | Hessian 추정과 반복 | offline calibration | 추론 전 준비 비용은 증가 |

핵심: YAQA의 결과는 선택한 quantizer가 표현할 수 있는 값 밖으로 나가지 않는다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 1, §1 quantizer and rounding distinction

## 4. 목표는 원본 출력 분포와의 KL을 줄이는 것

입력 X마다 원본 M과 양자화 모델 Mq의 전체 output distribution을 비교한다

1. **입력 X**: data distribution에서 sample
2. **원본 M**: output distribution 생성
3. **양자화 Mq**: 같은 입력의 output 생성
4. **KL objective**: 기댓값이 작은 quantized weight 선택

핵심: model-preserving은 정답 label만 맞추는 것이 아니라 전체 출력 분포를 가깝게 두는 목표다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 1, Eqs. 1–2

## 5. immediate activation error는 왜 proxy인가

한 layer 출력을 바로 맞추는 것과 이후 모든 layer를 지난 model output을 맞추는 것은 다르다


| 관점 | 측정 대상 | 장점 | 놓치는 것 |
| --- | --- | --- | --- |
| LDLQ/GPTQ | 현재 layer의 output error | forward input으로 계산 가능 | 후속 layer의 증폭·상쇄 |
| YAQA 목표 | full-model output KL | model behavior와 직접 연결 | 정확 계산은 너무 큼 |
| Hessian 의미 | rounding error의 민감 방향 | second-order 중요도 제공 | 근사의 질에 의존 |
| 핵심 차이 | H1 대 full H | tractability 대 fidelity | 둘은 같은 objective가 아님 |

핵심: local error가 작아도 후속 layers를 거친 최종 분포가 더 가까워진다고 보장되지 않는다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 1–2, Eq. 2 and local activation proxy

## 6. full Hessian은 그대로 저장할 수 없다

m by n weight matrix를 펼치면 민감도 행렬 H는 mn by mn이 된다


| object | shape | 역할 | scale 문제 |
| --- | --- | --- | --- |
| weight W | m by n | 한 linear layer | mn parameters |
| local H1 | n by n | input-channel sensitivity | LDLQ가 저장 가능 |
| true H | mn by mn | full-model KL curvature | 직접 연산·저장 불가 |
| YAQA factors | m by m + n by n | output·input 구조 근사 | O(m²+n²) storage |

핵심: YAQA의 핵심 압축은 weight가 아니라 Hessian을 두 작은 factor로 표현하는 데서 시작한다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 1, 4, Eq. 2 and §3.1.2

## 7. LDLQ는 input channel 방향으로 error를 넘긴다

한 번의 update를 왼쪽에서 오른쪽으로 펼치면 input-side feedback만 남는다

- **레인 LDLQ update**
  - **원본 W***: quantizer Q에 입력
  - **현재 Wq**: 선택된 codebook 값
  - **error Δ**: W* − Wq
  - **다음 quantize**: Q(W* + ΔL'I)
- 원본 W* → 현재 Wq (실선, 단방향)
- 현재 Wq → error Δ (실선, 단방향)
- error Δ → 다음 quantize (실선, 단방향)

핵심: L'I는 H1의 LDL factor에서 오며, 이미 생긴 error가 뒤 input-channel 결정을 바꾸게 한다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 2–3, Eq. 3 and Lemma 3.2

## 8. SND는 rounding dependency의 깊이다

support graph에서 한 weight의 결정이 다음 weight에 영향을 주는 longest chain을 센다


| 구조 | dependency | SND 해석 | iteration bound |
| --- | --- | --- | --- |
| diagonal | 서로 독립 | 깊이 1 | 한 번에 round |
| input LDL | input channel 순서 | 최대 n | LDLQ 약 n 단계 |
| dense full H | mn coordinates 연결 | 최대 mn | 직접 방식은 비현실적 |
| Kronecker LDL | output + input chain | 최대 m+n−1 | YAQA 약 m+n 단계 |

핵심: Kronecker 구조는 full dependence를 두 축의 chain 길이 합으로 제한한다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 3–4, Definition 3.1 and Lemmas 3.2–3.3

## 9. Kronecker factor가 두 channel 축을 결합한다

두 작은 민감도 행렬을 곱 구조로 묶어 full Hessian의 주요 방향을 근사한다

- **output factor H_O**: m by m channel 관계
- **input factor H_I**: n by n channel 관계
- **Kronecker product**: H_O ⊗ H_I
- **structured Hessian**: mn by mn 방향 근사

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Lemma 3.3 and Eqs. 5–6

## 10. YAQA는 output과 input 양쪽 error를 전달한다

현재 rounding error에서 세 feedback term을 만들고 원본 weight에 더해 다시 quantize한다

- **레인 output side**
- **레인 input side**
  - **현재 Wq**: quantized matrix
  - **error Δ**: W* − Wq
  - **output term**: L'OᵀΔ
  - **input term**: ΔL'I
  - **feedback sum**: cross 포함 세 term
  - **requantize**: Q(W* + 세 term)
- 현재 Wq → error Δ (실선, 단방향)
- error Δ → output term (실선, 단방향)
- error Δ → input term (실선, 단방향)
- output term → feedback sum (실선, 단방향)
- input term → feedback sum (실선, 단방향)
- feedback sum → requantize (실선, 단방향)

핵심: LDLQ의 ΔL'I에 L'OᵀΔ와 L'OᵀΔL'I가 추가되어 output-channel 관계도 rounding에 반영된다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Eqs. 5–6

## 11. 세 feedback term을 따로 읽기

L'O와 L'I는 각각 H_O와 H_I의 block LDL decomposition에서 얻은 strictly lower part다


| term | 전파 축 | 직관 | LDLQ에 존재 |
| --- | --- | --- | --- |
| ΔL'I | input | 이전 input-channel error 전달 | 예 |
| L'OᵀΔ | output | output-channel error 전달 | 아니오 |
| L'OᵀΔL'I | output + input | 두 축의 결합 의존성 | 아니오 |
| Q(W* + sum) | codebook | 세 correction 뒤 다시 선택 | 같은 Q 사용 |

핵심: dual feedback은 두 개의 독립 보정만이 아니라 두 축이 만나는 cross term까지 포함한다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Eq. 6 and following paragraph

## 12. 교육용 2 by 2 rounding trace의 설정

nearest-integer quantizer와 작은 LDL factors를 둔 재계산 가능한 예시이며 논문 실험값이 아니다


| 항목 | 값 | 의미 |
| --- | --- | --- |
| 원본 W* | [[0.45,1.55],[2.45,2.55]] | 양자화 전 weight |
| 초기 W0 | [[0,2],[2,3]] | W*를 nearest integer로 round |
| L'O와 L'I | [[0,0],[0.5,0]] | 두 축의 strictly lower factor |
| 초기 Δ0 | [[0.45,−0.45],[0.45,−0.45]] | W* − W0 |

핵심: quantizer의 integer codebook은 고정하고 feedback이 선택 code만 바꾸는지 확인한다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Eq. 6; p. 13, Algorithm 1; illustrative trace

## 13. 첫 update에서 code 하나가 2에서 1로 바뀐다

Δ0에 output, input, cross factor를 적용해 새 quantization target을 만든다


| 계산 | 행렬 값 | 결과 |
| --- | --- | --- |
| output term | [[0.225,−0.225],[0,0]] | L'OᵀΔ0 |
| input term | [[−0.225,0],[−0.225,0]] | Δ0L'I |
| cross term | [[−0.1125,0],[0,0]] | L'OᵀΔ0L'I |
| new target | [[0.3375,1.325],[2.225,2.55]] | W* + 세 term |
| round W1 | [[0,1],[2,3]] | upper-right 2 → 1 |

핵심: 같은 nearest-integer quantizer라도 feedback을 더한 target은 다른 code를 선택할 수 있다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Eq. 6; illustrative arithmetic

## 14. 두 번째 update 뒤 fixed point에 도달한다

새 code로 error를 다시 계산하고 같은 update를 반복해 code가 더 바뀌는지 확인한다


| 상태 | error 또는 target | quantized matrix |
| --- | --- | --- |
| W1 이후 error | Δ1=[[0.45,0.55],[0.45,−0.45]] | W1=[[0,1],[2,3]] |
| 두 번째 target | [[0.8375,1.325],[2.225,2.55]] | W2=[[1,1],[2,3]] |
| 세 번째 반복 | 같은 target과 code | W3=W2 |
| stop condition | code가 더 바뀌지 않음 | fixed point |

핵심: Algorithm 1은 objective gradient가 0이 될 때가 아니라 quantized code가 안정되면 멈춘다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 13, Algorithm 1; illustrative arithmetic

## 15. Theorem 3.4가 보장하는 범위

정리는 가정 아래 error bound를 주며, 방향 유사도와 incoherence가 좋을수록 bound가 작아진다


| 요소 | bound에서의 역할 | 가정·bound 해석 | 말하지 않는 것 |
| --- | --- | --- | --- |
| cosine c | H와 H_O⊗H_I mismatch | tightness: c→1이면 감소 | H를 정확히 복원 |
| incoherence | trace term 제어 | tightness: 낮을수록 유리 | 모든 layer 동일 |
| rounding | rounding error bound | nearest/stochastic; E[e²]≤B | 임의 quantizer |
| rank condition | LDLQ bound와 비교 | LDLQ 비교: 낮은 output rank | 항상 lower loss |
| 결론 | error upper bound | 가정: true KL H, PD factors | downstream accuracy 보장 |

핵심: ‘provably better’는 조건부 bound 비교이며 모든 설정의 품질 우위를 뜻하지 않는다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 4, Theorem 3.4 and Eq. 7

## 16. true KL Hessian을 real Fisher로 관측한다

원본 model output에서 token을 sample하고 sequence gradient의 outer product를 평균한다

1. **원본 logits**: model output distribution
2. **Monte Carlo token**: 그 distribution에서 sample
3. **sequence gradient G**: layer weight에 대한 gradient
4. **real Fisher**: gradient outer product 기대값
5. **factor sketch**: H_O와 H_I를 근사

핵심: training label이 아니라 original model distribution에서 얻은 real Fisher를 쓴다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 4–5, §3.2 and real Fisher discussion

## 17. Sketch A: token 독립 가정으로 variance를 낮춘다

layer input x와 output-error gradient를 token pair로 모아 factor power iteration을 수행한다

1. **input x**: 각 token의 layer input
2. **error gradient**: 같은 sample의 output signal
3. **token-level moments**: independence 가정으로 평균
4. **power iteration**: H1과 I에서 최대 3회
5. **H_I, H_O**: biased low-variance factors

핵심: 더 많은 token pair를 쓰는 대신 sequence correlation을 무시해 bias가 생긴다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 5, §3.2.1 and Eqs. 10–11

## 18. Sketch B: sequence gradient로 factor를 구한다

identity에서 시작한 one-step power iteration을 per-sequence real Fisher gradient로 계산한다

1. **sequence sample**: 원본 output에서 token sample
2. **gradient matrix G**: 한 sequence의 weight gradient
3. **input factor**: H_I = E[GᵀG] / m
4. **output factor**: H_O = E[GGᵀ] / n
5. **single pass**: 같은 backward에서 둘 다 누적

핵심: token independence bias를 피하지만 독립 단위가 sequence라 충분한 data가 더 많이 필요하다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 5, §3.2.2 and Eqs. 12–13

## 19. Sketch A와 B의 tradeoff

둘 다 local H1보다 full Hessian 방향에 가깝지만 data regime에 따라 상대 우위가 달라진다


| 항목 | Sketch A | Sketch B | 해석 |
| --- | --- | --- | --- |
| sample unit | token pair | sequence gradient | B가 dependency 보존 |
| bias | token independence로 존재 | 낮음 | A의 구조적 근사 |
| variance | 많은 token으로 낮음 | sequence 수에 의존 | B는 data 요구 큼 |
| main cost | 20M tokens, 약 20 GPU-h | 64K × 2K, 약 30 GPU-h | 10B 기준 보고 |
| 관찰 | data-limited 때 우세 가능 | 충분한 data에서 대체로 강함 | 항상 B는 아님 |

핵심: A는 lower variance, B는 lower bias 쪽의 선택이며 둘 다 한계가 있다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 5–7, Figs. 1–3 and §§3.2.1–3.2.3

## 20. incoherence processing은 bound의 trace를 낮춘다

randomized Hadamard transform이 민감 방향을 좌표에 고르게 퍼뜨리도록 weight와 factors를 함께 바꾼다


| 단계 | 대상 | 목적 | 경계 |
| --- | --- | --- | --- |
| RHT | weight channel basis | 큰 coordinate 집중 완화 | 정확한 uniformity 아님 |
| factor transform | H_O와 H_I | 같은 basis에서 LDL 수행 | factor도 같이 변환 |
| trace ratio | processed 대 original D | 1보다 작으면 bound 감소 | empirical CDF |
| experiment | QTIP main setting | LDLQ와 YAQA 모두 적용 | rounding 효과와 혼동 금지 |

핵심: 같은 rotation 조건에서 YAQA가 더 나은 Hessian feedback을 쓰는 비교다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 5–7, Fig. 2 and Appendix A.5

## 21. offline sketch부터 inference까지의 경계

추론 전에 factors와 codes를 만들고, 배포 시에는 선택한 quantizer의 기존 표현만 사용한다

- **레인 offline**
- **레인 inference**
  - **calibration**: sequences → model samples
  - **backward**: real Fisher signals
  - **H factors**: H_O와 H_I
  - **YAQA rounding**: fixed-point code 선택
  - **low-bit model**: 기존 datatype로 실행
- calibration → backward (실선, 단방향)
- backward → H factors (실선, 단방향)
- H factors → YAQA rounding (실선, 단방향)
- YAQA rounding → low-bit model (실선, 단방향)

핵심: no inference overhead는 final format에 대한 말이며 offline 비용은 남는다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 5, 12–13, §§3.2, A.2 and Algorithm 1

## 25. QAT 비교에서는 bit와 data 차이를 함께 본다

Gemma 3 12B Instruct에서 original-output KL은 YAQA가 낮지만 조건은 같지 않다


| method | type | bits | KL W2 ↓ | data condition |
| --- | --- | --- | --- | --- |
| Google QAT | QAT | 4.5 | 0.089 | authors estimate 약 100× data |
| YAQA-A | PTQ | 4 | 0.058 | 20M-token sketch |
| YAQA-B | PTQ | 4 | 0.056 | 64K × 2K sequences |
| original | BF16 | 16 | 0 | reference distribution |

핵심: 낮은 KL은 original 보존이며 QAT의 보편적 품질 열세를 뜻하지 않는다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) p. 8, Table 3 and following paragraph

## 28. 정확도 이득과 함께 지불하는 비용

추론 format은 그대로지만 offline calibration과 factor memory는 LDLQ보다 커진다


| 항목 | YAQA | LDLQ 대비 | 조건·한계 |
| --- | --- | --- | --- |
| factor storage | O(m²+n²) | 대략 2× Hessian storage | lower triangles만 저장 |
| accumulation | FP32 + regularization | backward 필요 | TF32는 불안정 보고 |
| rounding | output·input matmul 반복 | 약 2× quantization time | authors setup에서 작음 |
| Sketch A/B | 약 20 / 30 GPU-h | 추가 offline cost | 10B reported setup |
| inference | same quantizer format | YAQA 추가 overhead 없음 | kernel 성능은 Q에 의존 |

핵심: 배포 runtime을 늘리지 않는 대신 quantization pipeline의 준비 단계가 더 무거워진다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 4–5, 12, §A.2

## 29. 논문 결과를 넘어서 말하면 안 되는 것

method의 강점은 clear하지만 approximation, data, comparison scope가 남는다


| 확인된 결과 | 해석 경계 | 남은 질문 |
| --- | --- | --- |
| reported settings에서 lower KL | 모든 quantizer·model의 보장 아님 | 다른 architectures 재현 |
| Theorem 3.4 error bound | 조건부 second-order bound | bound와 actual KL 간격 |
| A/B가 H1보다 방향상 근접 | full H를 직접 계산하지 않음 | data-limited reliability |
| no inference overhead | offline GPU·memory cost 존재 | large deployment pipeline cost |
| 선택 baselines보다 우수 | omitted PTQ 전체와 비교 아님 | broader matched evaluation |

핵심: YAQA는 강한 근거를 주지만 exact optimization이나 universal dominance는 아니다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 4–8, Theorem 3.4, experiments, and §5

## 30. YAQA를 한 번에 정리하면

codebook을 바꾸지 않고 full-model sensitivity에 가까운 방향으로 rounding assignment를 바꾼다

- Quantizer는 값 집합을 정하고, YAQA는 그중 선택할 code를 정한다.
- LDLQ의 local proxy 대신 full-model KL Hessian의 Kronecker sketch를 쓴다.
- Input feedback에 output과 cross feedback을 더해 두 축의 error를 반영한다.
- A는 token-level lower variance, B는 sequence-level lower bias를 지향한다.
- 결과는 lower KL을 보이지만 theorem·bit·data·finetuning 조건이 붙는다.
- Inference format은 유지되지만 offline collection과 storage cost는 증가한다.

핵심: 핵심은 같은 값 집합에서 model을 덜 바꾸는 code를 고르는 것이다

근거: [paper-v3](https://arxiv.org/abs/2505.22988v3) pp. 1–8, main method and results; p. 13, Algorithm 1
