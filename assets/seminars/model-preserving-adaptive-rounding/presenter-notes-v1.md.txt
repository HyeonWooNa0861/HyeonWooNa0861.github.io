## 1. YAQA: 모델 출력을 보존하는 적응형 반올림

1. YAQA: 모델 출력을 보존하는 적응형 반올림

발표 대본
YAQA는 Yet Another Quantization Algorithm의 약자입니다. 이 논문은 새로운 low-bit datatype을 제안하지 않습니다. 이미 정해진 quantizer의 representable points를 그대로 쓰되, 각 weight를 어느 point로 보낼지를 full-model output distribution에 더 맞게 결정합니다. 핵심 도구는 full-model KL Hessian의 Kronecker-factored sketch와 output·input channel 양쪽으로 error를 전달하는 adaptive rounding입니다. 공개 기준 문서는 2026년 6월 3일의 arXiv v3이며 ICML 2026 proceedings footline을 가진 20쪽 논문입니다.

## 2. LLM 배포에서 양자화가 맡는 일

2. LLM 배포에서 양자화가 맡는 일

발표 대본
Weight-only post-training quantization은 pretrained weight를 다시 학습하지 않거나 제한적으로만 보정하면서 낮은 precision으로 저장합니다. Memory-bound inference에서는 읽어야 하는 bytes가 줄고, 지원되는 datatype에서는 throughput도 높아질 수 있습니다. 하지만 같은 bit 수라도 rounding 선택에 따라 model output distribution이 크게 달라집니다. 이 논문은 압축 형식을 설계하기보다 원본 모델의 행동을 더 잘 보존하는 rounding을 다룹니다.

## 3. quantizer와 rounding algorithm은 다르다

3. quantizer와 rounding algorithm은 다르다

발표 대본
논문은 quantization framework를 두 부분으로 구분합니다. Quantizer Q는 codebook C, 즉 표현 가능한 points를 정의합니다. Rounding algorithm은 원래 parameter를 그 points 중 하나에 배정합니다. 따라서 YAQA를 QTIP이나 standard INT4와 함께 쓸 수 있습니다. 추론 형식은 quantizer가 결정하므로 YAQA 자체가 새 decode kernel을 요구하지는 않습니다. 다만 Hessian sketch와 rounding을 계산하는 offline 비용은 분명히 존재합니다.

## 4. 목표는 원본 출력 분포와의 KL을 줄이는 것

4. 목표는 원본 출력 분포와의 KL을 줄이는 것

발표 대본
식 1은 quantized parameters를 codebook C 안에서 고르되, 입력 distribution에 대한 expected KL divergence를 최소화하도록 정의합니다. 원본 모델 output distribution이 기준이고 양자화 모델이 이를 근사합니다. 이산적인 조합 최적화를 정확히 푸는 것은 어렵기 때문에 논문은 한 linear layer의 weight 변화가 이 KL에 미치는 영향을 second-order approximation으로 다룹니다. 여기서 lower KL은 원본 모델과 더 가깝다는 뜻이지, 별도의 ground-truth task에서 항상 더 높은 accuracy를 뜻하지는 않습니다.

## 5. immediate activation error는 왜 proxy인가

5. immediate activation error는 왜 proxy인가

발표 대본
LDLQ와 동등한 GPTQ rounding은 H1 equals expected x transpose x를 사용해 현재 layer activation reconstruction error를 줄입니다. 이 값은 forward input으로 구할 수 있어 저렴하지만, 해당 error가 뒤의 attention과 MLP를 통과하면서 어떻게 변하는지는 반영하지 않습니다. YAQA는 full-model KL Hessian H를 목표로 삼습니다. 다만 H를 그대로 계산하지 않고 구조화된 approximation을 쓰므로, approximation이 true Hessian의 중요한 방향을 얼마나 잘 포착하는지가 성능과 bound를 좌우합니다.

## 6. full Hessian은 그대로 저장할 수 없다

6. full Hessian은 그대로 저장할 수 없다

발표 대본
W가 m output channels와 n input channels를 가지면 vectorized weight error에는 mn coordinates가 있습니다. Full-model KL의 second-order curvature H는 이 coordinates 사이의 관계를 담아 mn by mn이 됩니다. YAQA는 H를 H_O Kronecker H_I로 근사합니다. H_O는 output-channel 관계, H_I는 input-channel 관계를 담습니다. Storage는 O(m squared plus n squared)로 줄지만, LDLQ의 H1 하나보다 factor가 하나 더 있으므로 저자 구현에서는 Hessian storage가 대략 두 배입니다.

## 7. LDLQ는 input channel 방향으로 error를 넘긴다

7. LDLQ는 input channel 방향으로 error를 넘긴다

발표 대본
LDLQ의 fixed-point form을 한 update로 펼친 그림입니다. 먼저 quantizer Q가 current quantized matrix Wq를 만듭니다. Error Δ는 original W* minus Wq입니다. H1의 block LDL decomposition에서 얻은 strictly lower factor L'I를 이용해 ΔL'I를 원래 weight에 더한 뒤 다시 quantize합니다. 이 의존성은 input-channel 순서로만 전파됩니다. 그림의 화살표는 반복 전체의 cycle을 그린 것이 아니라 한 iteration의 data dependency를 시간 순서로 펼친 것입니다.

## 8. SND는 rounding dependency의 깊이다

8. SND는 rounding dependency의 깊이다

발표 대본
Structural nilpotence degree, SND는 L minus identity의 support graph가 가진 dependency depth를 나타냅니다. Definition 3.1이 SND를 정의하고 Lemma 3.2가 이 깊이로 fixed-point iteration 수를 bound합니다. Full Hessian의 dense triangular factor를 그대로 쓰면 depth가 mn까지 갈 수 있습니다. Lemma 3.3에 따라 Kronecker product of unit triangular factors의 SND는 두 factor의 SND 합으로 분해됩니다. 그래서 YAQA는 output m과 input n의 합에 비례하는 단계 안에서 수렴하는 구조를 얻습니다.

## 9. Kronecker factor가 두 channel 축을 결합한다

9. Kronecker factor가 두 channel 축을 결합한다

발표 대본
H_O와 H_I는 서로 독립된 입력이 아니라 full Hessian의 output-channel and input-channel structure를 각각 요약한 factors입니다. 이 둘의 Kronecker product는 mn by mn shape을 암시하지만 실제로 dense matrix를 만들지 않고 factorized operations로 사용합니다. LDL decomposition도 각 factor에 따로 적용할 수 있어 output-side L'_O와 input-side L'_I를 얻습니다. 이 구조가 YAQA의 세 feedback terms로 이어집니다.

## 10. YAQA는 output과 input 양쪽 error를 전달한다

10. YAQA는 output과 input 양쪽 error를 전달한다

발표 대본
YAQA의 식 6을 한 iteration으로 펼친 그림입니다. Current Wq로 error Δ를 만들고, output factor의 strictly lower component와 input factor를 적용해 세 terms를 계산합니다. Input term ΔL'I는 LDLQ에 있던 부분입니다. YAQA는 output term L'O transpose Δ와 cross term L'O transpose Δ L'I를 추가합니다. 마지막에는 original W* plus three terms를 같은 quantizer Q에 넣습니다. 따라서 representable points는 바뀌지 않고 code assignment만 바뀝니다.

## 11. 세 feedback term을 따로 읽기

11. 세 feedback term을 따로 읽기

발표 대본

## 15. Theorem 3.4가 보장하는 범위

15. Theorem 3.4가 보장하는 범위

발표 대본
Theorem 3.4는 true KL Hessian H와 positive-definite factors H_O, H_I를 두고 nearest 또는 stochastic rounding의 expected squared error가 bounded라는 가정 아래 quadratic error upper bound를 줍니다. 첫 항은 true H와 Kronecker approximation의 cosine similarity c로 생기는 mismatch이며 c가 1에 가까울수록 작아집니다. 둘째 항은 factor traces, incoherence, dimensions, and rounding error bound에 의해 정해지므로 낮은 incoherence가 tightness에 유리합니다. 논문은 낮은 output rank 등 별도의 충분조건 아래 trace part가 LDLQ 이하가 되는 비교도 제시합니다. 이는 exact discrete KL optimum이나 every downstream task improvement를 보장하지 않습니다.

## 16. true KL Hessian을 real Fisher로 관측한다

16. true KL Hessian을 real Fisher로 관측한다

발표 대본
KL divergence는 original model at W*에서 first derivative가 zero이고, corresponding Fisher information이 Hessian과 일치합니다. 저자들은 original logits distribution에서 Monte Carlo sample을 뽑아 cross-entropy gradient를 만들고 sequence 단위 outer products를 사용합니다. Training labels에 대한 empirical Fisher는 trained optimum assumptions에 의존하고 true Hessian과 다를 수 있습니다. 하지만 full Fisher를 그대로 저장하지 못하므로 다음 slides의 two sketches가 Kronecker factors를 직접 추정합니다.

## 17. Sketch A: token 독립 가정으로 variance를 낮춘다

17. Sketch A: token 독립 가정으로 variance를 낮춘다

발표 대본
Sketch A는 한 sequence 안의 tokens가 linear layer에서 independent라고 가정합니다. 실제 attention model에서는 맞지 않으므로 biased estimator입니다. 대신 sample size를 token count까지 늘려 variance가 roughly inverse number of tokens로 감소합니다. Input x와 error signal을 이용한 modified backward pass로 factor moments를 계산합니다. 초기값은 LDLQ Hessian H1과 output identity이고, authors report at most three full iterations. 10B model, 20M-token dataset에서 about 20 GPU-hours가 보고됩니다.

## 18. Sketch B: sequence gradient로 factor를 구한다

18. Sketch B: sequence gradient로 factor를 구한다

발표 대본
Sketch B는 identity factors에서 real Fisher Hessian에 대한 one round of power iteration을 수행합니다. 한 sequence의 layer weight gradient를 G라 하면 H_I는 expected G transpose G divided by m, H_O는 expected G G transpose divided by n으로 계산됩니다. 두 factors는 같은 backward pass에서 얻을 수 있습니다. Token-level independence를 두지 않아 Sketch A보다 bias가 낮지만, independent samples가 sequences이므로 variance를 낮추려면 more sequences가 필요합니다. Main setup은 64K sequences of 2K tokens, about 30 GPU-hours for a 10B model입니다.

## 28. 정확도 이득과 함께 지불하는 비용

28. 정확도 이득과 함께 지불하는 비용

발표 대본
Factor storage는 O(m squared plus n squared)이며 lower triangles만 저장해도 LDLQ Hessian storage의 roughly twice로 설명됩니다. Authors accumulate in FP32 with diagonal regularization around 1e-4 times trace over dimension and report TF32 numerical instability. YAQA rounding takes roughly twice LDLQ because SND is about m plus n rather than n, but is negligible relative to Hessian collection in their practice. The 20 and 30 GPU-hour figures는 특정 data choice를 쓴 10B model 기준이며 보편적 hardware guarantee가 아닙니다.

## 29. 논문 결과를 넘어서 말하면 안 되는 것

29. 논문 결과를 넘어서 말하면 안 되는 것

발표 대본
실험은 여러 Llama, Gemma, Qwen size와 QTIP·INT4 example을 포함해 폭넓은 근거를 제공합니다. Still, the paper explicitly selects baselines and does not compare every PTQ family. ## 30. YAQA를 한 번에 정리하면

30. YAQA를 한 번에 정리하면

발표 대본
첫째, YAQA is a rounding algorithm, not a quantizer. 둘째, full-model KL sensitivity를 직접 저장하지 않고 output and input Kronecker factors로 근사합니다. 셋째, three feedback terms가 input-only LDLQ를 generalize합니다. 넷째, Sketch A와 B는 bias-variance-data tradeoff가 다릅니다. 다섯째, experiments show strong KL preservation across several settings, but theorem and empirical claims have explicit conditions. 마지막으로 same inference format does not remove offline cost. 이 여섯 문장을 연결하면 논문의 전체 기여와 한계를 함께 설명할 수 있습니다.
