Open-ER는 와인을 고르는 과정을 검색, 필터, 비교, 시각화로 정리한 와인 탐색·교육 서비스다. 와인 이름을 찾는 데서 멈추지 않고 타입, 국가, 세부 산지, 포도 품종, 가격대로 후보를 좁힌 뒤 맛과 향의 차이를 비교하며 자신의 취향을 이해하도록 돕는다.

## 1. 주요 기능

| 기능 | 사용자 가치 |
|---|---|
| 검색과 필터 | 타입·산지·품종·가격대에 따라 와인 후보를 빠르게 선별 |
| 와인 상세 | 개별 와인의 특징과 테이스팅 프로필을 한 화면에서 확인 |
| 초보자 가이드 | 와인 타입, 국가, 품종과 선택 기준을 탐색 과정에서 학습 |
| 최대 5개 비교 | 여러 후보의 공통점과 차이를 나란히 확인 |
| 향 분석 | 공통 향과 고유 향을 구분해 각 와인의 개성 이해 |
| 프로필 시각화 | 단맛·산도·탄닌·바디·알코올 특성을 직관적으로 비교 |

## 2. 서비스의 의의

와인 선택에는 산지, 품종, 가격, 향과 맛처럼 서로 다른 기준이 동시에 작용한다. Open-ER는 전문 용어와 긴 상품 목록 사이에서 길을 잃기 쉬운 사용자를 위해 선택 기준을 구조화하고, 검색과 학습을 하나의 흐름으로 연결한다.

처음 와인을 접하는 사용자에게는 선택 근거를 만들어 주는 입문 도구가 되고, 이미 선호가 있는 사용자에게는 비슷한 와인과 새로운 개성을 함께 발견하는 큐레이션 도구가 된다.

## 3. 탐색 흐름

1. 검색 또는 필터로 관심 있는 와인 후보를 찾는다.
2. 상세 화면에서 산지, 품종, 가격대와 테이스팅 특성을 확인한다.
3. 관심 있는 후보를 비교 목록에 추가한다.
4. 최대 5개 와인의 공통 향, 고유 향과 프로필을 비교한다.
5. 시각화와 가이드를 바탕으로 자신의 선택 기준을 정리한다.

## 4. 비교와 시각화의 가치

| 비교 요소 | 기대 효과 |
|---|---|
| 공통 향 | 여러 후보가 공유하는 취향 축 파악 |
| 고유 향 | 특정 와인만의 차별점 발견 |
| 테이스팅 프로필 | 단맛·산도·탄닌·바디·알코올 균형 비교 |
| 입문 콘텐츠 | 비교 결과를 와인 용어와 선택 지식으로 연결 |

텍스트만으로 기억하기 어려운 감각 정보를 시각화하면 사용자는 “어떤 와인이 좋은가”뿐 아니라 “왜 이 와인이 내 취향에 맞는가”를 더 쉽게 설명할 수 있다.

## 5. 성장 로드맵

| 현재 제공 기반 | 해결 방향 | 확장 가능성 |
|---|---|---|
| 다중 필터와 와인 비교 | 데이터 품질·갱신 기준과 출처 표시 강화 | 국가·산지·품종별 전문 큐레이션 확대 |
| 향과 테이스팅 프로필 시각화 | 용어 설명과 비교 근거를 화면 가까이에 배치 | 초보자 학습 코스와 취향 리포트 제공 |
| 후보 중심 탐색 경험 | 즐겨찾기와 취향 기록 기능 연결 | 음식 페어링, 상황별 추천, 개인화 컬렉션 |

Open-ER는 탐색과 교육을 함께 제공하는 현재 경험을 기반으로, 사용자가 자신의 취향을 축적하고 새로운 와인을 발견하는 개인 큐레이션 플랫폼으로 성장할 수 있다.
