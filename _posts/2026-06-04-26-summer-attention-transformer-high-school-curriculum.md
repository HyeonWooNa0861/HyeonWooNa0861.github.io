## 4. 핵심 개념을 고등학생 수준으로 설명하기

### Attention

Attention은 문장 안에서 지금 중요한 단어에 더 집중하는 방법이다. 예를 들어 “그 학생은 책을 읽고 그것을 가방에 넣었다”라는 문장에서 “그것”이 무엇인지 이해하려면 앞의 “책”을 참고해야 한다. Attention은 이런 연결을 숫자로 표현한다.

### Self-Attention

Self-attention은 한 문장 안의 단어들이 서로를 참고하는 방식이다. 각 단어가 다른 단어들을 보면서 “나를 이해하는 데 어떤 단어가 중요한가”를 판단한다.

### Multi-Head Attention

Multi-head attention은 여러 명의 관찰자가 같은 문장을 다른 관점에서 보는 것과 비슷하다. 어떤 head는 주어와 동사의 관계를 보고, 어떤 head는 대명사가 가리키는 대상을 보고, 어떤 head는 가까운 단어 관계를 볼 수 있다.

### Positional Encoding

Transformer는 RNN처럼 단어를 앞에서 뒤로 하나씩 읽지 않는다. 그래서 단어의 순서를 알려 주는 별도 표시가 필요하다. Positional encoding은 “이 단어는 문장의 몇 번째 위치에 있다”는 정보를 벡터에 더하는 장치다.

### Transformer

Transformer는 attention을 중심으로 만든 AI 모델 구조다. 이 논문의 핵심은 RNN이나 CNN 없이도 attention만으로 문장 관계를 잘 학습할 수 있음을 보였다는 점이다. 이후 BERT, GPT 계열 모델의 중요한 출발점이 되었다.

## 5. 1일차: 문장을 숫자로 바꾸는 법

### 학습 목표

- AI가 문장을 직접 이해하는 것이 아니라 숫자로 바꿔 처리한다는 점을 이해한다.
- token, embedding, context의 의미를 설명할 수 있다.
- 같은 단어라도 문맥에 따라 의미가 달라질 수 있음을 예시로 설명한다.

### 시간 구성

| 시간 | 학습 방식 | 내용 |
|---:|---|---|
| 0:00-0:30 | 문제 제기 | “AI는 글을 이해하는가, 계산하는가?”라는 질문으로 언어 모델의 관점을 정리 |
| 0:30-1:10 | 이론 설명 | token, vocabulary, vector, embedding의 정의와 역할 |
| 1:10-1:50 | 예시 학습 | 문장 분할 예시를 통해 tokenization과 embedding의 필요성 해설 |
| 1:50-2:00 | 휴식 | 주요 용어 정리 |
| 2:00-2:50 | 문맥 분석 | “bank”, “사과”, “배”처럼 다의어가 문맥에 따라 달라지는 원리 해설 |
| 2:50-3:30 | 개념 확장 | 단어 단독 의미와 문장 속 의미의 차이를 context 관점에서 비교 |
| 3:30-4:00 | 정리 | token, embedding, context를 연결한 짧은 개념 서술 작성 |

### 핵심 설명

AI 모델은 문장을 그대로 읽지 않는다. 먼저 문장을 작은 단위인 token으로 나누고, 각 token을 숫자 벡터로 바꾼다. 하지만 단어 하나만 보면 의미가 부족하다. “배”는 먹는 과일일 수도 있고, 물 위를 다니는 탈것일 수도 있다. 그래서 AI는 주변 단어를 함께 보아야 한다.

이날의 핵심은 “문장 이해는 단어 하나의 뜻을 외우는 것이 아니라, 주변 관계를 보는 일”이라는 점이다. 이것이 attention으로 넘어가는 출발점이 된다.

### 예시 학습

아래 문장은 단어의 의미가 주변 문맥에 의해 결정된다는 점을 설명하기 위한 예시다.

- “나는 강가에서 배를 보았다.”
- “나는 점심으로 배를 먹었다.”
- “그 친구는 차가운 표정으로 말했다.”
- “책상 위에 차가 놓여 있었다.”

각 문장에서 같은 단어가 다른 의미로 쓰이는 이유를 주변 명사, 동사, 상황 단서와 연결해 해설한다. 이 예시는 embedding이 단어의 사전적 의미만 담는 것이 아니라 문맥적 의미를 반영해야 한다는 논의로 이어진다.

### 1일차 학습 정리

- “AI가 문장을 숫자로 바꾸는 과정” 개념 요약문
- 다의어 문장 2개에 대한 문맥 해설

## 6. 2일차: Attention과 Self-Attention

### 학습 목표

- attention을 “중요한 정보에 더 큰 비중을 주는 방법”으로 설명할 수 있다.
- self-attention에서 단어들이 서로를 참고한다는 점을 이해한다.
- Query, Key, Value를 쉬운 비유로 설명할 수 있다.

### 시간 구성

| 시간 | 학습 방식 | 내용 |
|---:|---|---|
| 0:00-0:25 | 개념 복습 | token, embedding, context의 관계 재정리 |
| 0:25-1:05 | 이론 설명 | attention을 가중치 기반 정보 선택 방식으로 설명 |
| 1:05-1:50 | Q/K/V 해설 | Query, Key, Value를 정보 검색 구조와 연결해 설명 |
| 1:50-2:00 | 휴식 | 주요 용어 정리 |
| 2:00-2:50 | 예시 분석 | 대명사와 지시어가 앞 단어를 참조하는 문장 분석 |
| 2:50-3:30 | 표 기반 학습 | attention score와 attention map의 의미를 간단한 표로 해설 |
| 3:30-4:00 | 비교 설명 | self-attention이 순차 처리 방식과 다른 점 정리 |

### 핵심 설명

Attention은 모든 정보를 똑같이 보지 않고, 지금 필요한 정보에 더 집중한다. Self-attention은 문장 안의 각 단어가 다른 단어들과 얼마나 관련 있는지를 계산한다.

간단한 비유는 다음과 같다.

| 개념 | 쉬운 비유 |
|---|---|
| Query | 내가 지금 찾고 싶은 질문 |
| Key | 각 정보가 가진 이름표 |
| Value | 실제로 가져올 정보 |
| Attention score | 질문과 이름표가 얼마나 잘 맞는지 |

예를 들어 “고양이가 생선을 먹었다. 그것은 매우 신선했다.”라는 문장에서 “그것”을 이해하려면 “생선”과 강하게 연결되어야 한다.

### 예시 학습

아래 문장은 self-attention이 단어 사이의 관계를 어떻게 계산하는지 설명하기 위한 예시다. 각 단어 사이의 관련도를 0-3점으로 단순화하면 attention score의 직관을 이해하기 쉽다.

예시 문장:

> 소년은 로봇에게 공을 던졌고, 로봇은 그것을 다시 소년에게 돌려주었다.

분석 질문:

- “그것”은 무엇을 가리키는가?
- “로봇은”과 강하게 연결되는 동작은 무엇인가?
- 모든 단어를 순서대로만 읽는 것보다 단어 간 관련도를 직접 계산하는 방식이 왜 유리한가?

### 2일차 학습 정리

- 한 문장에 대한 attention 관련도 표
- Query, Key, Value 개념 설명문

## 7. 3일차: Transformer 구조 이해

### 학습 목표

- Transformer가 RNN/CNN 없이 attention 중심으로 작동한다는 점을 이해한다.
- encoder와 decoder의 역할을 구분한다.
- multi-head attention과 positional encoding이 왜 필요한지 설명할 수 있다.

### 시간 구성

| 시간 | 학습 방식 | 내용 |
|---:|---|---|
| 0:00-0:30 | 개념 복습 | self-attention과 Q/K/V의 역할 재정리 |
| 0:30-1:10 | 구조 설명 | encoder, decoder, attention layer의 기능 |
| 1:10-1:50 | 논문 도식 해설 | Transformer block의 입력, attention, feed-forward 흐름 설명 |
| 1:50-2:00 | 휴식 | 주요 용어 정리 |
| 2:00-2:45 | 이론 확장 | multi-head attention이 여러 관계를 동시에 보는 이유 |
| 2:45-3:20 | 순서 정보 해설 | positional encoding이 필요한 이유와 간단한 예시 |
| 3:20-4:00 | 비교 설명 | RNN 방식과 Transformer 방식의 구조적 차이 정리 |

### 핵심 설명

Transformer는 크게 encoder와 decoder로 나눌 수 있다. Encoder는 입력 문장을 이해하는 부분이고, decoder는 출력 문장을 생성하는 부분이다. 번역을 예로 들면 encoder는 영어 문장을 읽고, decoder는 한국어 문장을 만들어 낸다.

논문에서 중요한 변화는 순서대로 하나씩 읽는 RNN 구조를 중심에 두지 않았다는 점이다. 대신 각 단어가 다른 모든 단어를 직접 참고하는 attention 구조를 사용했다. 이 덕분에 멀리 떨어진 단어 관계도 빠르게 연결할 수 있고, 학습 과정에서 병렬 처리가 쉬워진다.

### multi-head attention 예시 학습

같은 문장을 여러 관점에서 분석하면 multi-head attention의 필요성을 직관적으로 이해할 수 있다.

문장:

> 학생은 선생님에게 질문을 했고, 선생님은 친절하게 그것에 답했다.

| 관점 | 분석 기준 |
|---|---|
| 문법 관계 | 누가 행동했는가? |
| 지시 관계 | 대명사는 무엇을 가리키는가? |
| 의미 관계 | 감정이나 태도를 나타내는 단어는 무엇인가? |

관점별 분석을 함께 보면 하나의 기준만 사용할 때보다 문장을 더 풍부하게 이해할 수 있다. 이것이 multi-head attention의 직관이다.

### positional encoding 예시 학습

아래 두 문장을 비교한다.

- “학생이 선생님을 도왔다.”
- “선생님이 학생을 도왔다.”

사용된 단어는 거의 같지만 순서가 바뀌면 의미가 달라진다. Transformer는 순서대로 읽는 구조가 아니기 때문에, 단어 위치 정보를 따로 추가해야 한다. 이것이 positional encoding이다.

### 이용 사례

| 분야 | Transformer와의 연결 |
|---|---|
| 기계 번역 | 입력 문장의 단어 관계를 보고 다른 언어로 바꾼다. |
| 문서 요약 | 긴 글에서 중요한 문장과 단어에 집중한다. |
| 챗봇 | 이전 대화와 현재 질문의 관계를 보고 답변을 만든다. |
| 검색 | 질문과 문서가 얼마나 관련 있는지 비교한다. |
| 추천 | 사용자의 행동과 콘텐츠 특징 사이의 관계를 찾는다. |
| 코드 보조 | 자연어 설명과 코드 패턴의 관계를 학습해 제안한다. |

### 모델 한계와 윤리적 쟁점

- AI가 그럴듯하지만 틀린 답을 만들면 누가 책임져야 하는가?
- AI가 만든 글과 사람이 쓴 글은 어떻게 구분할 수 있는가?
- AI가 편향된 데이터를 학습하면 어떤 문제가 생기는가?
- 학교 과제에서 AI를 어디까지 활용해도 되는가?

### 사례 분석문

학습자는 하나의 AI 서비스를 선택해 Transformer 개념과 연결하는 짧은 분석문을 작성한다. 실제 서비스 기획보다 기술 개념을 정확하게 적용하는 것이 목표다.

필수 포함 항목:

- 선택한 AI 서비스의 입력 정보
- 서비스가 처리해야 하는 문장 또는 데이터의 관계
- attention이 중요한 이유
- Transformer 구조가 기존 순차 처리 방식보다 유리한 점
- 예상되는 오류, 편향, 한계

예시 주제:

- 긴 교과서 문단을 쉬운 말로 바꾸는 요약 서비스
- 영어 지문에서 핵심 근거 문장을 찾는 독해 보조 도구
- 학생 질문을 분류해 주요 내용을 요약하는 상담 보조 시스템
- 학교 공지사항을 개인 일정과 연결해 정리하는 알림 시스템

## 9. 평가 방법

평가는 어려운 수식 계산보다 개념 이해와 설명 능력을 중심으로 한다.

| 평가 요소 | 기준 |
|---|---|
| 개념 이해 | attention, self-attention, Transformer를 쉬운 말로 설명할 수 있는가? |
| 관계 분석 | 문장 속 단어 관계를 연결선이나 표로 표현할 수 있는가? |
| 사례 연결 | Transformer가 실제 서비스에 쓰이는 이유를 설명할 수 있는가? |
| 개념 서술 | 기술 개념을 정확한 용어와 쉬운 예시로 함께 설명하는가? |
| 비판적 사고 | AI의 한계와 위험을 함께 생각하는가? |

## 10. 수업 운영 팁

- 수식은 마지막에 보여 주되, 각 기호가 어떤 의미를 갖는지 먼저 설명한다.
- “attention = 집중”이라는 단어만 외우게 하지 말고, “어떤 단어가 어떤 단어를 참고하는가”로 말하게 한다.
- Multi-head attention은 여러 카메라 또는 여러 관찰자 비유로 설명하면 이해가 쉽다.
- Positional encoding은 “단어 순서가 바뀌면 의미가 바뀐다”는 예시에서 출발한다.
- 최종 정리는 구현보다 입력 정보, 단어 관계, attention의 필요성, Transformer의 구조적 장점과 한계를 중심으로 본다.

## 12. 마지막 핵심 정리

이 4일 과정의 핵심은 Transformer의 모든 세부 수식을 외우는 것이 아니다. 고등학생 수준에서는 다음 세 문장을 이해하면 충분하다.

1. AI는 문장을 숫자로 바꾸고, 단어 사이의 관계를 계산한다.
2. Attention은 지금 중요한 단어에 더 집중하게 해 주는 방법이다.
3. Transformer는 attention을 중심으로 만든 구조이며, 오늘날 많은 생성형 AI의 기반이 되었다.
